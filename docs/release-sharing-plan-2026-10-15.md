# GitHub 실험 자료 공유 구현 범위 — 2026-10-15

사용자가 현재 버전을 공개 저장소에 게시하고 반복 학습 자료 공유를 자동화하도록 승인했다.
기존 연구 코드와 실험 결과를 함께 게시하되 게임/학습/API 실험은 추가로 실행하지 않는다.

1. 코드·설정·검증 문서는 Git에, 가중치·시작 월드·기록은 공개 Releases에 둔다.
2. 공개 목록에 명시된 파일만 묶고 비밀정보 패턴, 경로, 파일 해시를 검사한다.
   Minecraft JAR 및 이를 포함한 wheel, 외부 원본 저장소/기본 모델 사본은 첨부하지 않는다.
   공식 다운로드와 고정 해시, 기존 로컬 빌드·패치 절차를 제공한다.
3. 묶음을 콘텐츠 해시로 식별하고 이전 manifest의 동일 묶음을 참조한다.
   각 실험에는 코드 snapshot, 원목/이동 checkpoint, 시작 월드, 임베딩을 함께 연결한다.
4. PowerShell 발행기는 기존 Git credential을 메모리에서만 사용하고 `gh`를 사용하지 않는다.
   draft에 새 자산을 올려 서버 SHA256을 확인한 다음 공개한다. 기존 자산/태그를 덮어쓰지 않는다.
5. PowerShell 동기화기는 실험을 선택해 필요한 묶음만 받는다. 캐시/기존 파일을 검증하고,
   경로 탈출·링크·다른 내용의 기존 파일을 거부한다. 코드를 실행하거나 환경을 자동 설치하지 않는다.
6. 새 회귀/통합 검사, 전체 소프트웨어 검사, 공개 파일 검사, 원격 다운로드 검증 후 종료한다.
   기존 10/12 및 10/15 실게임 증거와 이번 배포 검증은 분리한다.

Minecraft EULA의 modded game 배포 제한을 적용한다:
https://www.minecraft.net/en-us/eula . 원래 로컬 전달 ZIP은 수정하지 않는다.
현재 저장소 visibility는 GitHub API로 public을 확인했다.
