# 나무 수집 복구 시연 탐색 — 2026-10-08

## 결론

공식 VPT 10.x의 독립 세션 6개를 위치·인벤토리로 선별하고, 그중 3개의 영상을
내려받아 후보 구간의 스토리보드 36프레임을 직접 검토했다. 일반적인 나무 접근과
채집은 보이지만, **벽 앞 정체 → 목표에서 잠시 멀어지는 우회 → 재접근·수집**을
입증하는 시연은 이번 제한된 표본에서 확보하지 못했다. 복구 BC 학습 진입 조건 미충족.
공개 데이터 전체에 그런 시연이 없다는 결론은 아니다. 연속 영상 전 프레임을 사람이
검토한 것도 아니다.

추가 학습·특징 추출·게임 평가 0회, optimizer 갱신 0회. 기본 정책과 기존 체크포인트,
최종 평가 시드는 유지했다. 미실행 학습·평가를 실패 표본에 넣지 않는다.

## 출처와 분리

기존 공식 index `data/vpt-contractors-preflight-20261008/index-10.json`을 사용했다.
원본 제공처는 [OpenAI VPT](https://github.com/openai/Video-Pre-Training)이며, 파일 URL은
`data/bc-wood-search-20261008/selection.json` 및 `manifest.json`에 보존했다.
이전 호환성 probe인 `02e496ce4abb`를 제외하고 index 순서상 독립 세션 6개를 선택했다.
결과를 보기 전에 앞 4개 train, 뒤 2개 development로 지정했다. 공개 데이터의 기존
모델 사전학습 포함 여부는 확인하지 않았으므로 개발 split은 이번 BC 내부 분리만 의미한다.

같은 식별자의 다음 5분 녹화 조각을 다른 split에 넣지 않는다. 기존 BC plan 검사는
전체 파일명 중복만 검사하므로 이 누수를 차단하지 못했다. `bc_core.validate_plan`에
공식 파일명의 12자리 식별자 기반 분리 검사를 추가했다. 같은 split의 서로 다른 조각은
허용한다. 과거 FindCave 3개는 서로 다른 식별자이므로 기존 결과는 영향받지 않는다.

## 검증과 다음 단위

- 원본 6개 JSONL 및 3개 MP4의 바이트 수·SHA256을 보존하고 재검증했다.
- 새 교차 세션 회귀 테스트가 수정 전 실패, 수정 후 통과했다.
- Windows 전체 244개 중 228개 통과·16개 제외. WSL BC 관련 6개 통과.
- 이번 작업은 데이터 다운로드/CPU 영상 검토/검사뿐이며 게임 입력을 보내지 않았다.

다음에 필요한 것은 더 많은 일반 벌목이 아니라 **학습용 막힌 출발 상태에서의 교정 시연**이다.
사람 또는 명시적으로 구분된 교사 정책이 실제 저수준 행동으로 우회·획득을 완료한 기록을
수집하고, 별도 세션에 같은 능력이 존재하는지 확인해야 한다. 교사/스크립트 성공은 학습
정책 성공에 포함하지 않는다. 새 수집기나 교사 정책은 이번에 구현하지 않았다.
적합한 시연 확보 뒤에는 런타임 wood 목표 embedding 일치, 연속 프레임/행동 정렬,
