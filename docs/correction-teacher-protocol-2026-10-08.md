# 교정 시연 수집 조건 — 2026-10-08

사용자 승인 후 학습용 막힌 출발 월드 104743/104759에서 각 1회, 제어 시간 최대 180초로
명시적인 scripted teacher를 실행한다. 기존 스냅샷을 복원하며 원본 월드를 수정하지 않는다.
첫 월드는 정방향, 둘째는 z축 반전이다. 최종 평가/개발 월드에 교사를 실행하지 않는다.

교사는 서버 위치·ray hit·알려진 장애물 끝 좌표를 사용하는 privileged controller다.
벽에서 한 블록 뒤로 이동한 뒤 끝을 돌아 나무를 캐고 실제 인벤토리 증가에서 즉시 종료한다.
이동/시점/공격은 MineRL의 실제 물리 행동이며 순간이동·아이템 지급 명령은 쓰지 않는다.
이 결과는 학습 정책 성공이 아니며 PPO 데이터로 사용할 수 없다.

기존 STOP gate·입력 해제·프로세스 소유권 정리를 그대로 사용한다. 화면 PNG와 실제 전송된
행동, 행동 전후 서버 상태, wood-potential-v4의 행동 전 RM context를 기록한다.
성공뿐 아니라 실패·중단 원본도 보존한다. 성공·입력 해제·PID 정리·전이 정렬 검사를
통과한 경우에만 교정 시연 후보로 등록한다. 이 단계에서는 BC를 실행하지 않는다.
두 세션 모두 train 원천이며 이후 BC에는 별도 개발 세션과 목표 embedding/행동 양자화
검증이 필요하다. 이 시연 자체의 서버 관측을 영상 전용 학생의 입력으로 사용하지 않는다.
