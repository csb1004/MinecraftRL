# 현재 시점 입력의 공통 이동 학습 결과

`results/common-navigation-current-pose-20261017/final-verification.json`에서
6개 실제 실행/3,160행동, 초기 조건과 정책 코드/JAR의 쌍별 일치, 행동·logp·보상·value 재생,
STOP 이후 행동0, 입력 해제, 소유 자식 PID 종료를 검증했다. 재사용 train-a450행동은 새 실행에
중복 계산하지 않았다. 원문 연구 명세 SHA256은 바뀌지 않았다.

3개 학습 시드의 현재 시점 관측에서 정답1,384개를 만들고 704개 실제 optimizer update를
보존했다. 학생 방문 상태1,030개와 교사 행동354개이며 원본 행동/logp를 고치지 않았다.
동결 root와 value 보존, actor 변경, checkpoint 재로딩 오차0, expert 정답 재생 감사 통과.
학습242.669초, GPU peak allocated449.600MiB이다. 이는 전체 게임 GPU 사용량이 아니다.

목표6개는 같은 실행 내 연속 과업이다. 12개 독립 실험으로 해석하지 않는다.
10/12 최소 기준과 월드별 비악화, 총 성능 개선을 모두 통과하지 못했다.
`acceptance.json`의 passed=false를 보존하며 기본 모델은 교체하지 않았다.
학습 NLL8.8470→5.7719, 별도 monitor NLL8.6902→5.4756 감소는 게임 개선의 증거가 아니었다.

후보는 두 개발 월드의 목표12개 모두 양쪽 좌표가 반경 안에 들어온 시점이 있었다.
하지만 가까이에서 이동·점프가 재발하고 일부 목표는 도착이 늦어 12틱 안정 조건을 유지하지
못했다. 후보 점프18회, 기준1회였다. 이는 알려진 평지에서 얻은 실패 근거이며 일반 지형에서
점프를 제거해야 한다는 의미가 아니다. `development-a-diagnosis.json`,
`candidate-b-diagnosis.json`, `baseline-b-diagnosis.json`에 목표별 증거가 있다.

후속은 [거리 입력·실제 명령 BC 분리 비교](common-navigation-conditioning-study-2026-10-17.md)다.
같은 train 자료와 초기 정책 함수에서 두 요인을 각각 바꾸어 실제 가중치를 학습한다.
개발 실패 자료를 gradient로 사용하지 않으며 예약 최종 시드는 건드리지 않는다.
실험 월드가 반복 사용된 개발 환경이라는 한계, privileged 좌표 입력이라는 조건을 유지한다.
