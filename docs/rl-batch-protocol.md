# 다중 시드 첫 RL 배치 — 2026-10-05

목표는 원목 최소1개 자연 획득이며 행동 공간은 기존 STEVE-1 키·마우스 출력 그대로다. 인벤토리 정리나 제작에 대한 새 학습 목표를 추가한 실험은 아니다. 영상·순환 backbone을 고정하고 행동 출력층·가치함수만 학습한다.

## 시작 상태와 시간

시드별 새 월드를 생성하고20개의 중립 단계 후 정상 저장·종료한다. 저장 파일 SHA256과 시드를 검증하고, 같은 파일을 매 실행 별도 임시 폴더에 복원한다. 플레이어 UUID는 시드에서 결정해 스킨과 저장 인벤토리의 변화를 방지한다. 정책 기억은 초기화하고 저장된 같은 `collect wood` 임베딩을 사용한다. 행동 샘플링 난수는 정책 초기화가 끝난 뒤 시드로 다시 설정한다.

복원 후60개 중립 tick을 고정 적용한다. 이 구간은 정책 학습 transition이나 제어 시간에 포함하지 않으며 별도로 기록한다. 전역 렌더 작업 대기열은 `warmup.json`에 기록하되, 현재 화면 완료의 필요충분조건으로 취급하지 않는다. 실제 시작 픽셀, 서버 위치·인벤토리·월드 시간, 관측 생명 상태, 정책 초기 기억·임베딩·샘플링 시드의 일치를 직접 검사한다. 두 진단 실행이 이를 통과해야 학습 배치를 시작한다. 검증용 각 전후 쌍에도 같은 검사를 적용한다.

정책 행동마다 실제 서버 tick 차이가1인지 검사한다. 감사에서는 저장된 이벤트의 월드 시간 차이도1인지 독립적으로 확인한다. 정책 제어 시간은 첫 추론을 포함한 현실 시간180초 상한이다. 첫 GPU 계산의 초기화 지연을 숨기지 않는다. 게임 진행량은 tick 및 명목상 tick/20초로 별도 보고한다. 중립 준비·입력 해제는 정책 행동 수에서 제외한다.

동일한 초기 상태가 전체 미래 rollout의 결정성을 보장하지는 않는다. 실제 반복 시험에서 시작 화면은 같았지만 이후 일부 화면·행동이 달랐다. 소수 시드의 전후 결과를 인과적인 일반 성능 향상의 증거로 과장하지 않는다.

## 데이터 분리와 업데이트

- 학습 시드:104729,104743,104759. 직전 파일럿 체크포인트로 각1회 수집.
- 검증 시드:2000003,2000029. 학습 전후 각1회. 개선·퇴행 관찰용이며 학습 데이터에서 제외.
- 최종 평가 예약:3000017,3000029,3000047,3000061,3000073. 이번 배치에서는 실행하지 않음.
- 이전5개 평가 시드는 이미 결과를 살펴봤으므로 회귀 검사용 기록으로 유지.

세 학습 episode를 하나의 on-policy 배치로 합치되, 각 episode의 terminal/truncation과 bootstrap을 분리하여 GAE를 계산한다. 성공뿐 아니라 유효한 시간 초과도 포함하고 취소·기술 오류는 거부한다. 서로 다른 행동 체크포인트나 임베딩이 섞이면 업데이트를 거부한다. 실제 수집 확률과 재계산 확률의 최대 오차는0.0002 이내여야 한다.

실제 데이터에서 batch16 GEMM의 수치 오차가0.00022554로 확인됐지만, 수집과 같은 단일 transition 형태에서는452개 모두 오차0이었다. 허용값을 늘리지 않고 각 transition의 정책 forward 형태를 유지한 뒤 gradient를 minibatch16 단위로 합산한다. 최초 중단은 optimizer0회이며 원본 기록을 보존하고 같은 데이터로 재개한다.

이전 optimizer 상태에서 재개하며2 epochs, minibatch16, 학습률1e-5, PPO clip0.2, gamma0.99, lambda0.95, gradient clip1을 유지한다. KL 계수0.01의 기준은 이번 배치를 수집한 시작 actor다. 이 국소 정규화만으로 장기 인간다움이 보존된다고 주장하지 않는다. 평가 시에는 체크포인트를 갱신하지 않는다.

## 실행과 감사

Windows PowerShell에서 프로젝트 `src`를 PYTHONPATH로 두고 `scripts/run_rl_batch.py --prepared <initial-world.zip>`를 실행한다. 내부에서 기존 소유 프로세스 감시기를 사용해 WSL 격리 환경을 순차 실행한다. 수동 STOP은 자동으로 해제하지 않으며, 기술 오류나 초기 상태 비교 실패가 발생하면 배치는 중단된다. 유료 자원·Colab 연결·외부 API·GitHub 전송은 없다.

완료 후 WSL의 `scripts/audit_rl_batch.py <batch-folder>`로 실제 전달 행동, 최초 서버 보상, 종료 이후 전달 차단, tick, 학습/평가 분리, optimizer 누적 단계, 체크포인트·초기 월드 무결성을 감사한다. 실행별 GPU 메모리, 추론·제어 주기 중앙값/95백분위와 획득량은 원본 summary/events에 유지한다. 최종 판정과 원 연구 명세의 해시는 별도 검증 기록으로 남긴다.
