# 원목 단계 RM·거리 shaping 연결 실험

사용자 승인: 탐색→접근→채굴→수집 단계, 목표 거리 변화 및 게임 틱 비용.
기존 연구 명세·최종 평가 시드는 유지한다. 이번 실험은 배선·보상 감사용이며 정책 개선 검증과 구분한다.

## 고정 정의

- CLI `--reward-mode wood-potential-v1`; 기본 sparse 모드는 유지.
- 실제 서버 인벤토리 첫 원목 획득 +1, 즉시 중단. 종료 후 새 행동 금지.
- 서버 눈 위치와 중심 시선 ray 16블록으로 처음 확인한 원목 하나를 잠근다.
  시야 전체 영상 탐지기가 아니며 서버의 privileged 보조 관측이다. 좌표는 actor에 직접 넣지 않는다.
- 접근: 목표 중심까지 눈 위치의 3차원 직선거리. 채굴: 4블록 이내이며 중심까지 시선이 막히지 않음.
  회전 정렬/실제 공격 여부를 의미하지 않는다. 통과 비용이나 경로 거리가 아니다.
- 원목이 사라지면 수집 후보 단계. 최대 40틱 동안 파괴 위치 중심까지 거리를 사용한다.
  실제 아이템 entity 위치나 플레이어가 직접 파괴했다는 증거가 아니다.
  목표에서 32블록 이상 멀어지거나 수집 유예가 끝나면 탐색으로 돌아간다.
- 잠재값: 탐색 0, 접근 .1+.3*(1-min(d,16)/16), 채굴 .5,
  수집 .6+.3*(1-min(d,16)/16), 실제 종료 0.
- 보조 보상 `.2*(.99*Phi(next)-Phi(current))`, 틱 비용 `-.0001`.
  각 정책 행동의 실제 server tick 차이가 1인지 검증한다. 준비·정리 입력은 제외한다.
- 시간 초과는 truncation: 잠재값을 0으로 만들지 않고 최종 RM 입력으로 value bootstrap.
  실제 done/획득은 terminal: 잠재값과 bootstrap 모두 0.
- 총 보상/획득/거리·단계 shaping/시간 비용을 별도 저장. 순수 shaping은 완전한
  할인 종료 궤적에서 상쇄되므로 더 좋은 최적해를 새로 만드는 것이 아니라 학습 신호를 바꾼다.
  시간 비용은 실제 목적을 바꾼다. 사망으로 비용을 회피하는 행동 가능성은 별도 비교가 필요하다.
- 정책·value 입력에 단계 one-hot 5개와 정규화 거리 1개를 추가한다.
  기존 head의 추가 열은 0으로 초기화한다. 행렬 크기가 달라져 미세 수치 차이는 가능하다.
  frozen 영상/recurrent backbone 및 행동 공간은 그대로다. 이 버전은 privileged context 정책이다.
- PPO gamma .99/lambda .95 고정. 다른 shaping 계수·할인 target bundle 혼합을 차단한다.

## 검증 순서

경계 단위 테스트→Windows/WSL 회귀→별도 JAR 실제 컴파일→기존 학습 시드104729에서
최대180초 연결 수집→원시 보상/행동/정지 감사→조건이 유효하면 한 epoch 시험 업데이트.
저장 체크포인트의 실제 재실행은 기존 개발 시드2000003의 저장 월드에서 최대180초로
확인한다. 같은 월드에서 별도5초 제한 실행은 time-limit bootstrap 진단으로만 기록하고
과업 성공률 비교에 넣지 않는다. 이는 성능 비교 배치가 아닌 연결 검증 범위다.
최종 평가 시드와 이전 개발 평가 궤적은 학습에 사용하지 않는다.
배선 실험 후 실제 장애물 배치의 양방향 비교와 다중 시드 학습/평가는 별도 기록한다.
계수는 최적값이 아니며 획득률/효율 개선을 이 시험만으로 주장하지 않는다.

## 시간 비용 목적함수 수정: v2

v1 시험 뒤 할인 반환값을 직접 계산했다. gamma .99와 틱 비용 .0001이면
1000틱 성공의 task+time 반환값은 약 -.009956으로, 보상 없이 즉시 실패하는 것보다
작아질 수 있다. v1 원본 수집·7회 업데이트·개발 평가·5초 진단은 그대로 보존한다.

`wood-potential-v2`는 실제 environment done이고 획득이 없는 경우에만 failure=-1을
추가한다. 사용자 STOP·기술 오류는 학습 제외, 시간 초과는 bootstrap이며 이 비용을
적용하지 않는다. 성공과 실패가 동시 관측되면 실제 획득을 우선한다.
나머지 거리/단계/틱 비용/입력은 같다. v1 체크포인트의 6개 context 입력을 그대로
옮길 수 있으며 source checkpoint reward mode를 따로 기록한다. v1/v2 학습 데이터 혼합 금지.

같은 초기 잠재값에서 task+time의 완전한 할인 반환값은 성공이면 -.01보다 크고,
실패이면 -.01보다 작다(유한 tick, gamma .99, 실패 비용1). 따라서 이 단순 과업에서는
틱 비용을 피하려는 조기 실패가 성공보다 유리한 목적함수 문제를 제거한다.
함수 근사·탐색·truncation bootstrap 오차까지 해결했다는 뜻은 아니다.
수정 버전은 학습 시드104729 저장 월드에서 별도 수집 후 한 epoch로 연결을 재검증한다.
v2 실패 종료 분기는 단위 테스트로 검증하며, 실제 사망 유발 실험은 하지 않는다.
