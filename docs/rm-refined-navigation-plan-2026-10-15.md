# 보강 이동 정책의 RM 실행 연결

상태: 실제2게임 종료. [결과·검증 기록](rm-refined-navigation-validation-2026-10-15.md).
far 감사 통과·corner 재감사 timeout 미완료. 사용자 요청으로 기록 후 중지하며
다음 수집/학습은 실행하지 않는다.

사용자 승인 후 수행하는 다음 개발 단위다. 기존 계획과 장기 연구 명세를 유지한다.
현재 근거는 독립 이동 PPO10/12도착이며, 기존 RM executor는 이전6차원 모델만 읽는다.

1. RM executor가 명시적으로 바인딩한 기존/보강 체크포인트를 모두 읽게 연결한다.
   보강 정책에는 실제 직전 committed 전이의 이동/회전과 남은 tick 예산을 넣는다.
   root/다른 skill/대기에는 목표 입력을 해제하고 기존 정책과 기억을 유지한다.
2. 실패 재현 검사 후 구현하고, 저장 입력을 원시 관측·계획 예산으로 독립 재구성해
   행동 확률과 RM/목표 종료/STOP를 감사한다. 구형 체크포인트 호환도 유지한다.
3. 기존 blind-recovery 개발 far/corner에서 새 결과 디렉터리로 각1회 실행한다.
   seed104761, sampling14031, 제어180초, 계획 최대2회, 이동100tick/20초.
   공급자는 기존 고정 계획이며 API0이다. 실제 정체 후 이동→찾기→접근→root를 실행한다.
   미호출/미실행은 실패 분모에서 제외하고 완료된 이전 배치는 재실행하지 않는다.
4. 근접 재이탈은 정밀 도착 문제 가설로 기록한다. 이 실험은 새 학습이나 도착 반경 확대가
   아니며, 모델 연결과 실제 과업 재개의 효과를 먼저 분리한다. 실패가 남으면 train 쪽의
   근거리/역방향 보강을 다음 원인 기반 단위로 정리한다.

원문·가중치·원본 월드·기존 궤적은 해시로 보존한다. 기본 정책 승격·최종5시드·유료 호출·
Colab·GitHub 공개0. 사용자 지침에 따라 원래 경로에서 순차 실행하며 서브에이전트를 쓰지 않는다.
