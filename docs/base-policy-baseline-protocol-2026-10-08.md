# 원본 정책과 로컬 학습 영향 분리

사용자가 승인한 기본 행동 학습 진단의 첫 단위. 새 학습0, 최종5시드 미사용.
원본 STEVE-1의 능력과 로컬 학습/실행 경로의 영향을 구분하며 이번 소규모 비교만으로 일반 능력을 단정하지 않는다.

## 먼저 실행 경로 대조

`base-policy-parity-20261008`: 기존 개발 긴 벽/자연 기록의 첫64프레임씩을 순차 입력한다.
실제 게임을 새로 제어하지 않으며 평가 프레임에 optimizer를 적용하지 않는다.
공식 policy.act의 전처리/CFG6/초기 기억과 로컬 RLPolicy.features/guided/행동 변환을 대조한다.
feature 최대오차, recurrent 상태, 같은 RNG의 환경 행동, 버튼/카메라 분포 TV를 기록한다.
FP16/FP32 head 계산과 RM0열 확장을 별도로 대조해 수치 차이를 구조 오류로 혼동하지 않는다.

예측: 실행 경로 자체에 큰 오류가 없다면 동일 원본 모델의 표현/기억이 일치하고,
head 정밀도를 맞춘 분포 차이가 제거되거나 매우 작아야 한다. 이것만으로 게임 능력을 인정하지 않는다.
원본 head에 RM6열0을 추가하고 value0을 붙인 체크포인트를 별도 보존한다. pretrained 학습가중치는 변경0.
표현/기억 불일치 또는 정밀도로 설명되지 않는 큰 분포 차이가 있으면 게임 전에 진단한다.

## 실제 개발 비교

경로 대조 후 기존 긴 벽2000003과 자연2000029의 같은 불변 월드를 사용한다.
원본: 위 체크포인트. 로컬: `recovery-gap-20261007/train-gap-epochs2/checkpoint.pt`.
둘 다 동일 로컬 FP32 head 추론/고정wood embedding/CFG6/샘플링seed=월드seed,
RM wood-potential-v4, eval split, 실행당 제어최대180초. 원본은 추가 RM열0이라 RM입력에 반응하지 않는다.
이는 로컬 학습된 head와 RM 연결의 합산 효과를 비교하며 두 효과를 독립 분리한 실험은 아니다.

순서: 긴 벽 원본→로컬, 자연 로컬→원본. 각1회, 총4회 새실행. 기존 완료 배치 재실행 금지.
초기 서버/기억/픽셀 일치, 실제 서버 원목 획득, 이동·시점·점프·중앙벽 공격·통로 진입,
GPU/추론/제어 지연, STOP후dispatch0·키0·소유PID0을 확인한다.
초기 픽셀이 다르면 해당 쌍의 인과/시간 비교는 부적격으로 보존하고 성공할 때까지 재실행하지 않는다.
이 두 과업은 기본행동 전체에 대한 독립 벤치마크가 아니므로 각각의 기능을 모두 검증했다고 주장하지 않는다.

예측: 원본도 같은 벽에서 정체되면 로컬 학습이 실패의 유일한 원인이라는 가설은 약해진다.
원본이 통과하고 로컬이 실패하면 학습/조건 편향이 원인 후보가 되며 추가 반복·요인 분리가 필요하다.
같은 기록 화면에서의 확률 분석은 다른 정책이 실제 방문했을 상태를 대신하지 않는다.

기본 정책 승격/전체 모델 RL/새 대규모 데이터 수집/유료GPU/Colab 연결은 이번 단위에 포함하지 않는다.
RM 보존·우선순위 변경 합의와 장기 연구 목표는 유지한다.

## 게임 종료 후 시간 문맥 학습 가능성 검사

별도 폐기용 probe를 추가한다. 승인된 temporal 부분 학습 경로의 자원·gradient 검사이며 성능 실험이 아니다.
train104743의 보강 교사 시연 첫8프레임만 사용, 개발/평가 영상으로 학습하지 않는다.
동결 prefix를 순차 실행해 마지막 recurrent block 입력을 저장한 뒤 prefix는 CPU로 옮긴다.
마지막 recurrent block+lastlayer/final_ln+head만 GPU에서 학습 가능하게 둔다.
같은 순차 입력의 특징 재현 오차<1e-5, 마지막 프레임 변경 시 앞7프레임 영향0,
마지막 프레임 BC loss에서 앞 프레임 입력까지 gradient>0, recurrent parameter 실제변경>0을 확인한다.
AdamW lr1e-6 1회만 실행하며 peak메모리/오류를 기록하고 배포용 체크포인트는 저장하지 않는다.
게임과 동시에 실행하지 않는다. 성공해도8프레임 경로의 가능성만 확인한 것이며,
긴 문맥 학습·RL·게임 성능 개선은 별도다. OOM이면 해당 실행을 보존하며 성공으로 보고하지 않는다.
