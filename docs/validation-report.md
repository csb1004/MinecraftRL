## 결론

문서와 전달용 정책 검증 프로젝트를 작성했다. **사용자 Windows PC에 설치한 상태는 아니며, 실제 Minecraft rollout은 0회다.** GTX 1060 3GB에서의 실행 가능성, STEVE-1 지시 수행 가능성, 버킷 서버 호환성은 미검증이다.

## 차단 원인

실제 클라우드 점검에서는 Python 3.12.14, Java 21, numpy 2.3.5를 관측했다. torch/gym/gym3/MineRL 및 nvidia-smi가 없고 DISPLAY도 설정되지 않았다. 외부 실행 checkout과 가중치 receipt도 없는 상태였다. 이는 **사용자 Windows 환경 조사 결과가 아니다.**

원인별 JSON과 실행 요청은 `docs/evidence/cloud-vpt-*`, `docs/evidence/cloud-steve1-*`에 보존했다. 최종 suite 기록 기준 VPT는 첫 시드 사전 점검 차단 뒤 4개 미실행, STEVE-1 wood는 첫 시드 사전 점검 차단 뒤 4개 미실행, dirt 5개는 미실행이다. 개별 진입점 점검 기록은 별도이며 실게임 표본으로 합산하지 않는다.

유효 gameplay 분모가 0이므로 지시 과업 실패율/성공률과 실제 추론 지연·획득량·GPU peak는 보고할 값이 없다. blocked attempt의 기술 실패율을 정책의 게임 실패율로 해석해서는 안 된다.

## 독립 리뷰와 수정

독립 리뷰에서 아래 3개 문제를 발견했다. 수정 전에 각 문제를 재현했으며 수정 후 전체 15개 테스트를 통과했다.

1. 정상 시간 제한이 공유 STOP을 생성해 다음 시드를 중단함 → 자동 deadline과 사용자 STOP을 분리. 5개 연속 합성 episode 검사.
2. MineRL은 Java를 setsid로 분리하므로 worker killpg만으로 남을 수 있음 → Linux subreaper/PID+시작 시각 기반 소유 자식 추적. 분리 세션 자식 종료와 기존 무관한 자식 생존 검사.
3. MineRL done 뒤 중립 step은 오류 → terminal cleanup을 별도 상태로 기록하고 추가 step 없이 닫기.

추가로 실행 차단 시 아직 시도하지 않은 STEVE-1 조건이 집계에서 누락되는 문제를 테스트로 재현하고 unrun 항목으로 남기게 수정했다. 미해결 중요 리뷰 지적은 없다. 수정 후 두 번째 독립 리뷰는 하지 않았으며 실제 MineRL 연결 계약은 계속 미검증이다.

## 남은 실행

1. 지정 Windows 경로에 설치 후 read-only PC/WSL CUDA/렌더링 점검.
2. 프로젝트별 후보 환경 설치, MCP 빌드, import/reset/act 확인. 성공 시 explicit conda 목록/pip freeze/빌드 patch/모델 해시를 보존한다.
