# 가치함수 교정 실행 조건 — 2026-10-06

사용자가 원인 분석의 해결 방안 실행을 승인했다. 기존 정책의 행동 공간, 서버 보상/완료, 180초 제한과 최종 평가5시드를 유지한다.

1. 확대 배치의 학습8시드×2개 궤적만 사용한다. 검증2시드와 최종5시드는 fitting/설정 선택에서 제외한다. 부모78회 checkpoint의 critic이 비교 기준이다.
2. 실제 할인 return(gamma=.99)을 계산한다. terminal bootstrap0, 유효 truncation은 기록된 bootstrap, 취소/기술 실패는 제외한다. 새 정책 수집은 이 검사에서 하지 않는다.
3. 각 시드를 두 궤적 모두 통째로 제외한8분할에서, 나머지7시드로 frozen feature의 선형 value를 fitting한다. 기존 value의 잔차를 예측하고 학습분할만으로 특징을 중심화/표준화한다. 고정 ridge=1, mean squared residual + ridge*weight norm², bias는 비규제. hyperparameter 탐색은 하지 않는다. 기존 value 및 각 fold의 학습 return 평균을 기준선으로 비교한다.
4. 통과 기준을 결과 전에 고정한다: 전체 제외 표본 MSE가 두 기준선보다 각각10% 이상 낮고,8시드 중6개 이상에서 inherited value보다 낮아야 한다. 획득까지100행동 이상 남은 구간 MSE도 inherited보다 낮아야 한다. 모든 출력 유한성과 데이터 분리 검사를 통과해야 한다.
5. 통과하면 critic 교정 한 요인의 정책 학습 비교로 진행한다. 통과하지 않으면 새 actor 학습을 시작하지 않고 표현력/표본 잡음/분할 편차를 조사한다. 실패 결과를 숨기거나 검증 시드를 fitting에 넣지 않는다.

Ruling: 고정 ridge 잔차 회귀를 첫 fitting 방법으로 선택했다. 작은 선형 critic을 수치적으로 안정하게 비교하고 학습률/epoch 탐색을 피한다. 선택이 나쁘면 이 방법의 실패이지 critic 개선 불가능이라는 결론은 아니다.

Ruling: 기존 경로에서 주스레드로 실행·리뷰한다. 사용자 지침에 따라 subagent/worktree/Git 초기화/푸시를 하지 않는다. 기존 실험 파일을 덮어쓰지 않고 새 결과 폴더에 기록한다.

첫 결과: ridge 선형 교정은 전체 OOF MSE .128362→.050899,7/8시드 개선이지만 초반 MSE .014104→.077411로 악화해 gate 실패. 정책 학습에 사용하지 않는다.

Ruling: 표현력 후보를 정확히 하나 추가한다. 같은8분할/동일 target으로64-unit ReLU hidden layer와 sigmoid 출력의 작은 MLP를 비교한다. 학습 fold 전용 표준화, AdamW lr.001/weight_decay.01, minibatch256,20epoch, gradient clip1, seed40321을 사전 고정한다. epoch 선택에 제외 fold 결과를 쓰지 않는다. 동일 gate를 유지하며 이 후보의 fitting만 실행한다. 후보 선택이 나쁘면 representation 불가능의 증거는 아니며, 조건을 낮춰 actor 학습을 강행하지 않는다.

비선형 결과:1,820회 value-only optimizer step, actor0. 전체OOF MSE .063237,7/8시드 개선이지만 초반 .100844로 gate 실패. 양쪽 후보 모두 고정 정책으로 유지한다.

Ruling: 모델을 더 늘리기 전에 세계 다양성의 부족을 검증한다. 새 학습 시드를104827,104831,104849,104851,104869,104879,104891,104911로 실행 전에 고정한다. 각 세계를 준비하고 부모78회 actor/같은 embedding으로1회씩 최대180초 수집한다. 유효 실패/시간초과도 보존한다. 원16개와 새8개, 총16세계24개 궤적에서 같은 두 fitting 방법을 다시 비교한다. gate는 그대로 두되 개선세계 수 기준은75%인12/16으로 적용한다. 새 데이터에서도 실패하면 actor 학습을 강행하지 않는다. 최종5시드와 검증2시드는 fitting/설정 선택에서 제외한다. 이는 새 정책으로 학습한 라운드가 아니라 actor를 고정한 진단 데이터 확장이다.

해석 명확화(확대 fitting 전): 코드의 초반 구간 정의는 `remaining_episode_steps >= 100`으로 그대로 유지한다. 새 시간 초과 궤적에서는 이것이 ‘획득까지100행동’이 아니라 ‘수집 종료까지100행동’이다. truncation target은 기록된 기존 critic의 bootstrap을 포함한 추정치이며 관측만으로 확정한 전체 미래 return이 아니다. terminal/시간 초과를 별도 집계한다. 결과로 정의한 이 구간은 낮은 return을 선택하는 편향이 있어, 해당 gate 실패만으로 critic 또는 actor의 인과적 결함을 확정할 수 없다. 기존 보수적 채택 기준을 낮추지는 않는다.

측정 환경 기록: 수집 중 전체 테스트나 tensor 분석/fitting을 병행하지 않았다. 다만 상태 조회, 파일 읽기·목록 검색, 새 분석 스크립트 편집은 수행했다. 특히 두 번째 세계의 초기화 무렵 `rg --files`가 results 하위까지 열거해 수십 초 걸렸다. 첫 추론과의 정확한 중첩 시간 및 지연 기여는 계측하지 않았다. 해당 시간 초과 표본을 버리거나 재실행하지 않으며, 제어 시간/추론 지연은 완전히 격리된 하드웨어 벤치마크가 아닌 로컬 관측값이다. 새 세계 및 기존 세계의 분할은 이번 fitting에서 제외했다는 뜻이고, 부모 정책의 이전 학습 또는 공개 사전학습 전체에서의 미노출을 증명하지 않는다.

확대 결과: 새 8개 정상 수집은 성공 7회·시간 초과 1회·기술 실패 0회, 총 자료는 4,855행동이다. 선형 OOF MSE .056771, 15/16세계 개선, 초반 .066668; MLP MSE .057850, 14/16세계 개선, 초반 .067844. 기존 초반 .015243보다 모두 커서 두 후보 모두 gate 미통과다. 기준을 변경하지 않았고 actor 추가 갱신·실행 정책 교체는 0이다. 총 진단 MLP 갱신 7,660회, 선형 풀이 26회다. 조건부 다음 단계인 actor 비교/추가 on-policy 라운드는 미실행이다.
