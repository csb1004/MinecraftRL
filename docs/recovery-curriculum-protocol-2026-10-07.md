# 복구 행동 학습 — 짧은 우회에서 긴 우회로

이전 bedrock 평가 실패는 보존하며 그 궤적/월드는 학습에 사용하지 않는다. 기존 훈련 시드
104743/104759의 초기 자연 월드를 읽어 독립 시험장 ZIP을 만들고, 평가에는2000003/2000029의
초기 월드에서 만든 다른 ZIP을 사용한다. 최종5시드는 계속 미실행이다.

훈련1: 벽 x=7,z=1..3, 우회 통로 z=4. 왼쪽/오른쪽은 전체 z축 반사로 바꾼다.
훈련2: 같은 훈련 시드에 독립 ZIP, 벽 z=1..5. 평가: 다른 시드, 벽 z=1..7.
바닥/높이/원목/인벤토리 조건은 기존 시험장과 같다. 다른 geometry의 ZIP을 덮어쓰지 않는다.
이는 합성 장애물 curriculum이며 자연 세계 일반화를 입증하는 설계는 아니다.

정책은 STEVE-1 v2 head에서 시작해 wood-potential-v4 문맥을 사용한다. 물리 행동 공간,
embedding, frozen vision/recurrent, 보상·200tick 정체 정의는 고정한다. 직접 우회 행동을
주입하거나 평가 자료를 재분류하지 않는다. 짧은 벽을 정체 진입 전에 통과한 경우는 우회
경험으로만 세고 ‘정체 후 복구’ 경험으로 세지 않는다.

각 훈련 단계에서 동일 behavior checkpoint로 두 시드를 각1회, 최대180초 수집한다.
단계 내 하나 이상 실제 원목 획득이 있어야 PPO를 수행하고 다음 단계로 넘어간다. 획득이
없으면 최대2회만 같은 훈련 조건을 추가 수집한다. 그래도 없으면 난도를 올리지 않고
수집 실패/학습 미실행을 보고한다. 반복 시 source/체크포인트/월드 해시와 결과를 모두 남긴다.
학습 전 실제 보상·feature 문맥·STOP 감사가 통과해야 한다. 실패 궤적도 정상 시간 제한이며
동일 behavior 조건이면 함께 사용하고, 사용자 중단/기술 오류는 제외한다.

PPO는 기존 설정 lr1e-5, gamma.99, lambda.95, clip.2, reference KL 계수.01,2epoch,
batch16. 단계마다 실제 수집 initial_heads에서 fresh optimizer로 시작한다. 서로 다른
behavior의 단계1/2 데이터를 혼합하지 않는다. 확률 재계산·checkpoint/optimizer 재로딩 검증을 수행한다.
shaping 학습에도 기존 target-bundle 경로와 같은 최종 평균 reference KL≤.03 검사 결과를
노출한다. 초과 시 그 checkpoint를 채택하지 않고 동일 수집 자료로1epoch를 단1회 시도한다.
이 선택은 훈련 자료 지표로만 정하며 평가를 보고 학습 조건을 조정하지 않는다.

가능한 마지막 통과 checkpoint를 고정하고 별도 평가2세계에서 부모와 후보를 각1회 비교한다.
첫 세계는 부모→후보, 둘째는 후보→부모. 둘 다v4 조건이며 초기 상태·픽셀과 최초 행동 분기,
실제 획득·제어 시간/주기·추론 p50/p95·GPU·중단·해제를 기록한다. 시작 편차와 반복1회 한계를
명시하며 기본 정책은 자동 승격하지 않는다. 정체 진입/해제/획득을 각각 세고 문맥 입력의
고정features 개입 효과도 전후 확인한다. 신호 민감도만 커진 것을 성공으로 보지 않는다.

기본 규모는 훈련4회+평가4회이며, 획득 없는 단계의 추가 수집은 단계별 최대2회다.
실행/감사 오류는 원인을 고쳐 해당 미완료 단계부터만 복구하고, 완료된 일회용 배치를 재실행하지 않는다.
