# 연속 복구 시연의 마지막 기억층 BC — 실행 전 고정

승인된 후속 작업: 기존 교사 train6/development2 시연을 그대로 사용해 기억층 학습·저장·추론을
연결하고 실제 우회/자연 수집을 비교한다. 원문 연구 목표/RM/보상과 기본 정책은 유지한다.
실제 LLM 호출·우선순위 전환은 이번 하위 정책 학습과 구분한다.

## 입력과 학습

`configs/diverse-teacher-bc-20261008.json`의2037전이(train1436/development601), 고정 wood
embedding/CFG6, gap 부모를 사용한다. 기존 완료 배치를 재실행하지 않고 마지막 recurrent
block 직전 입력을 새 산출물에 순차 추출한다. 모든 frame/action/분할/해시/서버 연속성을 검사한다.
앞쪽 CNN/목표 결합/기억블록들은 동결하므로 해당 입력 캐시는 학습 중 유효하다.
평가 궤적이나 개발 데이터로 gradient를 계산하지 않는다. privileged RM6 조건은 유지한다.

조건 A: 마지막 표현층+head, 기억층 동결. 조건 B: 마지막 기억블록+표현층+head.
각각 같은 부모/자료/8프레임 창/순서seed9602/1epoch/AdamW lr5e-7/KL계수1/gradient clip1을
사용한다. 창은 episode 경계를 넘지 않으며 마지막 짧은 창도 포함한다(각182갱신 예정).
매 창 시작 전 episode 시작부터 현재 가중치로 기억을 no-grad 재계산한다. 창 안에서는 기억을
detach하지 않아 최대8프레임 gradient를 전달한다. 이는 전체 episode BPTT가 아니다.
참조 KL은 원본 backbone 특징+부모 head로 고정한다. 학습 대상은 미리 GPU로 옮기고 동결
prefix는 CPU/디스크에 둔다. 게임과 학습을 동시에 실행하지 않는다.

## 계약과 게임 진입 기준

캐시의 초기 순차 특징 오차<1e-5, 미래→과거 영향0, 창 안 앞 프레임 gradient>0,
실제 기억 가중치 변경>0(B만), 전체 저장/reload 오차0, 완전 정책 추론과 캐시 경로 일치를 검사한다.
체크포인트는 모델 SHA/기억블록 위치/개수/가중치/표현층/head/고정 value를 명시한다.
기존 head-only PPO 재개는 거부한다. value 가중치 보존은 값 예측 불변을 뜻하지 않는다.
두 조건 모두 개발 NLL 비악화, train KL<=.03, 유한한 값과 위 계약을 통과하면 실제 비교한다.
gate 실패/OOM이면 원본 오류와 측정값을 보존하며 미실행 게임을 성공/실패로 세지 않는다.
이번 단위에서 성공할 때까지 학습률 탐색이나 게임 반복을 하지 않는다.

실제 비교는 개발 긴 벽2000003, 자연2000029 각각 A/B1회, 제어 최대180초이다.
긴 벽 A→B, 자연 B→A. 기존 불변 월드와 sampling seed를 사용한다. 초기 서버/기억/픽셀
불일치는 해당 쌍의 인과·시간 비교를 부적격으로 남기며 반복하지 않는다. 성공은 서버 인벤토리로
판정한다. 획득/이동/통로/실패 원인, GPU/추론 중앙값·p95/제어 주기, STOP 뒤 행동0/키0/소유PID0을
감사한다. 새 후보가 실패해도 API/교사 제어로 대신하지 않는다. 최종5시드는 사용하지 않는다.

자원 부족이 실제 관측되면 로그를 보존하고 같은 자료·분할·가중치·명령의 Colab 실행 준비를 한다.
실제 Colab 연결은 별도 승인 범위다. 단위 완료는 구현/실행 결과를 뜻하며 우회 개선은 실제 결과로
별도 판단한다. synthetic teacher 데이터8episode만으로 일반적인 Minecraft 능력을 주장하지 않는다.
