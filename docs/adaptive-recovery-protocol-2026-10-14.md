# 막힌 방향 기억·원래 수집 재개·유료 LLM 후보 선택

사용자 요청: 다음 실험 실행. 유료 예산은 총 US$1 이하·최대4회 호출로 명시 승인.
기존 연구 명세·원본 가중치/월드/개발 결과 보존. 전역 환경 변경/추가 학습/Colab0.
작업은 주 실행 흐름에서 순차 진행하며 기존 완료 배치는 재실행하지 않는다.

## 고정 실험

10월12일 생성한 두 개발 월드 far/corner의 동일 원본 ZIP을 새 실행 디렉터리에 사용한다.
같은 부모/목표 조건/이동 head, world seed104761, sampling far14021/corner14022.
최종5시드 사용0. 제어180초, 실제 정체 감지 뒤 이동 예산400행동·복구60초를 유지한다.
계획 대기도 제어/복구 시간에 포함한다. 도착반경0.35·높이차1.5는 그대로다.

두 월드×세 조건, 총6게임. 새 경로 `results/adaptive-recovery-20261014` 사용.

1. 기존 `visit_memory`: 방문 셀 선호/실패한 목표 셀 비용, 목표3개 뒤 수집 재개.
2. `adaptive_rule`: 아래 실패 방향 기억과 수집 재개, 후보는 규칙 점수로 선택.
3. `adaptive_llm`: 동일 후보·실패 방향 기억·수집 재개. 최초 정체와 첫 후보 실패 때
   LLM이 허용 후보를 선택한다(게임당 최대2회). 이후 선택은 명시적으로 규칙 방식이다.
   따라서 제한된 LLM+규칙 혼합 조건이다. API 실패/부적합/만료 때 자동 규칙 대체 없이 멈춘다.

LLM에 전달하는 것은 자기 위치/yaw, 방문 이력, 후보, 실제 실패 근거와 원래 원목 목표다.
벽 정답 구조·출구·원목 좌표는 후보 생성/LLM에서 제외한다. 원래 root RM과 접근 여부 검사는
기존 privileged server 관측이다. F3-only/영상 전용 조건으로 주장하지 않는다.
모든 모터 행동은 기존 신경망에서 샘플하며 계획 대기의 중립 release/refresh만 별도 기록한다.

## 구현과 사전 검사

- 실패를 마지막 위치 부근의 이동 방향으로 기록한다. 근처에서 같은 방향의 조금 다른 목표를
  선택해 실패 이력을 우회하지 못하게 한다. 실제 충분히 정렬된 전진인데 위치 변화가 작은
  관측만 막힘 근거로 사용하며, 시선 불일치/정밀 도착 실패를 벽 존재로 단정하지 않는다.
  이 기억은 해당 회차에만 쓰는 관측 기반 가설이며 실제 반대 증거가 생기면 구분한다.
- 관측상 wood interaction_ready이면 원래 RM/기억을 유지하고 수집으로 즉시 돌아간다.
  직접 접근 근거가 없더라도 실제 목표1개 도달과 지속3블록 이탈 뒤에는 제한된 원래 정책
  시험을 허용한다(최대100행동, 두 번). 이것은 접근/과업 완료 선언이 아니다.
  시험에도 접근 회복이 없으면 실패 이력을 보존하고 이동을 재계획한다. 같은 장소의 반복
  시험은 거부하며 전체 제어/복구 예산을 늘리지 않는다.
- LLM 요청 전 실제 중립 입력 해제, 대기 중 정책 행동0, 응답 뒤 관측 refresh 및 STOP/시간/
  위치·회차·후보 유효성을 다시 검사한다. 기존 RM은 삭제/재생성하지 않는다.
- 검증: 이동 실패 vs 방향 불일치, 근처 중복, 성공 이동 반증, 계획 계약/미지원 후보,
  예산 초과·재시작·동시 claim·실패 호출, STOP 전후/대기 중/응답 직후, root probe 실패/성공.

## 유료 범위

기존 MyWife 설정의 `gpt-5.3-codex`와 키를 메모리에서만 읽는다. Responses 표준 요청,
tools0·store=false·출력최대2048token·요청본문최대16KiB·20초·재시도0. 다른 모델로 자동 교체하지 않는다.
[공식 모델 가격](https://developers.openai.com/api/docs/models/gpt-5.3-codex)에서 확인한
입력$1.75/출력$14 per1M tokens를 비용 추정에 사용한다(2026-10-14 확인).
안전한 로컬 예약 한도는 호출당$0.25, 최대4회/합계$1이다. 실패/불명 사용량도 예약을 소비한다.
실제 usage와 추정 비용을 보존하되 청구서 금액과 동일하다고 주장하지 않는다.
키·개인 대화·과거 개인 데이터는 요청/로그에 넣지 않는다. 호출이 불필요하면 예산을 소진하지 않는다.

## 완료 근거

- 각 조건의 실제 국소 이탈/벽 횡단/원목 인벤토리, 미호출 조건 제외, 목표/후보 실패 이력.
- 같은 행동·관측의 오프라인 감사, 원래 RM/기억/가중치·자료 분리, 실제 STOP/해제/소유PID.
- 추론·전체 주기 중앙값/p95, GPU, 계획 시간·호출/usage/비용, 근처 같은 막힌 방향 재시도 횟수.
- root prefix 화면/행동이 달라지면 인과 개선 주장 금지. 소수 개발 진단을 일반 성능으로 해석 금지.
- 원본 로그·기술 오류 보존, 문서/작은 결과 자료 갱신. 기본 정책·실행 vocabulary 자동 승격0.
