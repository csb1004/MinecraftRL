# 가치함수 교정 해결안 실행 결과 — 2026-10-06~07

두 교정안을 실제 fitting하고 새 학습 세계 8개를 수집해 다시 비교했다. **전체 예측 오차는 감소했지만 초반 구간 비악화 기준은 네 비교 모두 미통과했다.** 새 actor 학습이나 기본 정책 승격은 하지 않았다. 정책 성능 개선이 입증되거나 근본 원인이 해결된 상태는 아니다.

사전에 정한 조건은 [실행 프로토콜](rl-value-repair-protocol-2026-10-06.md), 이전 근거는 [원인 분석](rl-root-cause-2026-10-06.md)에 있다. 이 단계는 장기 연구 목표와 행동 공간을 유지한 선행 진단이다.

## 실행한 변경과 데이터

- 새 `rl_value.py` 모듈에 terminal/truncation 할인 return, 세계 단위 분할, 잔차 ridge 교정과 채택 기준을 구현했다. 기존 게임·보상·actor 학습 경로에는 연결하지 않았다.
- 고정 ridge=1의 선형 잔차 회귀, 2048→64→1 ReLU/sigmoid MLP를 비교했다. MLP는 AdamW lr=.001, weight decay=.01, 20 epoch, minibatch 256, seed 40321이다. hyperparameter 탐색이나 제외 세계를 이용한 epoch 선택은 하지 않았다.
- 같은 세계의 반복을 모두 제외하는 leave-one-world-out 방식이며, 표준화와 fitting은 나머지 세계만 사용했다. 검증 2시드와 최종 5시드는 사용하지 않았다. 부모 정책의 모든 과거 학습까지 미노출인 분할이라는 뜻은 아니다.
- 부모 78회 체크포인트를 고정해 새 8세계에서 각각 한 번 수집했다. 기존 정상 16개와 새 정상 8개를 합쳐 **16세계·24개 궤적·4,855행동**이다. 새 표본은 1,706행동, 성공 7/8, 시간 초과 1/8이다. 세계 준비 8회는 성능 표본이 아니다.
- 이번 새 수집의 기술 실패·재시도는 0회다. 이전 확대 배치의 기술 실패 1건은 [기존 결과](rl-expanded-validation-2026-10-06.md)에 계속 남아 있으며, 이번 24개를 과거 전체 시도의 24/24 성공으로 해석하지 않는다.
- 이번 **actor 갱신은 0회**, 진단용 MLP optimizer 갱신은 총 **7,660회**, 선형 풀이 총 26회다. 진단 checkpoint를 실행 정책으로 사용하지 않았다.

## 교차 검증 결과

MSE는 낮을수록 좋다. 평균 기준선은 각 fitting 분할의 target 평균이다. ‘초반’은 코드상 `remaining_episode_steps >= 100`이며 시간 초과 궤적에서는 획득까지의 거리를 뜻하지 않는다.

|비교|기존 MSE|평균 기준선 MSE|교정 MSE|초반 MSE: 기존 → 교정|개선 세계|채택 기준|
|---|---:|---:|---:|---:|---:|---|
|8세계 선형|0.128362|0.084276|0.050899|0.014104 → 0.077411|7/8|미통과|
|8세계 MLP|0.128362|0.084276|0.063237|0.014104 → 0.100844|7/8|미통과|
|16세계 선형|0.123595|0.078212|0.056771|0.015243 → 0.066668|15/16|미통과|
|16세계 MLP|0.123595|0.078212|0.057850|0.015243 → 0.067844|14/16|미통과|

전체 MSE가 두 기준선보다 각각 10% 이상 낮고, 세계의 75% 이상에서 개선하며, 초반 MSE도 기존보다 낮아야 한다는 기준을 유지했다. 확대 비교의 두 후보는 앞의 두 조건은 만족했지만 마지막 조건에서 미통과했다. 결과를 본 뒤 기준을 낮추거나 후보를 추가하지 않았다.

### 달라진 학습 신호와 남은 문제

초반 2,500행동의 정규화 advantage 양수 개수는 기존 **26 → 선형 995 / MLP 1194**였다. 거의 전부 음수였던 편중은 줄었지만, 양수 비율 증가가 좋은 행동을 학습한다는 증거는 아니다. 이는 OOF value를 넣은 저장 데이터 계산이며 실제 actor 업데이트가 아니다. gamma=.99, lambda=.95, 전체 24개 궤적 단위 정규화는 고정했고, 시간 초과 끝의 bootstrap은 세 후보 모두 기록된 기존 값을 유지했다.

|자료 구간|행동 수|기존 MSE|선형 MSE|MLP MSE|
|---|---:|---:|---:|---:|
|기존 8세계|3149|0.128362|0.039269|0.039160|
|새 8세계|1706|0.114796|0.089079|0.092348|
|성공 종료 궤적의 초반|2360|0.014868|0.045050|0.044777|
|시간 초과 1개 궤적|240|0.014536|0.397441|0.396438|

새 세계를 더한 fitting은 동일한 기존 8세계의 OOF 오차를 선형 .050899→.039269, MLP .063237→.039160으로 줄였다. 따라서 데이터 확대의 이득도 관측됐다. 다만 성공 궤적의 초반에서도 오차는 기존보다 크므로 시간 초과 하나만으로 gate 미통과 전체를 설명할 수 없다.

시간 초과 시드 104831을 제외한 fold에는 나머지 23개 성공 궤적만 남는다. 해당 표본에서 교정 예측은 기록된 target보다 크게 높았다. 그러나 이 target은 실제 전체 미래 보상이 아니라 기존 critic의 bootstrap **0.1714873463**을 사용한다. 기존 critic이 기준선인 동시에 target의 일부여서, 이 오차만으로 새 critic의 실제 미래 가치 판단이 틀렸다고 확정할 수 없다. 성공/실패와 미래 남은 길이로 나눈 구간도 결과에 조건을 건 분석이므로 진짜 상태 가치나 행동의 인과 효과를 직접 판정하지 못한다.

선형 OOF 예측 범위는 약 −.187~1.170으로 이 단일 보상 target 범위 [0,1] 밖 값도 나왔다. 출력이 [0,1]인 MLP에서도 채택 기준을 만족하지 못했으므로 단순 출력 제한 하나로 해결됐다고 볼 수 없다. 사후 clipping 결과를 채택 근거로 삼지 않았다.

첫 추론이 **9.42~137.24초**로 크게 흔들렸다. 시간 초과 시드에서는 132.90초를 차지했다. 이를 제거하면 성공했을 것이라는 반사실 결과는 실행하지 않았으며, CUDA/메모리/I/O 중 정확한 원인은 미확정이다. 이번 실행에서 OOM은 보고되지 않았다. 단순히 모델 로드 성공을 정책 성공으로 세지 않았고, API 제어로 대체하지 않았다.

180초 이후 새 정책 전달은 0건이었다. 시간 초과의 보고된 180.44초는 종료 경계/진행 중 처리와 마지막 기록을 포함한다. 실시간 강제 선점 보장은 아니며, 이미 전달된 행동이 끝날 수 있다는 기존 계약을 유지했다. 모든 새 시행에서 완료/중단 인정 이후 정책 행동용 추론 시작·정책 전달 0, 입력 해제, 자식 프로세스 잔존 0을 감사했다. 시간 초과의 학습용 bootstrap 추론은 게임을 닫은 뒤 별도로 수행하며 행동을 전달하지 않는다. 이번에 별도의 사용자 수동 중단 시행을 새로 돌린 것은 아니다.

수집 중 상태 조회·파일 읽기/목록 검색·스크립트 편집이 있었다. 특히 두 번째 세계 초기화 무렵 results 파일 열거가 수십 초 걸렸으며 첫 추론과의 정확한 중첩과 영향은 계측하지 않았다. 그 표본은 보존했다. 무거운 fitting과 전체 테스트는 게임 종료 뒤 실행했지만, 위 시간은 완전히 격리된 성능 벤치마크가 아니다.

## 이번 단계의 결정과 남은 일

사전 조건에 따른 이번 교정 실험은 마쳤다. **교정 critic 채택, 이를 이용한 한 요인 actor 비교, 새 정책의 여러 학습 라운드는 미실행**이며 실패 표본으로 계산하지 않는다. 기본 정책을 바꾸거나 같은 자료를 반복 학습해 개선으로 포장하지 않는다. 최종 시드 3000017·3000029·3000047·3000061·3000073도 미실행이다.

다음 판단에는 (1) 순환 기억·난수·세계 상태 보존을 먼저 입증하는 초기 추론 워밍업, (2) 시간 초과 bootstrap 의존성과 미래 결과에 조건을 건 초반 구간 기준의 한계를 분리한 가치 검증이 필요하다. 그 뒤 독립적으로 정한 조건의 실제 정책 비교로 효과를 확인해야 한다. 이번 데이터만으로 ‘더 큰 critic’, ‘더 많은 세계’, ‘양수 advantage 증가’ 중 하나가 해결책이라고 확정하지 않는다.
