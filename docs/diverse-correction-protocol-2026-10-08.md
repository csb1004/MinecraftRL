# 시연 범위 확장과 사전학습 미세조정 점검

사용자는 막다른 상태의 교정 시연 보강을 승인했고, 관련 부분을 가져와 파인튜닝하는
방향을 제안했다. 기존 STEVE-1은 이미 사전학습된 VPT 기반 정책이나 최근 BC/PPO는
출력 head만 학습했다. 전체 사전학습 표현을 미세조정한 결과로 부르지 않는다.

## 이번 시연 수집

`results/diverse-teacher-worlds-20261008/selection.json`에서 수집 전에 조건을 고정했다.
train6조건: 104743/104759 좌우 반전 각각 먼 출발(벽 끝5), 테두리 근접(끝8),
먼 테두리 출발(끝11). 뒤 두 조건은 나무가 아니라 막다른 바깥 벽을 바라보고 시작한다.
development2조건:104761에서 끝6/10과 다른 출발점. train과 분리하고 최종5시드 미사용.
기존 평가 episode를 train으로 바꾸지 않는다. synthetic fixture이므로 다양한 자연 지형을
대체한 자료라고 주장하지 않는다. 교사 상태는 알려진 좌표를 쓰며 DAgger는 아니다.

각 조건 교사1회, 최대180초. 성공/실패/취소를 모두 보존하고 STOP·키0·소유PID0·실제
인벤토리·전이 정렬로 감사한다. 시연이 실패하면 성공 시연으로 등록하지 않는다.
이번 추가 시연의 효과는 기존2개만 사용한 학습과 구분해야 한다.

## 미세조정 범위 점검

[공식 VPT 코드](https://github.com/openai/Video-Pre-Training)는 사전학습 가중치의 BC
미세조정을 제공한다. [STEVE-1 공식 코드](https://github.com/Shalev-Lifshitz/STEVE-1)는
VPT와 MineCLIP을 바탕으로 조건부 정책을 학습한다. 로컬 STEVE-1 코드의 net은
시각 처리→목표 결합→recurrent blocks→lastlayer→final_ln→action/value head 순서다.

사전학습 내부 층을 조정할 첫 후보는 마지막 표현층(lastlayer/final_ln)과 action head다.
앞부분을 동결하면 순차 메모리는 기존대로 유지하면서 마지막 표현의 미세조정 비용을
측정할 수 있다. 이는 CNN/Transformer 전체 파인튜닝과 다르다. 먼저 실제 가중치·학습용
프레임으로 메모리/gradient/출력 재현성만 조사하며 이를 게임 성능 성공으로 세지 않는다.
전체 backbone 미세조정이나 다른 정책 도입이 필요하면 목표/행동 공간/환경·공개 가중치
호환성을 따로 확인해야 한다. 자료 없이 특정 모델에 우회 능력이 있다고 가정하지 않는다.

현재 사용자의 세부 선호(정책 내부 층/외부 시연/둘 다)는 질문 중이다. 답변 전에는 공통으로
승인된 시연 보강과 읽기·자원 검증을 진행한다. 기본 정책 교체나 유료/Colab 연결은 하지 않는다.
# 동일 데이터 내부 표현층 비교 — 학습 전 고정

최종 제한 조정(두 번째 학습 완료 후, 게임 실행 전): lr2e-6에서 head KL=.006992 통과,
tail KL=.072940 미통과. 해당 비교4조건도 미실행. 이번 배치의 마지막 학습률 조정은
두 조건 모두5e-7, 동일180갱신이다. `diverse-bc-{head,tail}-lr5e7-20261008`에 보존한다.
동일 gate를 유지하며 이것도 미통과이면 추가 탐색 없이 실패 원인을 기록한다.

추가 사전 지정(첫 두 학습 완료 후, 게임 실행 전): lr1e-5에서 head KL=.124534,
tail KL=.281421로 둘 다 gate 미통과했다. 해당 체크포인트/결과를 보존하고 게임4조건은
미실행으로 기록한다. 새 결과 디렉터리 `diverse-bc-{head,tail}-lr2e6-20261008`에서
같은 부모/분할/순서/180갱신으로 lr2e-6만 변경한다. gate와 두 개발 세계 비교 규칙은
동일하다. 개발 결과를 본 뒤의 조정이므로 최종 평가로 주장하지 않는다.

새2037전이(train1436/development601)의 원본 사전학습 특징과 lastlayer 이전 특징을
같이 캐시한다. 두 후보 모두 기존 gap 부모에서 시작하고 train만 AdamW2epoch,
batch16/lr1e-5/KL계수1/순서seed9202로 학습한다. 조건A는 action head,
조건B는 lastlayer/final_ln+action head를 갱신한다. CNN/recurrent는 동결한다.
KL 기준은 원본 특징+부모 head로 고정한다. 바뀐 표현을 기준 정책에도 넣지 않는다.
개발 NLL 비악화, train KL<=.03, 유한한 값/실제 가중치 갱신/reload오차0 gate를 적용한다.
둘 다 통과하면 긴 벽2000003과 자연2000029에서 A/B 각각1회, 제어최대180초를 실행한다.
긴 벽은 A→B, 자연은 B→A. 초기 서버/메모리/픽셀 일치와 STOP/키/PID를 감사한다.
이들은 기존 개발 월드이며 최종 평가가 아니다. 최종5시드는 사용하지 않는다.
한 조건이라도 gate 미통과이면 비교 게임은 미실행으로 남기고 원인을 분석한다.
학생 성공은 서버 획득으로 판정한다. value 가중치는 보존하지만 표현 변경으로 값 예측은
달라질 수 있다. tail 체크포인트의 기존 head-only PPO 재개는 명시적으로 거부한다.
기본 정책 승격은 별도 검토까지 하지 않는다. 이번 로컬 비교에는 유료 API/Colab을 쓰지 않는다.
