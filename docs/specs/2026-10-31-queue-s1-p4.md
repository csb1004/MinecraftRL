# P4 — 목표 대기열·진행 이력과 새 S1 RL 경로의 개발 검증

2026-10-31 실행 전 고정. 사용자 승인한 병목 개선 및 큰 목표 우선순위 대기열의 첫 검증이다.
P3를 변경하거나 재시도하지 않는다. 고정 관측기/공식 backbone을 유지하고 새 학습 후보만 별도 저장한다.

## A. 동결 정책의 큐/상태 진단 (5회)

모두 공식 STEVE-1 2x, guidance 6, P3의 wood root/seek 임베딩 복사, dirt는 공식 visual embedding.
나무 단계의 접근/채굴/줍기는 여전히 root 조건을 공유한다. 새 의미 조건이 학습됐다는 주장은 하지 않는다.
priority 높은 값 우선, 동률 등록 순서, 활성 목표 비선점. 각 의존 목표의 완료만 다음 목표를 허용한다.
초기 보유량/앞 목표 획득을 다음 목표 수량으로 중복 계산하지 않는다.

| 개발 seed | 목표 | 목적 |
|---|---|---|
| 81031001 | wood 1 | 과거 미획득/탐색 복귀 장면의 새 실행 진단 |
| 81031007 | wood 1 | 알려진 목표 접근 정체 진단 |
| 81031003 | wood 1 → dirt 1 | 실제 다른 목표로의 handoff |
| 81031009 | wood 1 → cobblestone 1 | 미지원 돌 스킬/도구 조건을 성공으로 넘기지 않음 |
| 81031013 | wood 1 → 추가 wood 1 | 같은 자원의 신규 baseline·중복 완료 방지 |

no-progress budget 1200 server tick, pending-result budget 300 tick. 두 수치는 미보정 개발 한도다.
보상은 상위 목표 완료당 1, 나머지 0. 현 관측에 없는 새 상태/도구 사용 능력을 만들지 않는다.
돌은 새 queue executor에 검증된 binding이 없어서 `unsupported_skill`로 남는다.
blocked/미실행을 획득 실패 표본처럼 합산하지 않고 완료한 개별 목표와 차단 이유를 보고한다.
이 조건을 과거 P3와 짝지은 인과 비교로 해석하지 않는다.

## B. 새 S1 학습 경로 (수집 4회 → PPO 1회)

이전 retired RL CLI/체크포인트는 사용하지 않는다. frozen image/goal/recurrent features 뒤에
재사용 가능한 6개 입력(search/approach/mine/collect, 현재 목표 수량 진전, 결과 회수 대기)을
actor/value **둘 다** 연결한다. actor의 추가 열은 0으로 초기화하고 value는 0 초기화한다.
world seed와 정책 난수 seed를 같게 한다. 학습 중 GPU에는 backbone을 로드하지 않는 별도 head trainer를 사용한다.

| 학습 seed | 목표 |
|---|---|
| 81032001 | wood 1 |
| 81032003 | dirt 1 |
| 81032007 | wood 1 |
| 81032009 | dirt 1 |

학습 및 아래 비교의 진행/회수 budget은 모두 3600 server tick으로 동일하게 둔다.
제어 180초 제한이 우선하며 실패 경험을 미래 보상 0의 완료 경험으로 둔갑시키지 않는다.
실제 종료/최종 목표는 bootstrap 0, 시간 제한은 마지막 committed recurrent state·현재 목표로 value bootstrap.
취소/기술 오류/정체 차단 표본은 학습에 사용하지 않는다. 새로 실제 전달한 행동만 경험에 포함한다.

수집된 정확한 조건에서 log probability 재현 최대 오차 ≤1e-4가 필수다. 같은 시작 actor/value,
다중 학습 seed, 유한한 비상수 advantage가 확인돼야 optimizer를 실행한다. 실패하면 후보를 만들지 않는다.
고정 설정: gamma .999, GAE lambda 1, actor lr 1e-5, value lr 1e-3, epoch 1, minibatch 32,
PPO clip .1, 초기 actor에 대한 KL 계수 .1, approximate KL .02 초과 시 조기 종료,
gradient norm clip 1, value loss 계수 .5, 학습 난수 103131. root 완료 보상만 사용한다.
실제 actor/phase 열/value 가중치 변화와 gradient, 학습 시간·GPU 메모리를 기록한다.

## C. 같은 S1 수집기에서 초기 head와 후보 head 비교 (최대 10회)

학습에 쓰지 않은 5개 개발 seed, 조건별 1회. 초기/후보 순서는 seed 순서로 AB/BA/AB/BA/AB.
둘 다 같은 frozen backbone/추론 구현/6차원 연결/관측/RM/임베딩/예산을 사용한다.
P3의 원래 추론 구현을 이 비교의 초기 head 표본으로 대체하지 않는다.

| 개발 seed | 목표 |
|---|---|
| 81033001 | wood 1 |
| 81033003 | dirt 1 |
| 81033007 | wood 1 → dirt 1 |
| 81033009 | dirt 1 → wood 1 |
| 81033013 | wood 1 → 추가 wood 1 |

새 목표 조합은 작은 전이 진단이며 최종 평가가 아니다. 단일 후보/작은 표본이므로 일반화·지속학습
전체 성공이나 phase 입력의 독립적 인과 효과를 주장하지 않는다. 후보는 자동 승격하지 않는다.

## 공통 고정/중단/해석

- 실행당 wall control ≤180초, startup ≤600초, 실제 action당 server 1tick, neutral warmup 60tick.
- 초기 pose/PNG·서버 인벤토리·원본 이벤트·실제 goal/condition/phase·원본 소스·해시를 남긴다.
  PNG 동일성은 사후 공개하며 동일 seed만으로 동일 trajectory를 가정하지 않는다.
- 실제 목표 완료/차단/획득량·목표별 순서·제어 시간/tick, 추론/제어 주기/PNG 저장 비용·VRAM을 보고한다.
- 새 성능 실패의 임의 재시도 없음. 기술 오류 시 중단하고 원본과 별도 amendment를 남긴다.
- 마지막 별도 seed 81031999, queue+S1 초기 head에서 완료 transition 10회 후 STOP 검사.
  요청/ack 이후 dispatch 0, 실제 입력 해제/held key 0, 소유 PID 0, 정상 취소 worker exit 2.
  STOP 진단은 성능/학습 표본이 아니다. 최종 STOP 유지.
- 현재 사용자의 실행 승인을 근거로 이전 진단 STOP 원문/해시를 한 번 보존 이동한다. 새 STOP은 지우지 않는다.
- 외부 LLM/API·유료 자원·Colab·GitHub 게시 0. `results`/새 가중치 Git 제외. 연구 명세 원문 보존.
