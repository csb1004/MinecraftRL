## 1. 프로세스와 '최소'의 뜻

- 프로세스는 다음 순서로 이어진다. 원문 명세 Stage 7과 같다.
  1. 대화
  2. 실행할 목표 결정(Task Commitment)
  3. RM 컴파일·검증
  4. 플래너가 기술 순서 결정
  5. 기술 정책 실행
  6. 서버 상태로 RM 전이
- 프로세스의 LLM·RM·지식(KB)·재계획 쪽은 "철 캐줘" 시연(11-05)에서 실제로 돌았다.
  - 빈 KB 6/10, 이어받은 KB 1/3을 성공했다.
  - 실패는 모두 정책 동작이었다. 주로 원목·철광석 탐색 시간 초과다.
- 그래서 여기서 '최소 요구 능력'은 이렇게 정한다(**내 정의**). 플래너가 고른 기술 단계 하나하나를 정책이 정해진 시간 안에 서버 상태 기준으로 끝낼 수 있는 능력이다.
  - 대표 목표는 지금 시연 목표인 "철 캐줘"(원목→작업대→나무 곡괭이→조약돌→돌 곡괭이→철광석)다.
  - 다음 목표로 "작은 집 지어줘"를 둔다.

## 2. 지금 정책이 할 수 있는 것 (게임 검증, 평평한 시험장)

| 기술 | 결과 | 프로세스에 바로 쓸 수 있나 |
|---|---|---|
| 원목·조약돌 채굴(공식 STEVE-1 프롬프트) | 시연에서 동작, 탐색 시간 편차 큼 | 쓰고 있음 |
| 철광석 채굴 v3 | 최종 8/8(공식 8/8), 헛손질·시간 감소 | 아니오: 철광석 위치(fixture 좌표)를 특권 입력으로 받음 |
| 블록 놓기 | 최종 5/8 | 아니오: 목표 칸 좌표를 특권 입력으로 받음 |
| 다리 잇기 | 최종 5/8, 떨어짐 0 | 아니오: 과업 좌표 특권 입력, 학생이 교사보다 6배 느림 |
| 점프 코스 v2 | 최종 8/8 | 아니오: 다음 발판 방향을 코스 좌표로 받음 |
| 건축 3차 | 개발·최종 8/8, 가림 회복 확인 | 부분: 설계도는 플래너가 줄 수 있음. 서버 설치 기록과 자기 자세를 쓴다. 잘못 놓음이 남음(4차 진행) |
| 제작(작업대·화로 포함) | 규칙 보조(GUI 스크립트) | 규칙 스킬로 쓰고 있음(학습 정책 아님) |

새로 학습한 기술은 모두 LLM vocabulary에 넣지 않았다. 평평한 시험장에서 시작 위치·대상 위치를 fixture로 알고 시작한다.

## 3. 최소 요구에 못 미치는 곳 (우선순위, **내 판단**)

1. **탐색: 대상을 시야에 넣기(원목·돌·철광석).** 프로세스 실패의 대부분이 여기서 나왔다.
   - 시연 평가 실패 대부분이 탐색 시간 초과였다. 같은 seed에서도 5–10초에서 11분까지 퍼졌다. 바닥이나 경계벽만 오래 보는 동작이 원인이었다.
   - 지금은 공식 STEVE-1 프롬프트에만 맡긴다. 학습한 탐색 헤드는 없다.
   - 필요한 것은 두 가지다.
     - 기술 내부 단계: 둘러보기→대상 발견→다가가기.
     - "찾을 때까지" 감시 신호: 탐색 진척, 같은 곳 맴돌기.
   - 교사(특권: 대상 위치)로 DAgger 학습한 뒤, 평가는 대상 위치 없이 해야 한다.
2. **특권 입력을 화면에서 얻기.** 채굴 v3·놓기·다리·점프 헤드를 프로세스에 넣으려면 필요하다.
   - 지금은 대상 방향·조준점·발판 방향을 fixture 좌표로 계산한다.
   - 이 특징을 화면에서 예측하는 모듈이 있어야 한다. 예: CNN 블록 위치 추정. 11-07에 CNN probe를 해 봤다.
   - 아니면 프로세스가 정당하게 아는 값으로 바꿔야 한다. 예: 플래너가 준 설계도, 자기 좌표.
   - 판단 기준은 실제 사용 중에도 그 값을 알 수 있는가다.
3. **통합: 학습 헤드를 플래너 단계로 실행.**
   - 지금 헤드는 각자 fixture에서 시작한다. 프로세스에서는 앞 단계가 끝난 자리, 자연 지형, 다른 인벤토리에서 시작한다.
   - 필요한 것:
     - RM 단계와 기술 내부 단계 연결
     - 시작 상태 다양화
     - 기술별 감시 명세(제한 시간 또는 "찾을 때까지")
     - vocabulary 등록과 검증
4. **건축 품질과 크기.** "집 지어줘"류 목표에 필요하다.
   - 잘못 놓음 줄이기(4차, 진행 중).
   - 잘못 놓은 블록 치우기(부수기 단계).
   - 2칸 넘는 벽·지붕(발판 쌓기나 점프 놓기).
   - 재료 수량 관리.
5. **제작은 학습하지 않아도 된다(제안).** 규칙 스킬(GUI 보조)이 시연에서 동작했다. 최소 요구에서는 규칙 스킬로 두고, 학습 정책 결과와 섞어 세지 않는다. 사용자가 정할 부분이다.

## 4. 순서 제안

- "철 캐줘"를 안정적으로 돌리는 것이 최소선이다. 이를 위해 1(탐색)→3(통합)을 먼저 한다.
- 2(화면 예측)는 철광석 채굴 v3를 프로세스에 넣을 때 필요하다. 그 전까지는 공식 프롬프트 채굴로도 시연은 돈다.
- 건축·다리·점프는 "집 지어줘" 같은 두 번째 목표용이다. 4번은 그 목표를 고를 때 이어간다.
