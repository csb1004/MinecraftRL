# S2 STOP 재검증 부록 — 2026-11-01

기존 S2 성능/학습 37회와 네 후보는 완료됐으며 재실행하지 않는다.
최초 STOP probe는 게임 제어 전 공식 steve1.weights의 Windows SHA256 bridge가
120초 제한을 넘겨 preflight에서 차단됐다. 실제 정책 행동은 0개이고 STOP 요청도 발생하지 않았다.
원본 `results/rm-general-s2-20261101/stop-probe`와 helper 로그/receipt를 그대로 보존한다.
메인 드라이버는 실패 후 STOP을 래치했고 완료 receipt를 만들지 않았다. 이를 성공으로 바꾸지 않는다.

실패 당시 원본 이벤트 감사의 대용량 파일 읽기가 함께 진행됐다. 디스크 I/O 경합은 가능한 원인이지만
확정된 인과로 주장하지 않는다. 감사는 종료됐으며 37회·15,258행동 검증을 통과했다.

재검증 절차:

1. 잠근 원본 소스와 공식 파일 해시를 다시 검사한다. 큰 해시 읽기는 다른 대용량 분석과 겹치지 않는다.
2. 같은 native SHA256 bridge/120초 제한을 유지해 모든 공식 파일의 해시와 경과 시간을 기록한다.
3. `results/rm-general-s2-stop-r1-20261101`에 동일 goal-bank 복사본을 검증하고, 같은 wood1 프로그램과
   동일 nonlinear-on 체크포인트·seed 81031999로 **STOP 진단만** 실행한다.
4. 기존 자동 종료 STOP의 정확한 내용/해시를 확인하고 새 결과 폴더로 보존 이동한다.
   이는 사용자가 승인한 실제 중단 검증의 기술 오류 재검증이며 새 성능/학습/API 실행이 아니다.
5. 10행동 후 중단, 새 dispatch 0, 입력 해제/held keys 0, 소유 잔존 PID 0, worker exit 2를 확인한다.
   종료 후 STOP을 유지한다. 다른 대용량 분석은 이 진단이 끝난 뒤 실행한다.

실행 코드·모델·관측기·게임 JAR·해시 제한은 이 부록에서 변경하지 않는다.
종료 모니터 기록 수정도 실제 STOP 완료 및 원본 소스 해시 검증 이후 별도 사후 변경으로 수행한다.
