# 기억층 BC의 KL 기준 미통과 후 제한된 진단

학습 결과를 본 뒤, **새 게임 실행 전** 추가한 탐색 조건이다. 원래
[프로토콜](temporal-bc-protocol-2026-10-08.md)의 gate를 변경하거나 통과로 바꾸지 않는다.
개발 결과를 보고 선택한 조건이므로 사전 등록된 최종 평가로 해석하지 않는다.

## 관측과 판단

- 같은 자료/부모/순서로 각182갱신. 대조군 개발 NLL2.122717, 기억층 후보1.811346,
  시작2.197233. 기억층 후보의 train KL=.060300으로 기존<=.03 기준 미통과.
- 실제 기억층 가중치 변경, 긴 과거를 포함한8프레임의 gradient/causality, reload오차0을 확인했다.
  값은 유한하며 학습 OOM은 없었다. 전체 정책 추론 일치 검사는 게임 전에 완료해야 한다.
- `.03`은 로컬 `bc_core.comparison_gate`의 변화 제한값이다. 이 값만으로 우회 능력의
  성공/실패를 판정할 수 없다. 이미 [기본 행동 학습 조사](base-policy-learning-assessment-2026-10-08.md)에서
  작은 KL만 허용하면 필요한 행동 변화까지 억제할 가능성을 남겼다.

승인된 로컬 실험 범위 안에서 후보를 실제로 확인한다. 학습률 재탐색/추가 학습/후보 보간은
하지 않는다. 기존 엄격 gate 배치는4조건 **미실행**으로 먼저 닫아 보존한다.

## 별도 진단 조건

`results/temporal-bc-diagnostic-20261008/`: 위와 같은 두 체크포인트를 사용한다.
긴 벽2000003은 대조군→기억층, 자연2000029는 기억층→대조군, 각1회/제어최대180초.
원본 월드 복제·고정 embedding/CFG6/sampling seed/RM v4를 유지한다.
기존 gate를 통과했다는 표현은 하지 않으며 결과와 함께 두 후보 KL을 기록한다.
유한한 값, 개발 NLL 비악화, 실제 가중치 변경/reload0, 전체 추론 일치와
원본 체크포인트 SHA 검사는 그대로 요구한다. 달라지는 것은 진단 실행에 KL 상한을 적용하지
않는다는 점뿐이다. GPU 학습은 끝난 뒤 게임을 실행한다.

실제 서버 획득, 이동/우회, 실패 원인, GPU·추론/제어 지연, 중단 후 행동0/키0/소유PID0을
검사한다. 초기 픽셀 불일치는 인과/시간 비교 부적격으로 보존한다. 새 학습/게임 재시도로
성공률을 올리지 않고 최종5시드도 사용하지 않는다. 기본 정책을 승격하지 않는다.
미실행 엄격 gate4조건은 성공/실패 분모에 넣지 않는다. 진단 게임만 실제 표본으로 기록한다.
