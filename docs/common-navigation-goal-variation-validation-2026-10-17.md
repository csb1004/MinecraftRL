이는 관측된 분포 차이이며 시각 특징 암기나 특정 입력 열을 단일 원인으로 확정한 것은 아니다.

해결한다고 단정하지 않는다. 다음 검사는 같은 가중치에서 실제 전달 명령의 확률을 합산한
mode 선택이며, 학습용 월드의 작은 실제 calibration을 먼저 실시한다. 기존 네 실행은 그대로 보존한다.
