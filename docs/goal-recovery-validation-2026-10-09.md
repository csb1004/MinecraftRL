## 비교 한계

초기 snapshot·서버 상태·순환 기억·첫 픽셀은 같았다. 그러나5번째 정책 입력 화면,9번째 행동,
10번째 서버 pose부터 서로 달랐다. 정체 시점도649/603으로 다르므로 목표 텍스트 전환만의
엄밀한 인과 대조는 성립하지 않는다. 원인은 아직 렌더링/RNG 중 하나로 확정하지 않았다.
오프라인 같은 기억/화면의 조건 효과와 실제 게임에서 관측된 복구를 구분한다.

한 실제 탐색 실행에서 벽 횡단과 획득이 관측됐다는 근거다. 일반 우회 능력이나 성공률 개선을
입증한 것은 아니며 기본 정책 승격, 최종 평가5시드 사용, 지원 skill vocabulary 확대는 하지 않았다.
고정한 모서리 움직임/회전 입장 기준을 통과해 far와 자연 월드의 나머지4조건도 완료했다.
개입하지 않고 수집한 조건은 복구 성공 표본으로 세지 않는다.

far는25번째 입력 화면/196번째 행동/201번째 pose부터, 자연은4번째 화면/7번째 행동/9번째 pose부터
달랐다. 셋 모두 첫 서버·기억·픽셀은 동일하나 이후 재현성은 다르다. 자연 두 실행의 제어 조건은
개입이 없어 같은 wood이며,29초와49초의 차이를 탐색 옵션의 효과로 해석할 수 없다.
corner의 첫 다른 화면은 타격 파티클 주변에 차이가 보인다. 설치된 Particle/ParticleManager의 Random은
seed0이므로 단순히 미설정 random seed라고 단정하지 않는다. 렌더링 타이밍·난수 소비 순서의 원인은 미확정이다.

## 실패 근거와 재계획

실제 경보6건을 같은 판정기로 해석했다. corner/wood의649·1561, corner/explore의603,
far/wood의401·1288·1421이다. 나머지3획득 궤적에는 경보가 없었다. 이것은 선택된 개발 자료의
관측이며 일반 오탐률이나 재현율을 뜻하지 않는다. 복구 후 성공한 궤적의 경보를 자동으로 오탐이라 부르지 않는다.
corner/wood의 늦은 경보는 남은11.31초, far/wood의 복귀 후 경보는41.42초/27.72초였다.
LLM 계획 대기와 다음 skill 예산은 이 남은 전체 제어 시간 안에서 검사해야 한다.

목표 완료/STOP/관측 오류, 정체 의심, 복구 예산 소진, 접근 진전, 새 대상 발견, 상호작용 재개를
분리하는 판정9검사를 통과했다. 실패 근거에서 실제 실행을 승인하지 않으며 기존 RM을 보존한다.
실시간 LLM/스케줄러 연결·자동 다중 재개입·다중 RM 우선순위 관리는 아직 구현 완료로 보지 않는다.

## 실제 개입 중 STOP

같은 corner의 별도 sampling9721 검사에서 첫 개입 행동722 전이 뒤 소유 STOP 파일을 만들었다.
실제 전달722개/개입1개, 이후 새 정책 전달0·STOP acknowledgment 이후 새 추론0/전달0,
해제 뒤 held key0·잔존 소유PID0을 확인했다. 이 취소는 성능 성공/실패 분모에서 제외한다.
추론은723회였으며 마지막 미전달 행동은 STOP으로 폐기됐다.

워커는10초 종료 유예 뒤 소유권 추적으로 강제 종료돼 exit -9였다. 정상 자발적 종료라고 보고하지 않는다.
키 해제와 게임 close는 먼저 완료됐고,722개 trajectory 및 raw action/reward 자료의 완전 저장을
별도 CPU 로드·비교로 확인했다. 취소 데이터의 학습 적격성은 false이며 원본 STOP과 로그를 보존했다.

최종 전체 검사: Windows384(18환경 제외), WSL389(9환경 제외), 모두 종료0.
실제 API는0회이며, 첫 corner 쌍의 정체 당시 텍스트 증거에 대한 최대2회 제안 검사만 준비했다.
이후 결과나 정답을 LLM 입력에 넣지 않았고 실제 원격 호출과 게임 집행은 하지 않았다.

## 기술 오류의 분리

첫 감사의 tuple/list 비교 오류는 원본 게임을 보존한 채 감사기만 수정했다. 탐색군 첫 기동은
과거 PID 파일 충돌로 단계0/추론0에서 실패했다. 기술 오류1건은 성능 분모에서 제외하고 원본을
`technical_attempts`에 보존했다. 완료된 정책 실행을 더 좋은 결과가 나올 때까지 재실행하지 않았다.
watchdog 파일 범위 수정 뒤 동일 탐색 조건을 한 번 재기동해 위 결과를 얻었다.
