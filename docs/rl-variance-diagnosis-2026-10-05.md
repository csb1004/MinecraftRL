## 결론

첫 행동 분기는 **같은 세계에서 달라진 시각 관측/특징**에 의해 발생했음을 저장 특징 개입으로 확인했다. 4번째 행동에서 같은 입력 특징을 쓰면 전후 출력층 모두 같은 행동을 선택하고, 특징을 바꾸면 같은 출력층에서도 시선 행동이 바뀌었다. 최초3행동의 화면·특징·행동은 정확히 같았다. 원목 획득 판정 지연이나 목표 달성 이후 추가 행동 때문에 늘어난 시간이 아니다.

다만 화면 차이를 처음 만든 엔진 내부 경로는 미확정이다. 입력 차이를 없애는 엔진 수정은 수행하지 않았다. 학습 후 출력층도 이후 일부 샘플을 바꾸므로 전체84행동 차이를 전부 관측 편차로 설명하거나 학습 효과가 전혀 없다고 주장하지 않는다.

## 질문과 고정 조건

앞선 검증2000029에서 원목 획득까지211→295행동으로 늘어난 원인을 조사한다. 학습 자체의 퇴행, 관측/게임 실행 편차, 획득 판정 지연을 구분한다. 전후 모델 및 동일 시드 반복은 각각 독립된 새 시드 표본이 아니다.

시드2000029만 사용한다. 원 배치의 불변 월드·임베딩·체크포인트를 유지하고, 실행 순서는 전→후→후→전, 추가4회로 사전 고정했다. 모델마다 기존1회+추가2회다. 60중립 tick, 빈 초기 인벤토리, 정책 기억·샘플링 RNG 초기화, 시작 화면/서버 상태 비교, 실행당 현실 제어 상한180초를 유지한다. 기술 오류나 시작 조건 불일치는 보존하고 배치를 중단하며, 좋은 결과가 나올 때까지 재시도하지 않는다. 새 학습·최종 평가5시드·외부 API·Colab은 사용하지 않는다.

증거 폴더: `results/rl-variance-20261005T045909144159Z`. `experiment.json`에 실행 전 순서/해시/제한과 실행별 결과를 보존한다. 분석은 `ce-debug` 절차를 적용하며, 사용자 승인에 따라 주스레드에서 순차 수행한다.

## 기존 실행에서 확인한 사실

- 처음3개 입력 화면은 같고 첫3행동도 같다. frame3(4번째 행동의 입력)부터 화면이 다르다. 서버 위치·시선은3행동까지 같다.
- 4번째 행동에서 수평 시선 입력이 전 모델 -3.215369°, 후 모델 -10°로 갈라진다. 둘 다 공격한다.
- 전 모델은201행동째 원목을 캐고211째 주웠다. 후 모델은285째 캐고295째 주웠다. 두 경우 모두 캐기→줍기10행동이며, 서버 획득 즉시 종료했다. 따라서 최초 비교의84행동 차이는 획득 판정 지연이 아니라 원목을 캐기 전 구간에 있다.
- 실제 화면은 전 모델이 가까운 나무에 접근하고 후 모델이 다른 방향의 숲으로 접근하는 모습을 보인다. 이는 궤적 관찰이며 좋은 경로/나쁜 경로의 일반적 학습 효과 판정은 아니다.
- 첫 추가 전 모델 실행은 같은 시작 화면/상태에서312행동으로 성공했다. 동일 가중치임에도 frame3부터 화면,4번째부터 행동이 다르다. 학습 전 모델 내부 편차101행동이 기존 전후 차이84행동보다 크다.

`original-pair-diagnosis.json`, `original-pair-contact.png`, `first-pixel-difference.png`, `live-comparison.json`에 원본 증거와 비교를 보존한다. 입력 화면의 frame0은1번째 행동 전, frame3은4번째 행동 전이다. 마지막 획득 화면은 숫자 파일이 아닌 `frames/final.png`이며 총 단계보다 작은 인덱스의 입력 화면만 비교한다.

## 추가 검증

고정4회 실제 실행 뒤 같은 관측 특징에 전후 출력층을 교차 적용하고 같은 CUDA 난수열로 샘플링한다. 각 원래 모델/특징 조합에서 저장 행동과 확률을 먼저 재현해야 개입 분석을 해석한다. 이는 고정 특징에 대한 출력층 개입이며 다른 행동 뒤 실제 게임 미래를 재현한 반사실 rollout은 아니다. 별도 GPU 분석은 게임 실행이 모두 끝난 뒤 수행한다.

실행 로그의 실제 전달 행동/보상, 서버 tick과 월드 시간, 처음 원목 획득 이후 차단, 입력 해제·소유 자식 정리, 원본 체크포인트/월드 해시와 평가 전용 데이터 조건을 감사한다. 전역 기본 모델과 학습률은 이 진단을 이유로 변경하지 않는다.

## 원인 해석의 경계

같은 checkpoint에서 픽셀/행동 차이가 재현된 사실은 실행 편차의 존재를 보여주지만, 화면 차이를 발생시킨 Minecraft 내부 경로까지 확정한 것은 아니다. 로컬 MCP 소스의 Particle/ParticleManager는 이미 `new Random(0)`을 쓰며 WorldRenderer에는 지연 청크 재빌드 경로가 있다. 따라서 단순히 “입자 RNG seed 미설정”으로 단정하거나 임의로 입자/튜토리얼/렌더링을 끄지 않는다. 실행 JAR에 대한 개별 경로 계측이나 통제 실험 없이 특정 엔진 서브시스템의 인과 원인을 확정하지 않는다.

현재 가설: 관측 이미지의 실행 편차가 frozen 시각 특징과 행동 샘플링 분포를 바꾸고 경로 차이로 확대된다. 검증 예측은 같은 난수와 같은 actor를 유지한 채 실제 저장 특징만 바꿔도 최초 시선 분기가 나타나는 것이다. 반대로 이미지 변화 없이 actor 변경만으로 같은 분기가 나타난다면 학습 변화도 해당 분기의 원인 후보다. 이 구분은 교차 개입 결과로 판정한다.

## 감사 및 후속 기준
