# 공통 스킬 학습 1차: 목표 지점 이동

아래 고정 실험은 최초 조건의 기록이다. 현재는 [진행 기록](progress.md)의 조건을 따른다.
현재 도착 판정은 서버·현재 클라이언트 위치를 함께 확인하는12틱 안정 도착이며, 단순 첫 진입과 구분한다.
현재 [전체 관측 상대 목표 학습](common-navigation-dense-goal-2026-10-17.md)과
[자연 지형 사람 시연 준비](common-human-slope-data-2026-10-17.md)를 진행한다.

사용자 지시에 따라 특정 실패 저장본의 프롬프트/가드 수정 반복에서, 여러 과업이 재사용하는
실제 학습 스킬과 분리된 평가 중심으로 전환한다. 연구 명세 원문과 돌도끼/원목64 목표는 유지한다.
돌도끼 사망본은 통합 평가 자료로 보존하며 이 학습에서 부활·되감기하지 않는다.

첫 스킬의 입력은 목표의 상대 방향·거리·높이, 직전 이동·회전, 남은 시간과 기존 시각/기억 특징이다.
출력은 기존 정책 행동 공간이며 과업 이름이나 고정 경로 번호를 입력하지 않는다.
완료는 실제 서버 위치와 목표의 수평 거리0.35블록 이하·높이 차1.5 이하·GUI 닫힘으로 판정한다.
수집 접근·방문 지점 복귀·복구 이동이 같은 인터페이스를 사용할 수 있다.
도착 시 해당 목표의 실행은 실행기가 종료한다. 이번 판정에는 정지 속도/장시간 위치 유지가 없으므로
신경망 자체가 제동·안정 정지를 학습했다는 뜻은 아니다.

## 이번 고정 실험

- 설정: `configs/common-navigation-v1.json`. 생성 시드17101, 행동 샘플링17131.
- 기존 최선 navigation MLP+PPO 체크포인트를 기준으로 사용한다. 원래 STEVE-1/원목 정책은 동결한다.
- train3시드104729/104743/104759,4개 출발 위치·방향/대칭 조건, 각6개 목표.
  목표는3~6블록 이동과0.65~1.3블록 정밀 접근을 번갈아 무작위 생성한다.
- 새 correction4회: 학생8틱 후 미완료면 중립 입력 해제→명시적 좌표 교사로 인계한다.
  교사 성공은 학생 성공이 아니다. 교사 행동만 BC 정답으로 사용한다.
- 기존 감사된519개 교사 정답을 replay하고, 새 교사 자료를 합친다.
  학습률5e-6, 최대8epoch, batch32, KL상한0.03에서 해당epoch를 되돌린다.
  실제 보존 optimizer update와 actor tensor fingerprint 변화를 필수로 기록한다.
- label monitor는 기존 개발104761 교사 자료다. gradient에 넣지 않는다.
- 실제 비교는 학습에서 제외된 개발 시드2000003/2000029, 새 목표 순서·시점·시작 방향 각6개다.
  baseline/candidate 각각2게임, 같은 시작 월드·기억·샘플링 시드. 두 번째 월드는 실행 순서를 바꾼다.
  출발 위치/기억 일치와 초기 PNG 일치를 각각 기록한다.
- 실제 도착 개수 우선, 같으면 총 학생 행동수가 적은 후보를 개선으로 표시한다.
  이 작은 개발 평가로 기본 정책을 자동 승격하거나 최종 일반화 성공을 선언하지 않는다.
- 게임당 제어예산175초, 실측180초 이하. STOP 뒤 새 추론/행동0, 입력키0, 소유PID0,
  행동확률·실제 전달 행동·1서버틱 전이·교사 구분을 독립 재생 감사한다.
- 결과·시작 월드·source·학습 데이터 해시·checkpoint는 `results/common-navigation-20261017`에 보존한다.
  완료/부분 배치를 자동 재실행하지 않는다. 유료 API/Colab/외부 발행은 사용하지 않는다.

재현 진입점은 Windows PowerShell에서 격리된 `.runtime/fixture-tools/Scripts/python.exe`로
`scripts/prepare_common_navigation.py configs/common-navigation-v1.json`을 실행한 뒤,
`PYTHONPATH=src` 환경에서 `scripts/run_common_navigation_workflow.py configs/common-navigation-v1.json`을 실행하는 것이다.
이미 이 결과 디렉터리가 있다면 재실행하지 않고 원본을 보존한 새 설정/출력 경로를 사용해야 한다.
설정에 명시된 기존 월드·시연·baseline 가중치가 필요한 로컬 실험이며 Git 소스만으로 이 자료가 제공되는 것은 아니다.
이전 STOP은 사용자 재개 승인과 내용을 확인한 뒤 보존하고, 알 수 없는 STOP을 자동 삭제하지 않는다.

## 해석 경계와 후속 순서

이번에는 **서버 좌표를 쓰는 구성된 평지의 공통 이동**만 학습한다. 시드가 달라도 같은 평지 구조이므로
자연 지형 일반화, 장애물 우회, 낙하 회피, 영상만으로 목표 발견을 입증하지 못한다.
CNN/기억 본체는 동결하고 목표 조건부 residual/시각 projection 638,746개 파라미터를 학습한다.
시각 인식 오류를 이 학습으로 고쳤다고 주장하지 않는다.

다음 학습 단위는 (1)여러 자연 지형의 이동/정지·낙하 회피, (2)시야 회전→대상 발견/재관측,
(3)대상 접근→채굴→실제 아이템 획득이다. 공개 인간 행동 자료/검증된 시연을 활용하고,
실패마다 새로운 스킬 이름을 만들지 않는다. 각 스킬은 공통 입력·완료/실패 조건·데이터 분할·
변경된 가중치·분리 평가를 갖춰야 한다. 상위RM은 이 스킬들의 조합/우선순위를 다루며,
LLM에 아직 평가되지 않은 스킬을 실행 가능하다고 노출하지 않는다. 제작 GUI는 명시적 규칙 제어와 구분한다.
