# 대화 기억과 과업 기록 복원

2026-10-04 구현. 최근 대화 12개, 오래된 발화의 제한된 요약, 실제 과업 상태를
별도로 저장한다. 요약은 실행 명령이나 목표 달성 증거로 취급하지 않는다.

후속 사용자 요청으로 [월드 저장·재개](world-persistence.md)를 추가했다. 아래 자동 월드
복원 미지원 설명과 61개 테스트는 대화 기억 단계 당시 기록이다. 현재 `session`은 별도의
월드 저장 슬롯을 사용하며, 과업 체크포인트 파일만으로 월드를 재생성하지는 않는다.

## 저장과 모델 입력

- 최근 사용자/assistant 메시지 12개를 유지한다. 메시지는 최대 2,048자다.
- 최근 범위를 벗어난 메시지는 출처 ID와 분류를 붙인 최대 240자 발췌로 남긴다.
  선호, 미확정 제안, 질문, 과업 맥락, 일반 맥락, assistant 각 분류의 최신 4개,
  합계 최대 24개다. LLM이 다시 쓴 의미 요약이 아니며 요약용 API 호출은 없다.
- 모델에는 최근 대화와 발췌 요약, 현재 과업 상태를 함께 전달한다. 오래된 제안은
  미확정 상태를 유지한다. 이전 목표는 현재 목표를 덮어쓰지 않는다.
- 콘솔은 `data/dialogue/<사용자 ID 해시>.json`에 저장한다. `-UserId`를 생략하면
  로컬 운영자 하나의 기록을 공유한다. 같은 ID는 다른 게임 세션에서도 대화를 이어 쓴다.
  사용자 ID는 로컬 기록 선택자이며 인증 기능은 아니다.
- `.archive.jsonl`에 출처 발화를 추가 보존하지만 전체 아카이브를 모델에 보내지는 않는다.
  아카이브도 메시지당 2,048자 제한이며 별도 용량 자동 정리는 아직 없다.
  MyWife 개인 기록은 자동으로 읽거나 복사하지 않는다. `data/`, `results/`는 Git 제외다.

## 과업 복원 경계

살아 있는 동일 게임 worker에 콘솔을 다시 연결하면 이벤트 기록으로 현재 과업,
최신 인벤토리 진행도, 대체된 목표를 재구성한다. 명령 파일 발행 직후 재시작해도
이미 대기 중인 명령을 다시 발행하지 않는다. 확인 대기 토큰은 복원하지 않는다.

worker는 상태·진행도 변경 및 종료 때 `task-checkpoint.json`을 원자적으로 저장한다.
과업 복원 함수는 월드 ID 일치를 요구하며 실행 중 상태를 paused로 복원한다.
완료·취소된 과업은 재활성화하지 않는다. 이는 **Minecraft 월드나 프로세스 복원 기능이
아니다**. 새 게임에 이전 획득량을 이식하거나 이전 목표를 자동 재실행하지 않는다.
worker의 체크포인트 자동 로드도 아직 제공하지 않는다.

종료된 세션의 기록은 실행 없이 조회할 수 있다. 다음 세션 경로는 실제 결과 폴더로 바꾼다.

```powershell
.\scripts\Invoke-DialogueConsole.ps1 -SessionPath .\results\SESSION -InspectMemory
```

`-UserId`를 사용했던 대화는 조회에도 같은 ID를 지정한다. 조회는 STOP을 해제하거나
API를 호출하지 않는다. 이전 버전 세션에 체크포인트가 없으면 과업은 null로 표시한다.

대화 파일은 프로세스 잠금·revision 비교·원자적 교체로 보호한다. 오래된 콘솔의 쓰기와
손상된 파일은 오류로 거부한다. 동일 기록을 Windows와 WSL에서 동시에 쓰는 것은
지원하지 않는다. 아카이브 추가와 상태 교체는 하나의 트랜잭션이 아니므로 그 사이
프로세스가 죽으면 아카이브에만 발화가 남을 수 있다. 자동 아카이브 재생은 없다.
이 제한된 발췌는 오래된 사실을 모두 보존하는 장기 기억 검색 시스템이 아니다.

## 이번 검증

- Windows 61개 중 57개 통과, Linux 전용 4개 제외.
- WSL 전체 61개 통과. 기억 경계, 재시작, 오래된 확인 토큰, 중복 발행,
  최신 진행도, 월드 불일치, 위조된 완료 상태 및 합성 환경 체크포인트 검사 포함.
- PowerShell 구문 검사와 합성 체크포인트의 실제 조회 명령 통과.
- 추가 유료 API 호출 0회, 새 실게임 실행 0회. 이번 저장 I/O 변경의 실제 게임 검증과
  요약을 포함한 실제 모델 응답 품질 검증은 아직 하지 않았다. 기존 정책 실게임 결과와 구분한다.
- 로그: `results/memory-windows-tests-final.log`, `results/memory-wsl-tests.log`,
  `results/memory-inspection-check.json`. 기존 STOP 유지, 연구 명세 원문 변경 없음.
