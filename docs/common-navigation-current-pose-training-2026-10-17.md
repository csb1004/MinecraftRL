# 현재 시점 관측을 사용하는 공통 이동·정지 학습

`configs/common-navigation-current-pose-v1.json`을 실행 전 고정했다. 한 이동 모델에 목표 위치,
현재 시선, 직전 이동량을 넣고 다양한 출발/목표에서 학습한다. 기존 원목 actor/영상 본체/value는
동결하며 이동 residual/projection의 실제 가중치를 BC로 갱신한다. 임의의 새 RM vocabulary를 추가하지 않는다.

## 데이터와 실행 경계

- [입력 교정](common-navigation-pose-alignment-2026-10-17.md)의 train-a 시드104729 기록을
  감사 후 재사용한다. 같은 행동을 다시 실행하거나 새 수집 수로 중복 계산하지 않는다.
- 새 train-b/c 시드104743/104759에서 각각6목표, 학생60틱→해제→교사100틱 교정 수집을 한다.
  각 실행은6목표 중 최소5개 완료, 정상 실행/종료/확률 감사를 통과해야 학습으로 넘긴다.
  교사와 학생 완료는 별도 집계한다. 시작 방향·거울 배치·장거리/근거리 목표가 다르다.
- label-loss monitor는104761의 별도 기존 월드를 현재 입력 방식으로 새 수집한다.
  개발2월드2000003/2000029는 실제 실행 비교에만 사용한다. 이들 자료와 예약 최종 시드의
  자료는 gradient에 들어가지 않는다. 예전 서버 시점 replay는 모두 제외한다.
- 현재 학생 방문 상태에 대한 좌표 교사 질의는 알려진 평지 영역에서만 허용한다.
  원본 행동/logp/소유자/서버 관측을 고치지 않고 별도 정답/해시로 저장한다.

12틱 안정 도착을 양측 위치·접지·tick으로 확인한다. 게임당 제어175초/실측180초 이하,
STOP 이후 새 추론·행동0/입력 해제/소유 자식 PID 종료를 검증한다. 유료 호출0.

## 학습과 평가

시작은 v3 `584e7cf507a9ce4376f542f46269660fc40fc9f900e3878f425bc9f727066fb1`이다.
학습률1e-4, 16epoch, batch32, KL 한도3이며 학습 샘플 수에 따라 실제 갱신 수를 보고한다.
원본 모델 보존, 갱신된 actor hash, 저장/재로딩 오차0, label query 재생 감사를 요구한다.
체크포인트에 `pose_source=client`를 기록하고 RM 이동 executor도 같은 입력 계약을 따른다.
기본 모델 파일은 자동 교체하지 않는다.

학습 제외2월드에서 기준/후보를 같은 입력·목표·초기 화면/기억·샘플링 난수로 각각 실행한다.
12목표 중10개 이상 안정 도착, 각 월드 도착수 악화 없음, 총 도착 증가 또는 같은 도착수에서
행동 감소를 통과 기준으로 유지한다. 완전히 같은 코드/JAR에서 대조한다.
평가 후 일반 반경 진입 회귀와 자연 지형 이동/위험 회피로 확장할 근거를 판단한다.

출력은 `results/common-navigation-current-pose-20261017`이다. 준비 도중 추가한 수집 품질 gate는
게임 실행 전 `preexecution-plan-amendment.json`에 별도 기록했으며 최초 selection과 모든 시작
월드를 보존했다. 월드/목표/학습률/평가 조건은 변경하지 않았다.
이 문서는 실행 전 조건이며 실제 학습·일반화·전체 과업 성공 보고가 아니다.
