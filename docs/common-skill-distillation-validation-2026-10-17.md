## 실제 학습

v2와 같은 train 정답 1,908개(학생 방문 상태 질의 1,036 + 실제 교사 872), 같은 10개 sidecar SHA,
같은 시작 baseline을 사용했다. 학습률 1e-4 / KL 한도 3 / 16 epoch에서 **960 optimizer 갱신을 보존**했다.
최종 KL 1.0873, train canonical NLL 4.8395→2.3416, 별도 교사 development NLL 2.8091→2.6596.
638,746개 이동 residual/projection 파라미터만 갱신했다. 원목 actor·본체·value 보존, reload 오차 0.
학습 345.765초, PyTorch peak allocated 450.596 MiB.

후보: `bc/mlp/checkpoint.pt`, SHA256
`584e7cf507a9ce4376f542f46269660fc40fc9f900e3878f425bc9f727066fb1`.
학습률과 KL 한도를 함께 바꿨으므로 어느 하나의 인과 효과로 분리하지 않는다.

첫 출력 `results/common-navigation-distill-20261017`는 새 확률 진단의 singleton 차원 오류로
갱신 전 중단됐다. 갱신 0 / 게임 0이며 정책 실패 표본이 아니다. 원본 오류를 보존하고 실제 공식
VPT head의 다중 행 검사로 고친 뒤, 같은 월드/목표의 별도 retry1 출력에서 실행했다.

## 자원과 해석

실게임 추론 중앙값 48.397–50.569 ms, 95백분위 59.398–64.951 ms.
전체 제어 주기 중앙값 118.471–127.437 ms, 95백분위 136.981–158.387 ms.
PyTorch peak allocated 1,915.001 MiB / reserved 2,126 MiB. 이 값은 다른 프로세스의 VRAM을 제외한다.

도착 판정은 서버 거리 0.35블록 이하·높이 차 1.5 이하·GUI 닫힘이다.
도착 후 정책의 안정 정지나 낙하 회피는 아직 평가하지 않았다. 좌표는 privileged이며 영상 전용 결과가 아니다.
실행 중 teacher/API 제어 0, 새 PPO 갱신 0, 최종 평가 시드 사용 0, 기본 정책 자동 교체 0.

CPU의 별도 59개 train 상태/대체 목표 입력 진단에서는 회전 기대값 방향 일치가 기존 57/59,
후보 54/59였다. 따라서 기존 정책도 수치 목표에 반응하고 있으며, 입력을 완전히 무시했던 문제로
단정할 수 없다. 이 진단은 실제 행동/목표 성공 표본이 아니다.

실제 방문 상태 중 목표 방향 오차가 45도 초과일 때 전진한 비율은 기존 67/334(20.1%),
후보 9/148(6.1%)였다. `action-diagnostics.json` 및 `navigation-trajectories.png`를 보존했다.
회전 전에 전진해 크게 도는 행동이 줄었다는 기술적 관찰이며, 방문 상태가 다르므로 이 비율 자체의
독립 인과 효과를 주장하지 않는다. 점프는 기존 5회/후보 0회였다. 평지 교사에는 점프 시연이 없어
계단 등에서의 행동 보존을 이 결과로 가정하지 않는다. 원목 정책은 동결됐고 기본 이동 정책은 유지한다.

Windows 전체 824검사(799통과/25환경제외), 실제 head 관련 WSL 31검사 및 추가 common-navigation
7검사를 통과했다. 이후 발견한 자동 완료 마커 뒤 수동 STOP 추가 시 재무장되는 경계를 고쳐
STOP 관련 4검사를 통과했다. 소프트웨어 검사는 위 실제 게임 결과와 별도로 해석한다.

후보를 고정한 [새 난수·이전 조건 회귀](common-skill-regression-protocol-2026-10-17.md)를 이어간다.
자연 지형·탐색·채굴·제작 전체의 일반화 완료는 아니다.
