# 공통 이동의 학생 방문 상태 감독

사용자의 공통 스킬 학습 지속 지시에 따라 진행한다. 특정 실패 저장본에 행동 규칙을 붙이지 않고,
목표 방향·거리·출발 방향을 조건으로 받는 기존 신경망 이동 head를 실제로 갱신한다.
장기 연구 및 돌도끼/원목64 목표는 유지한다. 이번 단위는 서버 좌표를 받는 평지 이동이며
시각 전용, 자연 지형 안전, 제작 학습 또는 전체 공통 스킬 완성으로 해석하지 않는다.

직전 v1에서는 학생의 근거리·큰 회전 상태21개가 감독에서 제외됐고 새 교사 정답에는2개만 있었다.
이 가설을 확인하기 위해 학생이 실제 방문한 **train** 상태에도 명시적인 평지 교사 정답을 질의한다.
이는 사후 scripted expert 질의이며 당시 실행된 행동, 사람 시연 또는 실제 교사 rollout이라고 부르지 않는다.
원본 행동/logp/trajectory는 불변으로 보존하고 정답은 별도 파일로 남긴다.

## 고정 조건

- 설정 `configs/common-navigation-v2.json`, 결과 `results/common-navigation-dagger-20261017`.
- baseline은 기존 PPO `e033f1ef...8acaea`; 실패한 v1 후보를 시작점으로 쓰지 않는다.
- 새 train2월드: 학생만 최대100틱/목표,6목표. scripted 교사 행동 전달0.
- 이전 train8실행을 함께 사용한다. development/final 상태는 gradient에 사용하지 않는다.
- 이미 감사된 실제 관측에서만 정답을 생성한다. official VPT 변환/양자화와 왕복검사를 적용한다.
- 교사 적용 범위는 생성된 recovery arena의 열린 평지다. GUI/비정상 높이/범위 밖은 제외하고 수량·사유를 기록한다.
- BC lr1e-5, batch32, 최대16epoch, 기존 희소 상태 가중치, KL계수.01.
  기존 실패 head에 지나치게 묶이지 않도록 평균 KL 한도를.03에서.1로 바꾼 별도 조건임을 명시한다.
  한도 초과 epoch는 rollback. 따라서 개선돼도 데이터 추가만의 인과 효과로 단정하지 않는다.
- 원목 actor/영상 backbone/기억/value는 동결. 실제 actor 변경량, 저장/reload 및 자료 lineage 확인.
- 새 development2월드에서 baseline/candidate를 동일 시작본·samplingseed17231로 비교한다.
  목표들은 각 월드 안에서 순차적이고 독립 표본이 아니다. 평가 실행 중 교사/API 행동0.
- 채택 후보 조건: 도착 수가 증가하거나 같으면서 행동 수 감소. 한 쌍의 결과만으로 기본 정책을 자동 교체하지 않는다.
  통과하면 다른 sampling seed 및 기존 공통 개발 조건의 회귀 확인을 이어간다. 실패하면 train 상태를 더 분석·보강한다.
- 제어175초 예산/실측180초 이하, STOP 후 새 추론·행동0/키0/소유PID0 확인.
- 최종 평가 시드5개는 건드리지 않는다. 유료 API/Colab/게시0.

위 수치는 사전 실행 계획이다. 실제 완료/실패·미실행은 결과 ledger로 구분한다.
