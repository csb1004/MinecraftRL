## 언제 시작하는가

작업대 생성·배치·3×3 사용의 이번 검증을 마치면 **다음 연구 단계는 첫 소규모 RL 실험**이다.
모든 Minecraft 제작법·장비·대화 기능 완성을 기다리지 않는다.
연구 명세 10절은 결정적인 조합·인벤토리 처리를 규칙 기반으로 허용하고,
이동·탐색·채집 등에서 사전학습 정책을 강화학습으로 개선하는 방향을 유지한다.
현재 제작 보조를 학습 정책 성능으로 합산하지 않는다.

## 첫 과제와 유한한 진입 검사

첫 과제는 원목 1개 자연 획득으로 한정한다. 시간 상한은 실행당 제어 180초다.
기존 나무 채집 정책을 기준선으로 두고, 정책 종류·가중치·조건 입력·학습 대상 파라미터를
학습 전에 고정한다. VPT 단독에 자연어 지시 능력을 부여했다고 해석하지 않는다.

1. 실제 채집 transition에서 보상 연결을 검사한다. 서버가 확인한 인벤토리 획득을 사용하고,
   최초 목표 도달에만 보상을 지급한다. 드롭→재획득 반복이나 GUI 미리보기로 보상을 만들지 않는다.
   목표 도달 후 행동 권한을 회수한다. 취소와 시간 제한은 목표 달성과 별도 표기한다.
2. 소량의 실제 rollout에 대해 `log_prob`, value, recurrent state, reset/termination mask,
   이전 정책 확률과 reward를 저장하고 정합성을 확인한다. 추론 전용 `no_grad` 경로를 학습으로
   착각하지 않는다. advantage/return 계산에서 취소·시간 제한 처리와 bootstrap 규칙을 명시한다.
3. 격리 환경에서 **한 번의 forward→backward→optimizer step**을 실행한다.
   유한 loss/gradient, 실제 파라미터 변화, optimizer state, checkpoint 재로딩을 증거로 남긴다.
   이것은 학습 파이프라인 실행 성공이며 성능 향상 증거는 아니다.
4. 통과하면 제한된 업데이트 수의 파일럿을 실행하고 학습 전후 같은 평가 조건에서 비교한다.
   학습 seed/월드와 평가 seed/월드를 분리한다. 이미 디버깅에 사용한 고정 5개는 개발용으로
   표시하고, 일반화 성과를 주장할 별도 평가 월드는 학습에 사용하지 않는다.

보상은 skill reward와 RM 완료 신호, human prior를 분리해서 기록한다.
GUI 보조 행동은 학습 정책의 on-policy rollout으로 넣지 않는다.
정책이 실제 실행한 행동과 저장된 log probability가 일치해야 한다.
작업대 시험의 동일 저장 월드 복제 5회는 서로 다른 지형에 대한 일반화 평가가 아니다.

## 구현 후보와 자원 판단

기존 설계대로 MineStudio는 후속 학습 환경 후보다. 공식 문서에는 PPOTrainer의
rollout 수집, GAE, policy/value loss, backward/optimizer, checkpoint 경로가 설명되어 있다.
현재 설치된 MineRL/STEVE-1 추론 환경과 호환된다고 가정하지 않고 별도 환경에서 확인한다.
프레임워크 교체 자체를 학습 완료로 계산하지 않는다.

- [VPT 공식 저장소](https://github.com/openai/Video-Pre-Training)

자연 채집 실행에서 GTX 1060 3GB의 장치 전체 VRAM 최고 표본은 약 2781 MiB였다.
이것은 추론 관측이며 학습 메모리는 미측정이다. 학습은 활성값·gradient·optimizer state까지
측정한다. 부족하면 OOM과 설정·배치·파라미터 범위·할당량을 보존하고 동일 실험의 Colab
실행 파일을 준비한다. 학습 크기를 조정할 때 학습 대상 변경도 명시한다.
실제 Colab 연결과 유료 자원은 기존 별도 승인 경계를 유지한다.

첫 업데이트 시작 시점은 위 소규모 연결·자원 검사가 통과하는 때다.
향상까지 걸릴 학습 시간은 지금 확정할 근거가 없으며, 학습 곡선과 평가 결과로 판단한다.
이번 단계는 장기 동반 에이전트 연구와 연구 명세 원문 20항목을 축소하지 않는다.
