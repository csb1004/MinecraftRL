## 전환 계약

동일 coverage 가중치 `473142f1283521eb4417d3b4c6f568af27ad4b1a83113c4b506c9f2f6da153dd`를 사용한다.
처음에는 원래 wood 임베딩과 v4 나무 RM으로 실행한다. 기존 `StallDetector`/`wood_sample`의 첫 stalled 근거가
있을 때만 다음 정책 입력의 목표 임베딩을 바꾼다. 탐색/접근 정체와 실제 순환 근거를 그대로 기록한다.
이는 privileged server 위치·시선·대상·인벤토리를 사용하는 감지이며 영상 전용 조건이 아니다.

- 대조는 `wood_9711.npy`, 개입은 동일 latent의 `explore_9711.npy`이다. seed9711은 고정하고 더 좋은 draw를 골라 쓰지 않는다.
- 가중치·순환 기억·샘플링 RNG를 재설정하지 않는다. 중립 tick, 직접 회전, 좌표 경유점, 교사/API 행동을 주입하지 않는다.
- 게임에 전달되는 모든 행동은 같은 STEVE-1 후보의 출력이다. 목표 임베딩·단계·실제 적용/commit 여부를 전이와 함께 남긴다.
- 개입은 에피소드당 최대1회이다. 실제 원목 raw stage가 mine/collect가 되면 원래 wood로 복귀한다.
  새 화면, 새 위치, 회전만으로 복구 완료를 선언하지 않는다. 재무장/재개입은 하지 않는다.
- 그렇지 않으면200서버tick 예산에 도달한 전이 뒤 wood로 복귀한다. 제어는 전이 경계에서 바뀐다.
  실제 tick delta를 기록하고1tick 조건을 감사한다. 예산 초과를 성공으로 처리하지 않는다.
- 전체 제어는 최대180초이다. RM 수락·환경 종료·STOP가 전환보다 우선한다. STOP 뒤 새 추론/행동 전송을 금지하고
  입력 해제·소유 자식PID 정리를 확인한다. 추론 후 폐기된 행동은 적용된 개입으로 세지 않는다.
- 모든 자료는 eval/diagnostic 전용이며 PPO/BC 학습 적격성을 false로 둔다. 상위 나무 목표·RM 인스턴스·보상은 그대로 보존한다.

## 실행 순서와 판정

개발 fixture104761의 기존 development-corner ZIP으로 wood 대조→explore 개입 각1회, sampling seed9721을 사용한다.
동일 초기 snapshot/서버/기억/화면을 검사하고 개입 직전 prefix·실제 trigger 상태·기억·화면도 비교한다.
차이가 나면 두 실행의 관측 결과는 보존하되 전환만의 인과 대조로 주장하지 않는다.

이 두 실행을 감사한 뒤 explore에서 실제 개입이 commit되고, 개입 뒤 정체 시점 대비 시선 차이20도 이상 및
수평 변위0.5블록 이상이 모두 관측되면 다음 조건으로 확대한다. 이것은 추가 검사 입장 기준일 뿐 우회 성공이 아니다.
확대 시 development-far에서 explore→wood 각1회(sampling9722), 기존 natural2000029에서 wood→explore 각1회(sampling9723)를 한다.
나머지4조건은 최초 두 실행이 기준에 미달하면 미실행으로 남긴다. 최대 성능 진단6회이며 미실행은 분모에서 제외한다.

각 실행에서 실제 서버 인벤토리·통로 횡단·나무 재접근·획득량·실패 원인·추론/전체 제어주기 중앙값/p95·GPU 메모리와
STOP 뒤 행동0·해제키0·잔존 소유PID0을 기록한다. 전체 획득과 최초 정체 전 성공/개입 후 성공을 구분한다.
초기 준비·토스트·teacher 화면 재생을 실제 정책 성과로 세지 않는다. 학습률/가중치 변경이나 자연어 능력 일반화는 주장하지 않는다.

실제 개입이 가능한 경우 별도 취소 검사1회를 추가할 수 있다. 첫 개입 행동 확인 뒤 소유한 자동 STOP 요청을 만들고
취소·입력 해제·프로세스 정리를 감사한다. 사용자의 수동 STOP를 덮어쓰거나 소비하지 않는다.
이 취소 검사는 성능 성공/실패 표본에서 제외한다. 실패/STOP/OOM은 원본 로그를 보존한다.

완료된 원본 수집·재생·학습은 재실행하지 않는다. CLI 변경 전 소스 bytes/hash를 별도 보존한다.
실제 프로젝트 위치·Windows PowerShell·격리 WSL 실행을 유지한다. 최종5시드/기본 정책/연구 명세/유료 범위는 변경하지 않는다.
