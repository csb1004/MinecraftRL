# 복구 시작 BC 대조 조건 — 2026-10-09

사용자가 중간 재승인 없이 로컬 개선을 계속하도록 승인한 후속 실행이다.
[관측된 시작 행동 병목](correction-action-diagnosis-validation-2026-10-09.md)을 검증한다.
가설은 시작 정답의 희소한 갱신이 첫 복구 행동 학습을 제한한다는 것이다. 훈련 시작점 자체가
개선되지 않으면 표현/갱신 문제를, 훈련만 좋아지면 다양성/일반화 문제를 우선 조사한다.

## 고정 비교

- 원본 masked correction 특징/plan과 train4/dev2 분할을 그대로 사용한다. 개발 자료로 갱신하지 않는다.
- 양 조건 모두 시작 체크포인트는 `masked-correction-training-20261009/checkpoint.pt`,
  SHA `ed39af3d0df57ebcc6c8b1b98f7aa12d836d5a7cf120d1fce1911f884da29525`다.
  캐시의 frozen prefix는 같지만 마지막 기억층 이후는 현재 부모로 다시 계산한다.
  KL 참조도 현재 부모가 자신의 전체 문맥에서 생성한 특징/확률이다. 이전 부모 특징에 새 actor를 끼우지 않는다.
- `uniform`: 교사 포함 130window를 두 번, 총260갱신.
- `onset`: 동일한 교사 포함130window 한 번 + 시작 window130번, 교대로 총260갱신.
  시작 window는 첫 교사 정답1개와 바로 전 문맥7개다. 네 훈련 시연을 균형 순환한다.
  모든 원본 교사 정답은 양 조건에 들어가고 학생/중립의 직접 행동 손실은0이다.
- 양 조건 모두 AdamW lr5e-6,weight_decay0,KL계수1,gradient clip1,순서seed9605,
  학습 범위 actor+tail+마지막 기억층, value/시각층/앞선 기억층 동결이다.
  기존보다 학습률이10배인 별도 pilot이다. 조건 간 비교는 비중 효과를 분리하지만
  과거 lr5e-7 실험과의 차이를 비중 하나의 인과 효과로 주장하지 않는다.
- window 이전은 현재 가중치로 episode0부터 순차 no-grad burn-in한다.
  양 조건은 갱신 횟수와 gradient window 최대8을 맞춘다. 정답 노출 수/문맥 길이는 다르므로
  동일 wall-clock 비용이라고 주장하지 않고 실제 시간·메모리·노출 수를 보고한다.
- 각 조건은 같은 부모에서 시작한다. 조건당260갱신, 총520갱신을 상한으로 고정한다.
  52갱신마다 train 첫 행동만 계측한다. 개발 전체는 학습 전후에만 측정한다.
  비유한 loss/gradient/가중치, STOP, 소스 변경은 즉시 중단하고 오류·부분 기록을 보존한다.

## 측정과 실제 평가 경계

첫 행동·first8·교사 전체·나머지 교사 구간 NLL/명령 확률을 분리한다.
camera gate를 포함한 yaw 방향과 공격 해제+회전의 결합 확률을 측정한다.
180도에 가까운 회전에서는 양 회전 방향 모두 우회 시작에 유효할 수 있으므로 정답 yaw 부호와
공격 해제+어느 쪽이든 회전을 따로 보고한다. 움직임 확률을 실제 접근/탈출로 해석하지 않는다.

각 checkpoint의 저장/reset/reload 개발 전체 출력이 일치하고 입력/원본 hash가 유지되어야 한다.
엄격 KL<=.03 gate는 기존 의미 그대로 별도 기록하며 기본 정책 승격은 하지 않는다.
다음 조건을 만족한 후보만 제한된 실제 진단에 진입한다.

1. 개발 첫 교사 행동 평균 NLL이 부모보다 최소1 낮고, 공격 해제+회전 확률의 평균이 부모보다 높다.
2. 개발 첫 행동을 제외한 교사 NLL이 부모의110% 이하이며 모든 지표가 유한하다.
3. 실제 가중치 변화·value 불변·reload 일치·전체 영상 추론과 cached-prefix 경로 일치를 확인한다.

진입한 각 후보는 기존 긴 벽2000003과 자연2000029에서 학생 단독으로 최대180초씩 진단한다.
대조는 같은 부모로 새로 실행하며 초기 서버/기억/픽셀을 비교한다. 완료된 옛 게임을 재실행하지 않고
새 조건의 대조로 보존한다. 양 후보 진입 시 후보2종+공통 부모의 최대6게임이다.
획득은 실제 서버 인벤토리, 우회는 실제 통로 통과·재접근으로 판정한다.
STOP 뒤 정책 전송0·키 해제·소유 PID 종료, GPU/추론/제어 지연·실패 원인을 기록한다.
진입하지 못한 조건은 미실행이며 게임 실패 표본이 아니다.
