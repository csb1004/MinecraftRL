탐색·자원 접근·귀환·추종·실패 복구에 함께 쓰이는 이동 능력의 기반을 다룬다.

## 시간 정합 탈락의 해석

개발 자료를 조정에 쓰지 않고 학습 영상 10개에서 기존 측정값을 그대로 재현했다.
모든 영상에서 검사한 -4..4프레임 중 시차 0의 상관관계가 가장 높았다.
입력을 인위적으로 ±1/±2프레임 옮긴 40조건은 기존 기준을 모두 통과하지 못했다.
기록 좌표의 yaw 변화와 마우스 입력도 시차 0에서 일치했다
(절대 오차 95백분위 최대 약 0.00005도). 좌표와 입력의 일치는 영상 정합을 단독으로 입증하지 않는다.

화면 전체의 가로 움직임을 yaw만으로 설명하는 측정에는 적용 범위가 있다.
예를 들어 gimpy는 원래 상관 0.799에서 정지 중 표본 0.940,
snippy는 0.510에서 정지 중 표본 0.899,
wimpy는 0.672에서 |pitch|<=45도 표본 0.960이었다.
다른 영상에서는 이 필터가 개선을 만들지 않았다. 따라서 모든 탈락을 같은 원인으로 설명하지 않는다.
이 결과는 이동과 시야 방향이 측정을 교란할 가능성을 보여 주는 탐색적 진단이다.
기존 탈락 판정·0.8 상관 기준·0.1 시차 여유 기준을 바꾸거나 탈락 영상을 정답에 편입하지 않았다.

## 출처 균형 옵션과 적용 보류 이유

`scripts/train_navigation_refinement.py`에 선택 옵션
`--human-source-balance sqrt-recording-alias`를 연결했다. 기본값은 `none`이다.
`src/minecraftrl/human_source_bc.py`는 해시로 묶인 학습 녹화만 사용한다.

기존 각도/거리 보정, 사람 자료 총 비중, 점프 시작 가중치를 적용한 뒤 출처별 손실 총량을 M이라 하면,
새 총량은 sqrt(M)에 비례하도록 배분한다. 각 출처 안의 상대 가중치는 보존한다.
로컬 교사의 개별 가중치, 사람 자료의 총 비중 25%, KL 및 배치 추출 방식은 그대로다.
메타데이터와 계산 영수증은 학습 보고서 및 체크포인트에 저장된다.

실제 로컬 17,240개+사람 1,313개 정답의 손실을 계산했다. 개발 정답은 이 계산에 쓰지 않았다.

| 사람 자료 손실 비중 | 기존 가중 방식 | 출처 균형 옵션 |
|---|---:|---:|
| cheeky-cornflower-setter | 90.08% | 64.44% |
| pokey-cyan-spitz | 6.07% | 16.73% |
| shabby-pink-molly | 1.81% | 9.14% |
| whiny-ecru-cougar | 2.04% | 9.69% |
| 점프 시작 전체 | 9.95% | 7.89% |
| 점프 시작+유지 전체 | 25.11% | 19.30% |

출처 비중은 완화되지만 점프 손실은 약 23.11% 줄어든다. 출처 내 점프 가중치를 보존해도
출처 간 동작 분포가 다르면 전체 동작의 비중은 바뀐다. 가장 작은 출처의 행당 배율은 약 5.04다.
사람 정답의 가중 유효 표본 수도 약 1,031.2에서 727.0으로 감소한다.
이는 측정한 플레이 성능 저하가 아니라 **학습 전 손실 배분의 경고 신호**다.

따라서 이 자료로 출처 균형 옵션을 바로 켜고 업데이트 수를 늘리지 않았다.
다른 출처의 단차 시연을 보강해야 한다. 거리>=1의 현재 계약에는 안정 정지 정답도 없다.
단순히 가중치를 바꿔 자료에 없는 동작을 가르칠 수는 없다.

## 검증과 실행 상태

- WSL의 실제 프로젝트 환경에서 관련 테스트 32개 통과: 출처/시작 가중치, 개발 자료 차단,
  CLI 조건, 실제 행동 헤드의 KL 축, 배치 중요도 보정 및 기대 기울기 보존.
- 새 데이터의 특징·행동·목표 재현, 기존 정답 연속성, 실제 손실 총량/출처/동작 비중 검증 통과.
- 첫 GPU 추출은 실행 명령에서 기존 WSL 라이브러리 경로를 누락해 cuDNN 초기화 중 종료했다.
  실패 폴더와 로그를 보존했다. 기존 실행기와 동일한 `LD_LIBRARY_PATH=/usr/lib/wsl/lib`로
  두 번째 버전이 완료됐다. 시스템 라이브러리나 드라이버를 바꾸지 않았다.
- 첫 시간 진단은 마지막 영상 프레임에 다음 메타데이터 좌표가 없는 경우를 처리하지 못했다.
  원본 실패를 보존하고 해당 속도를 unknown으로 둔 v2에서 완료했다. 이미 추출한 흐름 3개는 재사용했다.
- 이번 추가 정책 업데이트 0, 실제 게임 행동 0, API·유료·Colab·GitHub 게시 0.
  기본 정책과 연구 명세 해시는 그대로다. 최종 평가 5월드는 사용하지 않았다.
