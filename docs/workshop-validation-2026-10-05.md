공식 레시피 데이터 기반 계획·공통 grid 검사·재료 예산·일반 클릭·서버 커밋을 구현했다.

페이지/검색 탭 탐색은 구현했지만 이번 한 페이지의 재료 조건으로 다중 페이지 성능을 검증하지 않았다.
모호한 그룹 버튼, 원거리 작업대 탐색, 일반 대화/RM의 제작 요청 연결은 남아 있다.

학습 transition을 연결하고 한 번의 backward/optimizer 갱신부터 실행하는 것이다.
작은 학습 실험과 학습 전후 평가로 진행하며, 3GB GPU의 학습 가능 여부는 별도 실측한다.
