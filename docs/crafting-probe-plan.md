# 판자 제작 선행 검증 — 사전 고정 조건

현재 STEVE-1로 원목→판자 제작이 가능한지 확인한다. 대화/RM의 지원 목표는 확장하지
않으며 기존 정책 행동을 API 제작으로 대체하지 않는다. 추가 API 호출은 0회다.

- 기존 자연 수집 저장 슬롯 `sequence-20261004T025836469371Z`의 세대
  `28222939e73444be84ba333eedf2d4d8`: 참나무 원목 1개·흙 1개·판자 0개.
- 원본 대신 각 시행의 results 내부 저장소에 독립 복사. 같은 슬롯 이름으로 플레이어
  UUID를 보존하고 원본 pointer·manifest·zip 해시를 검사한다. 재료 지급 없음.
- 시드 104729, 130363, 155921, 196613, 262147. 같은 저장 지형의 난수 비교다.
- 문구 `craft wooden planks`, guidance 6.0, 기존 가중치 그대로. 문구를 결과에 따라
  바꾸지 않는다. 시행당 제어 180초, 초기화는 기존 600초 감독 규칙을 사용한다.
- 성공은 정책 제어 중 같은 관측에서 원목 순감소 ≥1, 판자 순증가 ≥4 및
  craft_item.oak_planks 통계의 baseline 대비 증가 ≥4를 모두 충족해야 한다.
  이는 보수적인 판정이다. 새 원목 획득이 소비를 상쇄하는 경우 별도 원시 증거로 분석한다.
- 통계만 증가하거나 판자만 증가하면 성공으로 보지 않는다. 초기 통계는 차감한다.
- 매 단계 프레임·행동·GUI 모니터·전체 관측·추론/제어 주기·GPU 사용을 기록한다.
  마지막 프레임, 중립 해제 전후 및 GUI 닫기 전후 인벤토리를 남긴다.
- GUI 닫기는 종료 정리 동작으로만 시행한다. 이때 회수된 결과는 cleanup_witness로
  분리하고 정책 회수 성공에 포함하지 않는다. 현재 관측에 커서 아이템이 없으므로
  자동으로 검증 완료라 표시하지 않고 관련 프레임을 추가 확인한다.
- 원시 정책 미완료와 기술 오류, 미실행을 구분한다. 기술 오류 시 남은 시행은 중단한다.
  창 닫기·입력 해제·STOP 후 새 정책 행동 0회·소유 자식 정리도 확인한다.

기존 episode 측정 루프와 감독기를 재사용하는 `craft-probe` 실험 경로를 추가한다.
종료 후 복사본에 월드 증거를 저장하되 사용자 수집 과업에는 제작 목표를 넣지 않는다.
실제 판자 성공 여부를 먼저 판정하며 막대기/작업대/곡괭이는 이번 실행 대상이 아니다.
