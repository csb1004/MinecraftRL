## 승인된 범위 안의 다음 단일 대조

현재 후보의 감사와 사전 기준/허용된 실제 검증을 끝내고 원본을 봉인한 뒤 새 실험을 준비한다.
동일 출발223ae0, 동일29,801정답·가중치, adapter833,082개, seed14101, 4×546업데이트와 clip1을 유지한다.
평지/단차/사람 비중 .5/.25/.25 및 배치16/8/8도 유지한다.
바꾸는 것은 단차8개를 양성1개+음성7개로 뽑는 표본 추출뿐이다.
각 클래스에서 골고루 섞어 순환하고, 기존 전체 평균 목적함수가 같도록 클래스별 표본 확률을 보정한다.

단차 행의 기존 중요도에 `(해당 클래스 크기 / 단차 크기) × (8 / 해당 클래스 배치 수)`를 곱한다.
따라서 점프 총 손실 비중 .10172562766505709와 비점프 총량, flat/human 손실과 유지 KL은 그대로다.
한정된 배치/gradient clipping에서의 경사 분산이 바뀌는 대조이며 optimizer 경로가 같다고 주장하지 않는다.
기존 uniform sampler를 그대로 실행해 flat/human 선택과 전역 RNG 진행을 보존하고,
별도 복제 RNG로 단차 슬롯만 교체한다. 비활성 옵션은 기존 경로를 그대로 둔다.

입력 오류(빈 클래스·잘못된 flag·배치 누락)는 거부한다. 모든 배치의1/7·16/8/8,
가중 목적함수의 기댓값, flat/human 인덱스와 전역 RNG 동일성, 기존 uniform 결과 보존을 검사한다.
실제 학습 보고서에 클래스별 노출 수와 점프 포함/미포함 경사 clipping 통계를 남긴다.
새 옵션과 감사 근거를 명시적으로 기록하고 재현 검증한 뒤에만 게임 검증한다.

기존16기준, 실제 평지/자연 각5/6, 분리 개발 조건을 바꾸지 않는다. 최종5시드는 미사용한다.
stochastic근거리정지 .85도 별도로 유지한다. 자연 실패 이미지는 학습하지 않는다.
정책 행동을 좌표 스크립트로 대체하지 않고, 기본정책·상위RM·연구명세를 유지한다.
