# 공통 스킬 학습 재개와 방향 점검

2026-10-22 사용자 재개 요청. 원문 연구 명세와 장기 목표를 유지한다.
현재 단계는 사람 플레이 사전학습을 활용한 재사용 가능한 하위 이동 스킬의 개선이다.
이동은 탐색·자원 접근·귀환·플레이어 추종·실패 복구에서 공유된다. 단일 나무나 벽,
고정 좌표에 특화한 제어 분기를 추가해 시험을 통과시키는 방향으로 진행하지 않는다.

이후4시간 작업에서 키 해제와 위치 안정이 실제 기록된 정지 참조를 추가했다.
의도·지면·안전·과업 완료 정답을 만든 것은 아니다. 여러 출처 자료의 실제 BC를 수행했고
평지 정지 유지와 자연 단차 이동을 함께 개선해야 한다는 병목을 확인했다.
최신 결과는 [4시간 결과 기록](common-skills-four-hour-results-2026-10-22.md)과
[입력·보정 분기 진단](common-movement-input-diagnostics-2026-10-22.md)을 따른다.
아래의 ‘현재’는 재개 시점의 상태이며 완료된 자료 수집/학습을 다시 실행하지 않는다.

## 현재 범위와 위험

- 기존 후보는 평지 좌표 이동에서만 개선을 보였고 자연 지형에서는 실패했다.
- 기존 사람 학습 자료가 하나의 녹화자 별칭에 집중되어 있다. 출처·장면 다양성을 먼저 확장한다.
- 현재 사람 자료 계약은 미래 위치를 참조 목표로 붙인 이동 모방이다. 사람의 실제 의도나
  안정 정지 정답을 관측한 것이 아니다. 이 자료만 늘려 정지 문제가 해결된다고 주장하지 않는다.
- 40프레임 구간과 고정 특징 학습에는 장기 기억·분포 이동의 한계가 있다.
- 좌표가 주어진 이동과 자율 목표 발견은 별개다. RM 연결 시 행동 선택·도달·기억 계약 차이도 남아 있다.
- 코드 점검상 로컬 교사와 반사실 목표 정답은 검증된 평지 시험장에만 제한된다
  (`navigation_supervision.py`, `navigation_goal_queries.py`). 자연 지형에 그 교사를
  그대로 적용하지 않는다. 평지 정지 정답과 사람 원거리 이동을 섞었다는 사실만으로
  자연 지형의 근거리 정지를 충분히 가르쳤다고 볼 수 없다.

## 이번 실행

1. 10월 19일 준비한 고정 메타데이터 선별을 한 번 실행한다. 학습/개발 별칭과 세션 분리를 보존한다.
2. 적격 구간이 있는 별칭마다 녹화 하나를 고정된 세션 해시 순서로 선택한다.
   같은 별칭에서 점프가 가장 많은 녹화만 고르는 대신 기존 구간 선별의 이동/점프 다양성을 유지한다.
   최대 학습 12·개발 4 녹화, 영상당 256MiB·총 4GiB다. 누락·상한 초과는 기록하고 임의 대체하지 않는다.
3. 기존 영상-행동 정합 기준과 모든 선택 프레임의 시각 검수를 적용한다.
   피해 정보 누락은 unknown이다. 수중·GUI·오버레이 등 현재 육상 이동 계약 밖 장면을 구분한다.
4. 적격 자료 수·출처·단차/비점프 사례·부족한 범위를 보고 학습 편입을 결정한다.
   추가 학습을 시작하기 전에 자료·손실·비교 예산과 성공 기준을 별도로 고정한다.
5. 공통 능력의 진전은 학습에 쓰지 않은 출처/지형에서 확인한다. 현재 시험 월드에만 맞는
   수치·키 입력 분기나 성공 기준 완화는 하지 않는다. 기본 정책 승격과 최종 평가도 별도다.

이는 전체 연구를 이동 과업으로 축소하는 설계 변경이 아니다. 이동의 제한된 교정 결과와
탐색→접근→채굴→수집, 제작 및 장기 RM의 통합 성과를 구분해 기록한다.
