## 고정할 경계

- 공통 이동은 탐색·자원 접근·귀환·추종·복구에서 재사용할 하위 스킬이다.
  특정 벽/나무의 좌표나 행동 순서에 맞춘 런타임 분기를 추가하지 않는다.
- 기존 학습/개발 별칭 구분과 미개봉 출처를 유지한다. 최종 평가 5월드는 열지 않는다.
- 새로운 자료의 관측·행동·출처가 검증된 뒤 학습한다. 영상 정합 조건을 바꾸면
  별도 프로토콜·대조군·원본 판정을 보존한다. 실패 영상을 통과시키는 임계값 탐색은 하지 않는다.
- 사람의 정지는 관측된 키 해제와 이동량으로 정의한다. 그 정지의 의도, 지면 접촉,
  안전성, RM 목표 달성을 추정하지 않는다. 학습용 참조 위치와 실제 과업 성공을 구분한다.
- 자료 보강과 가중 방식 변경의 효과는 고정된 대조 조건에서 구분한다.
  학습 손실 개선으로 실게임 성능 또는 RM 통합 성공을 주장하지 않는다.

## 실행 순서

1. 기존 12개 학습 별칭에서 최대 4개의 새로운 녹화 그룹, 4개 개발 별칭에서 최대 2개를
   고정 해시 순서로 선정한다. 실제 가용 그룹은 학습44·개발8이다. 소스 부족분은 대체하지 않는다.
   공개 메타데이터 최대2GiB, 영상 최대12GiB, 영상당256MiB, 재시도/대체0이다.
2. 기존 이동 관측 필터를 유지하면서 상승 점프·하강·평지·이동 후 정지 구간을 구분한다.
   전체 행동 범위의 다양성을 확인하고 영상 검수/시간 정합/공식 행동 매핑을 수행한다.
3. 적격 자료의 특징과 기존 자료 연속성을 검증한다. 정지 참조는 기존 원거리 참조와 별도
   의미 계약으로 검증하고 개발 자료는 기울기에 쓰지 않는다.
4. 자료의 출처×동작 분포와 실제 손실 비중을 확인한 뒤 학습 조건/예산/게이트를 고정한다.
   준비되면 기존 정책과 같은 초기 가중치·업데이트 예산의 비교를 실행한다.
5. 학습 단계 게이트를 통과하면 실제 로컬 교정, 입력 해제/STOP/소유 자식 종료를 확인한다.
   미실행은 성공/실패 표본에 포함하지 않는다. 기본 정책 승격은 별도의 근거가 필요하다.
