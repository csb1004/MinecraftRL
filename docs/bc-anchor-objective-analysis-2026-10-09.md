# BC의 부모 정책 유지 항 분석 — 2026-10-09

coverage BC 학습 진행 중 목적함수를 검토했다. 현재 학습 조건과 갱신 수는 변경하지 않았다.
현재 손실은 교사 정답 NLL + `KL(parent || candidate)`이며 계수는1이다.
공식 `CategoricalActionHead.kl_divergence`는 첫 인수의 확률로 가중한다.
`DictActionHead`는 버튼/카메라의 NLL과 KL을 각각 더한다.

한 상태의 각 categorical 분포를 자유롭게 정할 수 있다고 놓고, 부모 분포를 p, 교사 one-hot을 y,
후보를 q, KL 계수를 λ라고 하면 q에 의존하는 항은 다음과 같다.

`L(q) = -Σ (y_i + λ p_i) log(q_i) + constant`

정규화 제약 아래의 최적 분포는 `q_i = (y_i + λ p_i) / (1 + λ)`이다.
부모가 교사 정답에 거의 확률을 주지 않는 상태에서 λ=1이면 각 head의 정답 확률은 약1/2,
버튼과 카메라가 모두 교사 정답인 결합 확률은 약1/4가 된다. 더 많이 반복해서 학습하는 것만으로
이 목적함수의 선호가 교사 정답100%로 변하지 않는다.

이번 train11개 첫 정답의 실제 부모 확률을 대입한 독립 상태 최적 정답 결합 확률은
25.003%~25.067%, NLL은 약1.384~1.386이다. 계산 원본은
`results/onset-coverage-work-20261009/anchor-objective-analysis.json`에 보존했다.
이는 모델의 절대 상한이 아니다. 공유 가중치·다른 상태 손실·최적화 경로 때문에 이를 넘거나 못 미칠 수 있다.
또한 '정확한 버튼+카메라 정답'과 로그의 '공격 해제+임의 yaw'는 다른 지표다. 둘을 동일하게 해석하지 않는다.

현재265갱신의 train 첫 행동 NLL2.051 및 공격 해제+임의 yaw22.62%는 이 절충과 양립하지만,
이 근접성만으로 인과관계를 확정할 수 없다. 특히 개발 상태에 전이되지 않는 문제를 이 수식 하나로 설명하지 않는다.
개발 두 상태의 수식 계산은 가상 독립 상태 분석이며 개발 정답으로 학습한 것이 아니다.

λ=.1인 같은 독립 상태 계산에서는 정답 결합 확률이 약82.64%가 된다. 아직 해당 계수로 새 모델을
학습하거나 게임을 실행하지 않았다. 이후 계수 효과를 검증하려면 자료·부모·seed·갱신 수를 고정한
별도 대조와 자연 수집 행동 손상 검사가 필요하다. 현재 학습 도중에 λ를 바꾸거나 최종 평가 자료로
선택하지 않는다. 기존 엄격 KL gate와 기본 정책도 그대로 유지한다.

후속398갱신 점검에서는 train 첫 행동 평균NLL1.286, 공격 해제+임의 yaw36.07%가 관측됐다.
이 수치는 독립 상태 계산을 실제 학습의 확률 상한으로 부르면 안 된다는 점을 다시 보여준다.
공유 파라미터의 다른 상태 손실과 근사 최적화가 함께 작용하며, 계수 효과 자체는 대조 전까지 미확정이다.
