# 공통 단차 교정 자료와 전이

2026-10-23. 승인된 공통 스킬 학습의 후속 자료 구성이다. 연구 원문·상위RM·돌도끼/원목64
목표는 유지한다. 사용자는 필요한 확인사항이 없으면 개선을 계속하도록 승인했다.
같은 계획의 단계별 재승인이나 별도 에이전트를 요구하지 않고 주 실행 흐름에서 구현한다.

## 문제 근거

adapter-only223ae0는 실제 평지6/6·자연4/6, 두 상승 목표 각100행동·점프0이다.
기존 사람 train2,109정답의 근거리195개에는 점프가 없고 가까운 상승 목표도0이다.
기존 검증 녹화22개의 새로운40/80frame정지구간 검색에서도 해당 교정 시연을 확보하지 못했다.
6실패 관측×49사람 점프 시작 목표를 교차해도 실제 실패의 시각 특징에서는 점프 선택1/294뿐이다.
반대로 사람 시각 특징에6실패 목표를 넣으면 각9~29/49개에서 점프가 선택된다.
이는 시각 특징/시연 분포의 전이가 중요한 병목이라는 증거지만 CNN 자체가 손상됐다는 증명은 아니다.
근거는 `results/common-movement-branch-study-20261023/feature-goal-factorial.json`이다.

## 선택

가중치 비중만 추가 조정하면 자료에 없는 교정 상황은 남는다. 공식 영상 추가 검색은 장기적으로
필요하지만 이미 확인한 가까운 단차 교정 자료의 공백을 보장해서 채우지는 못한다.
따라서 **다양한 별도 훈련장에서 실제 학생 상태를 교정하는 시연 수집**을 다음 단위로 한다.
기존 자연 평가의 실패 화면에 임의 행동을 정답으로 붙이지 않는다.

새 조건은 기존 수집→원본 궤적→분리된 교사 정답→BC→동일 평가 흐름을 확장한다.
시각/기억 encoder와 게임 행동 공간, 목표10입력, 상위RM 실행 vocabulary는 유지한다.
교사는 제한된 두 높이의 지형을 알고 있으며, 이 privileged 감독과 학습 정책의 성공을 구분한다.

## 월드와 교사 계약

- `step_navigation`은 별도 명시적 종류다. 원본ZIP의 복사본을 고친 새ZIP/NBT만 사용한다.
  기존 월드·체크포인트·실패 궤적은 수정하지 않는다. 1.16.5와 프로젝트 내부 경로를 검증한다.
- 한 청크의 안전한 바닥(발 높이201), 한 블록 높은 넓은 플랫폼(발 높이202), 외곽 경계와
  충분한 머리 공간을 갖는다. 재질은 돌/흙/지속 잎 블록, 방향은90도 단위 회전, 경계 위치와
  출발 거리·yaw를 바꾼다. 원본 자연 지형의 좌표/벽 배치를 복제하지 않는다.
- 처음에는 train시드만 사용해6가지 조건을 미리 고정한다. 시작 높이는 낮은 바닥이다.
  목표6개는 가까운 상승→높은 평지→하강→먼 상승→높은 평지→하강으로 구성한다.
  좌표는 상대적인 훈련장 생성 규칙이다. 모델의 행동 분기에 실제 평가 좌표를 넣지 않는다.
- 준비 시 저장 NBT의 바닥·머리 공간·경계·회전·목표 높이를 검증하고 SHA256에 연결한다.
  외부 자연 지형이나 임의 metadata는 이 교사로 처리하지 않는다.
- 교사는 현재 client pose/heading과 실제 ground 관측, 선언된 훈련장의 단차 경계를 사용한다.
  기존 방향 제어를 재사용하고 상승 목표를 향해 경계에 접근할 때 jump를 제안한다.
  공중에서는 jump를 새로 제안하지 않는다. 내려가기/같은 높이에서는 강제 점프하지 않는다.
- 모든 행동은 기존 MineRL supervisor와 공식 행동 매핑을 통한다. 실제 교사/학생 owner를
  기록하고 점프를 전달했다는 사실만으로 단차 성공이라고 부르지 않는다.
- 수집은 기존 correction 모드의 학생 prefix→검증된 입력 해제→교사 흐름을 쓴다.
  기존 교정 흐름의 예산은 학생8행동→해제1행동→교사 최대100행동, 목표당 최대109행동이다.
  평가에서는 교사 없이 최대100행동이다. 한 실행 제어 최대180초, 도착은 서버/client 반경.35·높이.05·12틱 안정이다.
  교사 규칙이 실패하면 그 자료를 완성된 시연으로 넣지 않고 원본 실패를 보존한다.
- 실제 world/관측 바인딩, 체력 손실0, 모든6목표 도착, STOP 이후 행동0·입력해제·소유PID0을
  수집 적격 조건으로 한다. 교사 도착은 learned arrival 수에 더하지 않는다.

## 학습과 평가 경계

- 새 교정 정답은 실제 train 관측에만 연결한다. 자연 evaluate 궤적 및 개발/최종 자료는 배제한다.
- 기존 평지 교사의 반사실 목표 정답은 평지에만 유지한다. 새 단차 자료에 평지 가정을 적용하지 않는다.
- 새 자료의 수·높이별 정답/점프 시작·출처·실패/제외를 먼저 검증한다. 그 뒤 정확한 학습 혼합량과
  업데이트 수를 별도 실행 계획으로 고정한다. 자료 수를 미리 성공한 것으로 적지 않는다.
- 기존 사람2,109/355 및 평지17,240 정답은 보존한다. 기존 평지의 유지 손실과 새로운 단차
  감독을 구분한다. 초기 정책이 실패하는 새 단차 정답을 초기 정책과 같게 만들도록 유지 손실을 주지 않는다.
- 목표는 실제 가중치 학습이다. 교사 성공을 정책 성공으로 대체하지 않으며, 평가 실행에 교사를 넣지 않는다.
- 기존 점프/오탐/출처/정지/근원거리 행동 기준을 유지한다. 통과 시 평지5/6→자연5/6→분리된
  개발 월드 검증으로 이어간다. 중간/final epoch 선택, 최종5시드 사용, 기본 자동 승격은 하지 않는다.
- 유료/API/Colab 연결/공개 게시 없이 로컬에서 진행한다. Windows PowerShell과 WSL 격리 환경을 쓴다.

## 검토한 위험

단차 훈련장의 재질/배치만 외울 위험은 회전·경계·출발 거리·재질 다양화와 기존 자연 전이에서 확인한다.
새 교사 알고리즘은 관측/충돌/입력 시간의 검증을 먼저 거치며 일반 자연 길찾기로 주장하지 않는다.
교사 규칙·자료와 학생 정책을 섞어 결과를 높이지 않는다. 접근/정지의 회귀 및 사람 이동 정답 퇴행을
기존 기준으로 차단한다. 실험 전 소스를 고정하고 한 배치의 수집·감사 중에는 바꾸지 않는다.
