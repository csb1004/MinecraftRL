# 제작대 → 돌 도끼 → 추가 원목 64

사용자 지시: 제작대를 활용해 돌 도끼를 만들고 나무 한 세트를 캔다. 한 세트는 원목 64개다.
이전 원목64/흙4 달성 이력은 유지한다. 이번 목표는 돌 도끼 제작 이후 재고를 기준으로
**추가 보유 원목64**이며 이전 재고를 새 획득으로 세지 않는다. 실제 도끼 사용 증거도 별도로 요구한다.

시작 세계는 `goal-completion-20261016-memory-resume/worlds/priority-dev`의
`2b50d8ba1ad24cb7873266d456d29b4c` 복사본이다. 원본·이전 학습 가중치·실패본은 보존한다.
개발 seed104761, 회차 제어시간180초 이하. 최종평가용5시드 재사용, 유료 호출, 새 공개 배포는 하지 않는다.

검증 단위:

1. 재료를 소비해 제작대를 만들고 설치·열기, 나무 곡괭이 제작·장착. 서버 인벤토리/선택 도구/저장 블록으로 확인.
2. 신경망 정책으로 조약돌3개 획득. 곡괭이 사용·실제 재고·생존 상태로 판정. 미검증 조건을 성공 스킬로 등록하지 않는다.
   실제 채굴 후 좁은 구덩이(y61)에 도달해 제작 가능한 지상 공간 복귀가 추가로 필요해졌다.
   지상 제작대의 실제 기록 높이71을 사용해 y70 이상·접지·낙하0·활성 추격0·재료 조약돌3 유지와
   가까운 제작대 또는 검증된 설치 공간을 함께 요구한다. 점프 중 순간 고도만으로 완료하지 않는다.
   로컬 공식 prior로 만든 pillar-up 텍스트 조건은 미검증 후보이며 scripted 이동으로 대체하지 않는다.
3. 실제 버전 JAR 레시피로 돌 도끼 제작·장착. 도달 가능한 기존 제작대는 재사용하고, 멀어졌다면 새 제작 비용을 기록한다.
4. 이 시점 원목 재고를 기준선으로 잡아 추가64개를 수집. 서버의 도끼를 든 실제 파괴와 순재고 증가를 구분해 기록한다.
   정책이 다른 아이템으로 전환한 뒤 도끼 채굴 진전이 없으면 자동 반복을 중단한다.
   기존 GUI 도구 장착을 별도 명시적 보조 단계로 재사용할 수 있다. 이 단계는 재고·월드·임무 이력을
   유지하며 장착만 확인하고, 제작대 설치나 채굴·이동을 대신하지 않는다. GUI를 보지 못한 정책 기억은
   무효화한다. 장착 보조의 기여와 기억 초기화를 함께 기록하며 신경망의 자율 도구 선택 성공으로 세지 않는다.
   재장착 후에도 정책이 스스로 원목 슬롯으로 바꾸는 실제 실패가 확인돼, axe_wood에 한해 로컬 공식
   prior의 도끼 사용 텍스트 조건을 별도 개발 변형으로 허용한다. 프롬프트·조건 파일·모델 해시·guidance·seed를
   보존하고 조건 변경 시 기억을 초기화한다. 기준선/도끼 실적/현재 월드를 유지하며 원래 조건의 실패 기록을 남긴다.
   새 조건으로 직접 도구를 선택할 수 있는지 확인하므로 초기 재장착을 강제하지 않는다. 결과 없이 검증 스킬로 승격하지 않는다.
   wood-9에서도 도구 유지 실패를 확인해 다음 후보로 기존 돌 도끼를 첫 핫바 슬롯으로 옮기는 GUI 보조를 준비했다.
   재료·수량을 유지한 슬롯 교환과 양쪽 저장 NBT의 선택 슬롯/도구를 검증한다. 자율 정책 장착과 구분한다.
   이 후보는 단위 검사만 완료했으며 사용자 일시 중단으로 실제 게임에서는 미실행이다.
