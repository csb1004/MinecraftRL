# 오래된 목표의 실행 우선순위 — 승인된 구현 범위

사용자 승인: 미완료 목표를 삭제하지 않고 미완료 기간·실행 대기 기간을 반영한다.
하위 정책 보상/가중치/원문 연구 명세는 변경하지 않는다.

- 공통 우선순위 장부: 활성 세션 시간, 실행 가능 대기, 실제 서비스 시간을 분리한다.
- 기본 중요도 + 제한된 aging/명시적 활성시간 마감 가중치. 최대 대기 초과는 별도 공정 배정 규칙이다.
- 선행 작업은 의존 목표의 긴급도를 상속한다. 선택 자체는 서비스가 아니며 짧은 선택으로 대기 초기화 금지.
- 완료·취소·사용자 pause·STOP·미지원 skill·실패 재시도 차단은 우선순위보다 우선한다.
- 기존 RM 스케줄러의 실제 선택과 LLM 입력에 연결한다. 노드 이름을 바꿔도 같은 방법의 시간 이력은 보존한다.
- 기존 task session의 명시적 다중 목표 모드에서 지원된 wood/dirt 목표를 보관·전환한다.
  서버 인벤토리 완료 근거, 입력 해제, 추론 폐기, 월드 checkpoint 복원을 유지한다.
- TDD: starvation/선행 작업/짧은 전환/재계획/복원/pause/취소/STOP 검증 후 전체 Windows 검사.
- 게임·API·학습을 이 기능의 단위 검증과 혼동하지 않는다. 기존 완료 배치와 최종5시드는 재실행하지 않는다.

초기 비교용 설정: 최소 서비스 구간10초, 최대 실행 가능 대기60초,
미완료30초당5점(최대30점), 명시적 활성시간 마감 전30초부터 최대30점.
이는 조정 가능한 초기값이며 실제 게임의 최적값으로 검증하지 않았다.
