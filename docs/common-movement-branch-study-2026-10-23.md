# 공통 이동 보정망 간섭 대조

사용자 재개 지시에 따라 2026-10-23 시작한다. 이전 4시간 배치는 완료된 채 보존한다.
연구 명세·돌 도끼와 원목64 통합 목표는 유지하고, 이번 단위는 공통 이동의 단차/정지 간섭이다.

## 관측과 가설

이전 자료 추가 후보는 평지6/6, 자연3/6이었다. 상승 목표2개에서 점프0으로 예산을 소진했다.
이전 전체604관측의 분기 진단은 학습된 기본 보정망이 점프를 억제하며, 이를 추론에서 제거하면
평지의 불필요한 점프와 정지 실패가 증가함을 보였다. CNN 실패나 유일한 원인을 증명하지는 않는다.

가설: 같은 업데이트에서 기본 보정망과 새 시각 adapter를 함께 움직이는 것이 정지/단차 간섭을
강화할 수 있다. 기존 기본 보정망을 초기 정책 그대로 고정하고 adapter만 학습하는 대조를 한다.
두 조건의 초기 함수는 같으며 추론에서 분기를 끄지 않는다. 단차 앞 강제 점프는 추가하지 않는다.

## 잠근 조건

- 출발 d6137d, 사람 train2,109/dev355, 로컬17,240/monitor254 및 모든 원본 해시 유지.
- 학습 seed14101,4epoch×546=2,184갱신, lr0.0001, local24/human8, 사람 비중.25,
  시작 가중4, local KL1/global KL.01, adapter64, root context ignored, source balance none.
- 고정 epoch4만 평가한다. 개발 자료는 gradient·모델 선택·진입 기준에 쓰지 않는다.
- 대조는 이전 b87286 전체 보정망 학습과 비교한다. 이번 유일한 학습 개입은 optimizer 대상:
  1,471,828개 대신 adapter833,082개. 소스 변경은 학습 범위 선택과 보존 증명이다.
- 초기 함수·자료·예산·로컬 정답 동일 여부를 검증한다. 과거 게임과 인과적 짝 비교라고 주장하지 않는다.
- 기존 점프/오탐/부분집합/정지/근원거리 진입 기준을 그대로 유지한다. 통과 시 실제 평지5/6,
  자연5/6, 피해0·STOP후 행동0·해제·소유PID0을 확인하고 별도 개발 월드 검증으로 진행한다.
- 실제 제어는 매 실행180초 이내, delivered_mode, 도착 유지12틱. 최종5시드는 열지 않는다.
- 신경망 학습과 게임은 겹치지 않는다. 유료/API/Colab/공개 게시와 기본 정책 자동 승격은 없다.

## 검증 단위

1. 학습 범위의 초기 함수·RNG·기존 기본 동작 동등성과 실제 gradient/동결 검사.
2. 고정 source/자료/계획 아래 새 가중치 학습과 checkpoint 재로드·동결 tensor 증명.
3. 기존 행동 기준 검사와 실패 관측에서 새로운 후보만 재추론.
4. 진입 시 실제 게임·분리 개발, 미달 시 실패 원인별 다음 대조. 미실행을 실패 표본으로 세지 않는다.

작업 원본: `results/common-movement-branch-study-20261023`. 완료 기준을 낮추거나 단일 train 월드
통과를 일반 정책 완성이라고 부르지 않는다. 시간 입력·출처×전이 비중·표현 병목은 대조 결과 후 분리한다.

  근거리 하강14개는 존재한다. 로컬17,240개는 모두 높이 차0인 기존 감독이다.
