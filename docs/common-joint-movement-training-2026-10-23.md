# 같은 단차 자료에서 기존 이동 보정망과 어댑터 공동 학습

학습 방법은 저장된 시연과 검증된 목표 대조 정답을 이용하는 BC 미세조정이다.

상대 판단 후보17a42856은 2,184업데이트와 독립 검증을 마쳤으나 기존16기준 중15개만 통과했다.
필요한 점프5/61, 전진 정답에서 정지308/1,003, 근거리 stochastic정지.78088675로 충분하지 않다.
실제게임은 미진입이며 892파일을 봉인했다. 평균 정답 오차 감소를 공통 이동 성공으로 해석하지 않는다.

현재 어댑터만 학습하는 조건에서는 기존 이동 보정/시각투영12tensor도 동결되어 있다.
앞선 분기 진단은 이 기존 보정망의 점프 억제와 평지 정지 기여를 함께 확인했다.
이를 추론에서 제거하는 방식으로 해결되지 않았다. 현재 단차·제동 시연과 목표대조를 포함한 상태에서
기존 보정망까지 학습하면 두 기능을 함께 조정할 수 있는지 확인한다. 이는 검증할 가설이다.
이전 b872 전체보정망 실험은 출발 d613과 단차 시연 없는 자료를 사용했으므로 이번과 다른 조건이다.

바꾸는 것은 optimizer가 갱신하는 기존 parameter 범위다. 어댑터833,082개에서 기존 보정망을 포함한
1,471,828개로 늘린다. 신경망 구조나 초기 정책 함수는 바꾸지 않는다. 원래 base의 visual/goal6tensor,
영상encoder, value는 동결한다. 기존18tensor 전부가 계속 동결됐다고 보고하지 않는다.

다음 조건은 상대 판단 후보와 같다.

- 출발223ae08d, 기본41,387정답과 보정 가중치, 사람/평지/단차 분할.
- conditional-ranking 보조손실0.2, 동일4행 추가질의와 같은관측/예산1. 총8,736질의.
- 기본 및 대조 표본 순서, seed14101,4회차×546=2,184업데이트, 최종회차만 판정.
- AdamW1e-4, weight decay0, clip1, local KL1/global KL.01, 기존 retained population.
- 어댑터의 공간입력 보정8/저장1, ignored RM context, 기존12개 보정tensor에는 새 입력 변환 없음.
- 기존16기준→실제평지5/6→자연5/6, 개발 진입에는 별도 stochastic정지.85도 필요.
- 실제 제어180초 이내, 서버/클라이언트 안정도착12틱, 피해0·STOP후전달0·입력해제·소유PID0.

전체 갱신량과 자료는 같지만 학습변수·경사·clipping과 Adam의 경로가 달라진다. 계산량이 완전히 같다고
주장하지 않는다. 새 좌표 예외, 강제 점프, 개발 자료 학습 편입, 기준 완화는 추가하지 않는다.
돌 도끼/원목64 통합 목표와 연구 명세는 유지한다. 최종5시드와 기본정책은 보존한다.

검증은 실제 출발 actor에서 학습범위 변경 전후 state/RNG 동일, 학습20tensor와 동결6tensor를 확인한다.
학습 후 기존12tensor와 어댑터8tensor의 변경, 동결6tensor·value·root 보존 및 모든 표본 해시를 독립 검증한다.
ignored RM의 미사용 입력 열도 변하지 않았는지 검사한다. 선언한 범위만 바뀌었는지를 초기 측정값으로 확인한다.
합성 검사와 저장 관측 재추론은 실제 정책 성공으로 세지 않는다.
