# 레시피북 GUI 실험 조건 — 2026-10-05

사용자가 승인한 레시피북 경로의 실제 동작을 확인한다. STEVE-1 성능 표본과 분리한
명시적 GUI 보조이며 학습 모델·LLM을 호출하지 않는다. 게임의 고수준 제작 API,
레시피 지급 명령, 인벤토리 편집은 사용하지 않는다. 클릭 좌표·레시피 정체·해금 여부를
읽기 전용 관측으로 알아내므로 픽셀만 사용하는 정책 성공으로 해석하지 않는다.

기존 자연 제작 판자4·흙1 저장본을 독립 복사한다. 막대기/작업대를 각각 고정 시드
104729/130363/155921/196613/262147로 실행한다. 제어 상한은180초, 기술 오류가 나면
원인을 조사하고 그 실행을 따로 남긴다. 미실행은 성공/실패 표본에서 제외한다.

실행: 인벤토리 열기→책 열기(이미 열려 있으면 유지)→해금·단일 레시피 버튼·재료 확인→
일반 클릭으로 자동 배치→실제2×2 칸 배치/아이템/수량 및 결과 미리보기 확인→책 닫기→
결과 칸 일반 클릭1회→기존 회수·서버 확정·정지·저장 NBT 검사.
잘못된 레시피, 중복 선택지, 화면 밖 레시피, 재료 부족은 임의로 대체하지 않고 거부한다.
현재 페이지의 고정 두 레시피만 지원하며 검색/페이지 이동/그룹 선택은 미지원이다.

해금 조건은 실제1.16.5 JAR의 advancements/recipes JSON과 저장 NBT/advancements를
대조한다. 해금·화면에 표시됨·현재 재료로 제작 가능·실제 제작 완료를 구분한다.
막대기 획득 후 나무 곡괭이 해금도 저장 데이터에서 확인한다. 3×3의 실제 제작은 별도
재료 예산과 작업대 접근이 필요하므로 이2×2 성공률에 포함하지 않는다.

모델 추론 시간 대신 GUI 결정 시간을 기록하고, 실제 제어 주기/장치 VRAM/획득량/실패를
보고한다. GPU 모델 미탑재 결과를 기존 STEVE-1 추론 성능과 비교하지 않는다.
기본 수집 정책·RM·연구 명세는 바꾸지 않는다.
