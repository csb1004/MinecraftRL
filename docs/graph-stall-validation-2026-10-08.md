기존 실제 궤적14개, 8,788전이를 **오프라인 재생**했다. 새 게임/학습/LLM 호출0.
결과: `results/graph-stall-replay-20261008-v3/report.json`, 전이별 판단 JSONL,

## 구현한 것

`stall_detection.py`의 감지기는 위치/시선/내부 단계/대상의 방향 그래프를 사용한다.
실제 시간 순서의 재방문에서 닫힌 경로를 추출한다. 같은 방향의 사이클은 시작점 회전만
정규화하고 역방향은 구분한다. 제자리 반복은 자기 루프와 행동 비중으로 따로 다룬다.
정적 그래프에 사이클이 있다는 사실만으로 정체라고 하지 않는다.

새 탐색 위치/시야, 최초 대상, 대상별 거리 최고 기록, 관측된 채굴 진행 최고 기록,
블록 소실과 인벤토리 최고 기록을 진전 근거로 사용한다. 위치 이동은 2블록 셀 신규성으로
측정해 목표에서 멀어지는 정상 우회도 허용한다. stage/target 왕복이나 채굴 수치 초기화,
아이템 버리기/재획득은 같은 기록의 진전으로 반복 인정하지 않는다.

관찰창은 search400/approach200/mine400/collect200 서버tick, 과업 증거 없는 탐색 예산800tick.
현재 고정한 개발 가설이며 모든 지형·도구에 적합하다고 검증한 값은 아니다. 단순 단계 왕복으로
타이머를 리셋하지 않는다. 같은 무진전 episode에 경보1회, 유효 진전 이후 다시 감시한다.
이미 끝난 과업/STOP 이후 update는 거부한다. world/task revision은 감지기 간 혼합하지 않는다.

기존 `ApproachRecovery`와 reward/actor/실행기는 수정하지 않았다. 새 감지기는
**재검토가 필요하다는 관찰 이벤트**를 반환한다.
해당 이벤트에 실행 권한은 없다. RM 보존/우선순위 변경, 실행 가능한 skill 검사, 실패 이력과
재시도 예산, LLM 응답 검증은 다음 연결 과제다. 기본 정책도 그대로다.

## 사이클이 의미하는 범위

전체 원본 경로 그래프의 별도 감사에서 blocked-0은 서로 다른 닫힌 경로8종, 반복된 경로2종을
보였다. 반복2종은 같은 구역에서 높이201↔202로 오가는 점프 순환이다. 자연 로컬 성공 궤적에도
닫힌 경로2종이 있었지만 반복은 없었다. 나머지 참고궤적은 연속 중복 노드를 제거한 경로에서
다중 노드 사이클이 없었다. 제자리 반복은 이 다중 노드 집계에서 제외된다.

blocked-0의 최초 경보 시점에는 같은 사이클2회 증거가 아직 부족해 `no_progress`로 분류했다.
나머지3개 실패 기록의 경보는 `stationary_repetition`이다. 수평 왕복 실패를 `repeated_cycle`로
분류하는 경계는 합성 검사로 확인했으며, 다양한 실제 수평 왕복 실패 자료 검증은 남아 있다.
새 위치 방문도 반드시 유용한 탐색이라는 보장은 없어 전체 과업 증거 없는 시간 예산을 별도로 둔다.

## 구현 중 발견해 수정한 문제

1. 첫 replay에서 `render_ready`를 관측 유효성으로 오해했다. Java 정의는 글로벌 청크 업데이트
   대기열이 비었는지이며 신선한 서버 관측 여부가 아니다. 이 조건으로 정상 궤적 대부분이 누락됐다.
   `results/graph-stall-replay-20261008/`은 원본 그대로 보존하되 성능 근거에서 제외한다.
2. 이 조건을 고친 v2는 교사 행동이 scalar/flat camera, 정책 행동이 1-element batch라는 형식
   차이로 첫 입력에서 중단했다. `results/graph-stall-replay-20261008-v2/` 오류를 보존했다.
   두 표현을 동일 서명으로 변환하도록 수정한 뒤 전체14개를 v3에서 다시 재생했다.
3. 마지막 manifest 경로 보호 검사에서 기존 ID의 underscore를 거부한 회귀를 발견해 수정했다.
   입력 경로 탈출/해시 누락/중복 ID/최종 평가 시드 포함은 계속 거부한다.

임계값을 결과에 맞춰 조정하지 않았고, 위 재생은 코드 결함 교정에 따른 것이다. 완료된 Minecraft
실행 배치는 재실행하지 않았다. 실패 산출물/검사 로그도 보존했다.
