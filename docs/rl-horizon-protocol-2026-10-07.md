# 보상 시간 규모 비교 — 실행 전 고정 조건

사용자 승인: 중간 보상 없이 할인/GAE/critic 비교와 제한된 실제 학습·평가, 결과에 근거한 수정까지 자율 실행한다. 기존 ce-debug 절차를 이어 적용한다. 재승인, Git, subagent, 전역 설정 변경, 유료/Colab 연결은 하지 않는다.

## 가설과 고정 범위

1행동=1서버 tick, 원목 첫 획득 +1/종료, backbone 고정·출력층 PPO, 부모 78회 checkpoint, 동일 24개 학습 궤적(16세계/4,855행동)을 유지한다. 저장 궤적은 부모 actor와 같으므로 첫 PPO 업데이트의 behavior 분포가 일치해야 한다. 추가 epoch/반복 데이터 사용의 한계는 기록한다. 최종 평가 5시드는 사용하지 않는다.

가설: γ=.99/λ=.95의 짧은 직접 보상 영향과 부정확한 critic 의존성이 개선 부재에 기여한다. 신호 변화만으로 성공을 주장하지 않는다. 동일 자료에서 γ=.99,.995,.999 × λ=.95,.99,1의 9조합을 계산한다. 양수 advantage 개수는 기술 지표이며 선택/채택 기준이 아니다.

## 시간 초과와 가치 재학습

시간 초과를 종료 실패 0으로 바꾸지 않는다. 저장 final.png와 committed final recurrent state로 다음 특징을 복원하고 부모 bootstrap 재현을 검사한다. 새 γ에서 기존 bootstrap은 정답으로 사용하지 않는다. 0≤할인 미래 획득 보상≤1의 범위를 보조 민감도 계산에 사용한다.

각 γ에서 seed 전체를 제외하는 교차 검증을 수행한다. 동일 선형 ridge=1 critic을 영 초기 prior에서 맞춘다. 종료 궤적은 직접 할인 return, 잘린 궤적은 이전 pass critic의 마지막 특징 예측을 [0,1]로 제한한 bootstrap을 사용한다. 초기 bootstrap .5, 정확히 3회 fit으로 고정한다. bootstrap 추정은 관측된 정답이 아니며 실제 종료 궤적의 오차와 잘린 구간의 범위 위반을 별도로 기록한다. 모든 궤적을 학습에 포함하고 실패 자료의 부족을 보고한다. 기존 early>=100 기준도 그대로 보고하되 새 γ에서는 이전 γ 점수와 직접 우열 비교하지 않는다. 시작부터 100tick 이내 오차도 추가로 보고한다.

정책 advantage는 자신의 세계를 제외해 학습한 critic으로 계산하고, 정책과 함께 학습할 value 출력층은 해당 γ의 전체 학습자료 fit으로 초기화한다. 이는 별도 실험 분기이며 과거 critic 채택 실패를 뒤집거나 기본 모델에 승격하는 것이 아니다. 실제 정책 비교에는 gamma/lambda 2×2인 (.99,.95),(.999,.95),(.99,1),(.999,1)을 모두 사용해 주효과와 상호작용을 구분한다. .995/.99는 저장자료 진단만 수행한다.

## 제한된 학습과 실게임

4개 분기는 동일 부모 actor, 새 optimizer, epoch=1, lr=1e-5, clip=.2, reference KL coefficient=.01, minibatch16, 동일 shuffle seed7301, 동일 전체 배치 advantage 정규화를 사용한다. critic만 분기 타깃에 맞게 초기화한다. 원시 behavior logp 재현 오차≤2e-4, 유한 gradient/파라미터, checkpoint reload를 요구한다. raw actor/reference KL 최종 평균>.03 또는 비유한 출력이면 해당 분기 실게임은 차단하고 원인을 기록한다. 정확히 한 번씩만 학습하며 결과가 나쁘다고 seed나 epoch를 바꾸어 재시도하지 않는다.

평가는 기존 개발용 2000003/2000029, 각 2회, 부모+4분기 총20회 최대180초다. 반복1은 부모→(.99,.95)→(.999,.95)→(.99,1)→(.999,1), 반복2는 역순으로 고정한다. 각 조건에서 두 seed를 순서대로 사용한다. 기존 immutable world/embedding을 사용하고 서버 초기 상태/순환 상태와 화면 차이를 기록한다. 기술 실패는 게임 성공/실패로 세지 않으며, 0행동 preflight 일시 실패에만 별도 로그를 보존하고 한 번 복구할 수 있다. 새 수동 STOP은 즉시 존중한다. 시작 시 이전 취소 검증용 STOP은 이번 사용자 재개 승인으로 보존 후 해제한다.

일차 지표: 실제 성공 수/유효 시행 수. 이차: 성공까지 tick과 제어시간, 미성공은 180초로 제한한 시간 점수. 모든 시도·미실행·중단·잔존 PID·보상 이후 행동 금지·VRAM·추론/제어주기 중앙값/p95를 보고한다. 2개 개발세계×2회는 일반화 증거가 부족하므로 개선이 보여도 기본 정책 자동 승격은 하지 않는다. 후속 개선은 우선 로그 기반 오류 수정과 연구 권고이며, 실패를 숨기거나 평가 데이터를 critic 학습에 넣지 않는다.
