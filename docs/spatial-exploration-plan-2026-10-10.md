# 방문 기억과 F3 좌표 연결 계획

사용자 승인: 방문·경로 기억으로 미방문 경로 우선, 집 등 목적지는 반복 방문 허용.
추가 지시: F3 좌표 활용. 기존 RM/보상/신경망 행동 경계와 연구 명세는 유지한다.
writing-plans 절차를 적용하며 사용자 지시에 따라 주 실행 흐름에서 순차 구현한다.

## 실행 단위

- [x] 좌표 관측 출처 계약: F3 화면 OCR과 privileged server 좌표를 구분한다.
  F3 판독 실패/음수/중복 XYZ/비정상값을 거부하며 서버값으로 조용히 대체하지 않는다.
- [x] 방문·방향별 경로 지도: 체류와 방문 분리, 관측 공백/순간 이동으로 가짜 연결 생성 금지,
  음수 좌표·높이·차원·월드·실험 분할 구분. 저장 후 재시작에서도 지도/랜드마크 보존.
- [x] 탐험/귀환 목적별 경로 비용: 탐험 때 반복 경로의 우선순위만 낮추고 귀환 때는
  검증된 기존 길 사용. 막다른 길 후퇴를 금지하지 않는다. 집/작업대 이름으로 등록·조회·제거.
- [x] 기존 하위 계획 요청에 실제 지도 요약 연결. 지도만으로 벽/미관측 통로를 추정하지 않으며
  경유점 추종이 미지원인 상태에서 LLM 실행 vocabulary에 이동 명령을 추가하지 않는다.
- [x] 실제 MineRL의 F3 켜기/화면 캡처/끄기/입력 해제 진단. OCR과 같은 시점 서버 좌표 대조.
  준비용 UI 검사이며 정책 탐험 성공/학습 표본으로 세지 않는다. API/optimizer0.
- [x] 기존 실제 궤적의 지도 재생, 집 왕복/탐험 후보 선택 회귀, STOP/기존 하위 계획 회귀.

결과: [검증 기록](spatial-exploration-validation-2026-10-10.md).
집/경로 검사는 저장·조회 및 알고리즘 회귀이며 실제 학습 정책의 귀환 성공은 아니다.
지도 복원 API/CLI는 구현했지만 실험 controller는 에피소드마다 새 지도를 만든다.
F3 판독→별도 지도 저장은 실제 화면으로 확인했으며, 이동 중 자동 F3 관측과 live planner의
F3 출처 입력은 후속 과제다. 현재 live planner 지도 출처는 privileged server로 명시한다.

## 파일과 검증

`spatial_memory.py`: 출처가 고정된 지도, 관측된 방향별 연결, 명명된 장소, 목적별 경로 비용.
`f3_coordinates.py`: 제한된 XYZ 텍스트 해석. OCR은 별도 로컬 도구이며 이미지 해시로 결합한다.
`subgoal_control.py`/`rm_planner.py`: 지도 관측·저장·계획 입력. 원래 RM/조건 벡터 계약 불변.
각 모듈의 실패 재현 검사를 먼저 실행한 뒤 구현한다.

위치만으로 통행 가능 공간이나 자원 위치를 알아낼 수 없다. 이 단위 다음의 학습 과제는
시각 관측으로 통행 후보를 확보하고 상대 경유점 입력을 따라가는 신경망 이동이다.
현재 동결 STEVE-1의 텍스트 조건을 좌표 추종 정책이라고 바꾸어 부르지 않는다.
