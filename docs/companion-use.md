# 한 명령으로 실행하고 이어가기

프로젝트 PowerShell에서 실행한다.

```powershell
Set-Location -LiteralPath 'D:\DATA\Desktop\MinecraftRL'
.\scripts\Start-MinecraftRL.ps1
```

기본 저장 슬롯은 `companion`, 대화 사용자 ID는 `local-operator`다. 같은 슬롯과
사용자 ID로 다시 실행하면 같은 월드·과업과 기존 대화 기억을 읽는다. 미완료 과업은
paused 상태로 복원되며 `다시 계속해줘`를 입력해야 정책 행동이 시작된다.
완료·취소된 과업을 복원했다면 새 수집 요청을 입력할 수 있다.

처음에는 게임과 모델 초기화에 시간이 걸린다. 준비 메시지 이후 입력한다.
현재 사용 흐름은 **세션별 제어 최대 180초**이며 대기·일시정지도 포함한다.
목표 완료·취소·시간 상한이면 저장하고 종료한다. 종료 뒤 같은 명령으로 다시 실행한다.
장시간 연속 플레이 모드나 자동 반복 시작은 아직 제공하지 않는다.

| 입력 | 동작 |
|---|---|
| `흙 2개 모아줘` | 새 흙 수집 목표 |
| `원목 2개 모아줘` | 새 원목 수집 목표 |
| `목표를 흙 3개로 바꿔줘` | 현재 목표 수정, 수정 시점부터 추가 3개 |
| `잠시 멈춰줘` | 입력 해제 후 일시정지 |
| `다시 계속해줘` | 일시정지된 과업 재개 |
| `작업 취소해줘` | 과업 취소 후 세션 종료 |
| `/status` | 목표·획득량·완료 단계·정체 상태 조회 |
| `/help` | 지원 명령 |
| `/exit`, `/stop`, Ctrl+C | STOP 요청, 입력 해제·저장·자식 종료 확인 |

기존 `Invoke-DialogueConsole.ps1`의 `/exit`는 콘솔만 닫는다. **새 통합 실행기의
`/exit`는 게임 세션도 종료한다.** 다른 터미널의 `scripts/Stop-PolicyProbe.ps1`도
계속 사용할 수 있다. 원격 API 응답 대기 중에는 외부 STOP 명령을 사용한다.

기본 모드는 유료 API 없이 제한된 한국어 문법만 사용한다. 자유 대화 LLM을 사용하려면
이미 제공되는 프로세스 환경 변수 `OPENAI_API_KEY`, `OPENAI_MODEL`과 명시적인
`-AllowPaidApi -MaxApiCalls 5` 옵션이 필요하다. 이번 작업은 실제 API를 호출하지 않았다.
키나 MyWife의 개인 기록을 자동으로 가져오지 않는다. LLM 제안의 확인 절차와 기존
페르소나·최근 대화/발췌 요약 구조를 그대로 사용한다.

별도 월드/사용자를 쓰려면 `-WorldSlot my-world -UserId my-user`를 지정한다.
서로 다른 사용자에게 같은 슬롯을 주면 같은 게임 월드를 공유하므로 이름을 구분한다.
실행 기록은 표시된 `results/companion-<시각>/`, 게임 증거는 그 안의 `run/`에 있다.
같은 슬롯의 월드는 `data/worlds/`, 사용자별 기억은 `data/dialogue/`에 저장된다.

실행기는 직전 STOP을 결과 폴더에 보존하고 시작하며 종료 시 STOP을 다시 유지한다.
동시에 두 통합 실행기가 시작되지 않도록 잠금 파일을 사용한다. 비정상 종료로
`results/companion-launch.lock`이 남았다면 내용의 PID 및 기록을 확인하고 소유 실행이
끝난 뒤에만 해당 파일을 제거한다. 실행기는 잠금을 자동으로 빼앗지 않는다.
다른 기존 실행기와 동시에 시작하지 않는다.

현재 실행 가능한 목표는 원목·흙 수집뿐이다. 조합은 아래 평가 대상으로 남아 있다.
