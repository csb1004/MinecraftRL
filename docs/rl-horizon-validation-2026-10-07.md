# 할인 시간 규모·GAE 비교 — 2026-10-07

실제 학습 네 분기와 평가20회가 완료됐다. 원시 감사·행동 재생 결과는 아래 후속 기록과 `results/rl-horizon-20261007/audit.json`을 기준으로 한다. [사전 고정 프로토콜](rl-horizon-protocol-2026-10-07.md).

## 질문과 변경

사용자는 tick 단위 행동에 비해 보상 영향이 짧고 중간 보상을 악용할 수 있다는 문제를 제기했다. 원목 최초 획득 +1·즉시 종료·1행동=1서버 tick·관측/행동 경계는 유지했다. GAE는 원래도 한 번의 역순 계산으로 전체 궤적을 처리한다. 문제는 계산 전파 속도가 아니라 감쇠와 가치 추정 의존성이다.

γ=.99,.995,.999 × λ=.95,.99,1의 9조합을 저장 자료에서 비교했다. 실제 학습에는 γ=.99/.999 × λ=.95/1의 4분기를 동일한 24개 궤적·4,855행동·부모 actor·한 epoch·학습률·셔플·PPO 설정으로 사용한다. 기본 정책은 자동 교체하지 않는다.

## 시간 초과 타깃 수정

24궤적 중 23개는 목표 획득 종료, 1개는 시간 초과다. 시간 초과를 실패 0으로 바꾸지 않았다. 저장 final.png와 committed final recurrent state로 마지막 특징을 복원했으며 기존 bootstrap **0.17148734629154205**가 정확히 재현됐다. 이 복원은 실제 모델을 사용하지만 게임 행동은 0회인 오프라인 계산이다.

새 γ에는 기존 γ=.99 bootstrap을 재사용하지 않는다. 16세계 leave-one-world-out critic을 영 prior·ridge1로 학습하고, 잘린 궤적은 초기 .5 bootstrap에서 정확히 3회 fitting을 수행한다. 각 다음 bootstrap은 새 critic의 마지막 특징 예측을 [0,1]로 제한한다. 이는 추정이며 정답이 아니다. 0/1 양끝 민감도도 별도로 기록한다. λ=1도 시간 초과에서는 추정 bootstrap이 들어가므로 완전 관측 Monte Carlo가 아니다.

Actor advantage에는 자신의 세계를 제외한 critic을, 함께 학습할 value 초기값에는 해당 γ의 전체 학습자료 fit을 사용한다. 이 새로운 critic 절차는 네 분기에 공통이다. 따라서 부모 대비 차이는 critic 절차와 PPO 업데이트도 포함하며, γ와 λ의 효과는 학습 분기 사이에서 구분해야 한다.

## 원시 감사와 원인 분리

`audit.json` verified=true. 실제4,866행동의 server tick1, 서버 인벤토리 보상, 목표 수락 이후 새 추론/행동 없음, stop_ack 이후 전달 없음, 입력 해제, 소유 PID 정리를 확인했다. 모든 평가 궤적은 학습 제외다. 초기 세계·서버 상태·순환 상태·sampling seed·embedding의18개 비교는 모두 일치했고, 초기 화면은15/18만 동일했다. 실제 첫 추론20회는 .212~1.809초였다. 전체 제어주기의 시행별 중앙값 범위134.95~157.37ms, p95 범위155.55~223.65ms다.

후속 `action-diagnosis/diagnosis.json`은 **4,866개 실제 행동과 확률을 모두 오차0으로 재현**했다. 각 저장 입력과 난수를 고정한 채 부모/네 후보 head를 교체해 한 단계 행동의 차이를 검사했다. 부모와 실제 첫 행동이 다른10개 비교 중9개는 부모 입력·후보 입력 어느 쪽에서도 그 지점의 actor 교체 효과가 없었다. 즉 해당 첫 분기를 actor 변경만으로 설명할 수 없다. γ=.999/λ=.95 반복1의4번째 행동은 후보 입력에서만 actor 교체 효과가 있어 입력과 파라미터의 상호작용이 관측됐다.

2000003의 부모 저장 입력에서는 모든 후보가86행동 전부 같은 행동을 냈다. 2000029 부모 입력에서는 γ=.999/λ=.95가 두 반복 각각14/448·15/448행동을 바꿨다. **학습 파라미터가 실제 행동 선택을 바꿀 수 있음은 확인했지만, 관측된 전체 경로 단축의 인과 효과는 분리하지 못했다.** 한 단계 개입은 달라진 행동 이후의 대체 미래 화면을 재현하는 실험이 아니다. 따라서23.77% 단축은 관측 결과이며 확정된 정책 개선률이 아니다.

## 판단과 다음 개선 방향

중간 보상은 추가하지 않았다. 할인률과 타깃 처리, 다른 γ의 critic을 기존 bootstrap과 섞지 않는 경계, 세계 제외 advantage 계산, 고정한 실제 비교·행동 재생 도구를 구현했다. γ=.999·λ=.95를 **후속 검증 후보**로 보존하고 기본 정책은 유지한다. λ=1이 더 좋은 해결책이라는 가설은 이번 비교로 지지되지 않았다.

다음 우선순위는 더 긴 학습이나 임의 shaping보다 **새 개발세계의 다양성 및 반복 분포 확보**다. 현재 쉬운 세계는 모든 조건86tick으로 구분력이 없고, 학습 자료는23성공/1시간초과로 편향되어 있다. 기존 두 개발세계의 좋은 결과를 보고 반복 수를 사후 늘리거나 최종5시드를 튜닝에 사용하지 않는다. 새 개발세계 목록·예산·성공/효율 판정을 먼저 고정한 뒤 후보와 대조를 비교하는 것이 적절하다. 정확한 렌더링 결정성이 없더라도 충분한 독립 세계의 결과 분포로 평가할 수 있으나 이번 규모는 부족하다. 이번 단계에서 해당 추가 배치는 실행하지 않았다.
