# 통로 진입 경험 학습과 분리 평가 — 2026-10-07~08

통로 가까운 훈련 배치에서는 정책이2/2회 원목을 획득했고,622전이로 PPO78회 업데이트를
완료했다. 그러나 긴 벽의 별도 평가에서는 부모/후보 모두0/2회 획득했다.
**성공 경험 확보와 실제 학습은 완료했지만 정체 복구 개선은 입증하지 못했다.** 기본 정책은 유지한다.

[완료 배치](../results/recovery-gap-20261007/experiment.json),

## 바꾼 것

기존 실패 세계/궤적은 보존하고 독립 훈련 ZIP2개를 만들었다. 벽은 x7,z1..3으로 유지하고
시작점은 상대(5.5,201,5.5), 시작 yaw는 나무 중심 방향으로 바꿨다. 두 번째 세계는 반사 배치다.
초기 배치가 쉬워졌으므로 이전 실패와 이번 수집 성공의 차이를 학습 효과로 해석하지 않는다.

세계 seed104743/104759와 정책 sampling seed701/702를 분리했다. 새 CLI 옵션은
`scripts/run_rl_pilot.py --sampling-seed`, worker의 `--rl-sampling-seed`다.
생략하면 기존처럼 세계 seed를 사용한다. 세계 seed·정책 seed는 요청과 실제 policy condition에서 대조했다.

부모는 기존 v2 head, 실행 보상/문맥은v4다. embedding·전체 물리 행동 공간·frozen backbone을
유지했다. 오프라인 배치 수정 이외에 scripted 이동, API 대체, LLM 제어는 사용하지 않았다.
관측은 서버 RM 문맥을 사용하는 privileged 조건이며 영상 전용 결과가 아니다.

## 학습과 문맥 반응

동일 behavior의 새 훈련2개만 사용했다. fresh AdamW,2epoch,batch16,lr1e-5,gamma.99,
lambda.95,clip.2,reference KL 계수.01. 실제78회 갱신, 행동 확률 재현 오차0,
checkpoint 재로딩 확률 오차0·optimizer state 재로딩 확인. 최종 평균 reference KL은
0.000664369로 한도.03을 통과했다. 이 KL은 이번 수집 behavior와의 차이이며 성능 보증은 아니다.

## LLM 상위 플래너와 다음 단위

[LLM 상위 플래너 검토안](llm-high-level-planner-2026-10-07.md)을 준비했다. 기존 MyWife 참고
구조의 의미 해석/persona 분리와 최근 대화+요약을 유지하면서, 실행 중 정체에 대한 하위 과업
제안·검증을 추가하는 안이다. 실제 정체2건/완료1건의 snapshot도 추출했다. **아직 실행 planner
구현이나 실제 LLM 호출을 한 것은 아니다.**

이번 성공 경험에는 정체 후 방향을 고르는 구간이 없었다. 다음은 이동/재탐색의 관측과
완료 조건을 갖추고 정체 위치에서 통로 진입으로 이어지는 경험을 확보하는 단위다.
LLM은 지원된 하위 과업을 제안하고 RM은 목표/완료 근거를 유지하는 역할로 분리한다.
현재 없는 이동 skill을 LLM vocabulary에 이름만 추가하지 않는다. 지연 원인 격리도 함께
다루되 평가 자료를 보고 이번 후보를 재학습하거나 성공 표본으로 바꾸지 않는다.
