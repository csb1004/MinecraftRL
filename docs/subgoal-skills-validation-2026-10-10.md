# LLM이 선택할 수 있는 신경망 하위 스킬

검증 상태: 로컬 구현·개발 게임·전수 감사·조건 비교·최종 회귀 검사 완료.
이 보고서 이후 별도 승인으로 [실제 LLM 연결 검사](subgoal-live-validation-2026-10-10.md)도 완료했다.
[실행 범위](subgoal-skills-protocol-2026-10-10.md).

## 달라진 실행 구조

LLM의 RM 계획이 `leave_stalled_area`, `locate_wood`, `approach_wood`를 선택·생략·의존 순서·우선순위로
구성할 수 있다. 등록된 단계는 실제 STEVE-1 입력 embedding을 바꾸며, 이동/시점/공격/인벤토리 행동은
동결 신경망 출력이다. 각 단계는 실제 서버 관측의 완료 조건과 최대200tick/30초의 예산을 갖는다.
조건 문구를 추가한 것이 새 운동 능력을 학습했다는 뜻은 아니다. 실험용 실행기이며 새 optimizer 갱신은 없다.

| 스킬 | 실제 완료 조건 | 해석 한계 |
|---|---|---|
| 정체 지점 벗어나기 | 진입 위치에서 수평3블록 이동 | 벽을 우회하거나 통로를 확보했다는 증거가 아님 |
| 나무 위치 찾기 | 서버의 유효한 원목/드롭 목표 추적 | 화면상 인식 정확도나 접근 가능성과 다름 |
| 나무 접근 | 현재 원목 상호작용/드롭 수집 준비 | 새 텍스트 조건이며 우회 능력을 보장하지 않음 |

계획 입력의 추상 상태는 `gui_open`, `unknown`, `tracked_unreachable`, `reachable`, `mining`,
`collecting`, `completed`다. 실제 위치·목표·도달 가능성·인벤토리·tick에 묶어 검증하며,
단계와 조건 해시는 행동/특징 궤적에도 저장한다. 하위 단계 달성은 root 보상이 되지 않는다.
원래 root RM, 보상, 완료 조건, 진행도와 recurrent memory를 유지한다. 지원되지 않는 계획은 실행하지 않는다.

실패한 노드의 실제 전후 관측/방법/행동 수/종료 이유를 이전 계획과 함께 다음 요청으로 전달한다.
같은 실패 조건은 노드 이름·설명·예산·우선순위를 바꾸거나 기존 탐색을 다른 이름으로 불러도 반복하지 못한다.
관측으로 이미 충족된 단계는 행동0으로 생략하며, 이를 정책이 새로 달성한 것으로 세지 않는다.

## 실제 화면·기억을 고정한 조건 영향

새 게임의803번째 행동 직전까지802화면을 재생해 같은 recurrent memory를 복원하고,
같은 화면/RM 문맥에서 조건 벡터만 네 가지로 바꿨다. 실제 leave 조건의 특징 벡터 재현 오차는0이다.
기존 wood 대비 행동 분포 KL은 leave0.076934, locate0.009698, approach0.048378이었다.
최대 단일 범주 확률 차이는 각각0.076350/0.019468/0.049778이다.
이는 입력 조건이 정책 출력에 영향을 주는 **동일 관측1개 비교**이며, 각 스킬의 수행 능력이나 성공률을 뜻하지 않는다.
새 게임/API/optimizer 갱신0, GPU peak allocated1128.804MiB. `condition-probe/report.json`에 기록했다.

## 수정과 로컬 검사

- GUI 열림을 정상 상태로 표현하고 열린 동안 탐색/접근 조건을 완료시키지 않도록 수정했다.
  원래 신경망 인벤토리 동작은 유지하며 자동 키 스크립트로 닫지 않는다.
- 재계획 중 중립 문맥 인코딩의 입력과 기록이 원래 wood 조건으로 일치하도록 수정했다.
- 새 조건 뒤 기존 탐색을 고르면 원래 explore embedding을 복원하고, 초기 조건 메타데이터를 보존한다.
- 계획이 탐색을 생략하고 접근부터 선택하면 실제 첫 정책 입력도 달라진다.
- 알려진 목표와 접근 가능성을 구분하고, 이동만으로 root 수집 재개를 허가하지 않는다.
- 계획 대기/응답/추론/실행 도중 STOP 경계와 입력 해제의 모의 검사를 통과했다.
- 게임 이후 첫 행동 전 예산 만료 경계를 추가 재현했다. 행동0을 실패로 기록해 재계획하는 오류를
  `unrun`으로 수정하고 추가 호출 없이 정지하게 했다. 이 수정은 별도 모의 재현/회귀 검사로 검증하며,
  완료된 게임을 재실행하지 않았다. 실제 게임 소스 사본과 최종 두 모듈 변경을 구분해 보존한다.

최종 Windows 전체516검사/21skip, WSL521검사/9skip 통과(실패0).
첫 오류191전이와 성공1315전이, 합계1506전이를 감사했다. 초기 오류는 오류인 채로 보존했고,
감사 통과는 그191전이를 정상 실행 성공으로 바꾸지 않는다.
결과 묶음은 `results/subgoal-skills-20261010/`에 보존한다.
보존/완료 근거는 같은 디렉터리 `final-verification.json`이다.
