# 공통 이동 입력과 행동 학습 목적의 분리 비교

현재 시점 좌표를 사용한 학습에서도 개발 A는 6개 목표 모두 반경 안에 들어갔지만
12틱 안정 도착은 1개였다. 목표 가까이에서 이동·점프가 다시 발생했다. 학습 시드의
거의 정지한 상태 4개를 이용한 평지 내 거리 반사실 검사에서도 가까운 목표의 전진
확률이 먼 목표보다 높았다. 이는 추가 진단 근거이며 실제 성공률이나 원인 확정은 아니다.

진행 중인 현재 좌표 비교 배치를 먼저 종료·감사하고, 다음 두 변경을 분리한다.
원래 actor, 같은 1,384개 학습 상태와 별도 254개 monitor, 난수14101,
16epoch/batch32/학습률1e-4/KL 한도3을 유지한다. 개발 게임 자료는 gradient에 넣지 않는다.

WSL Torch2.0.1에서 별도 linear 검사는 최대1.1921e-7의 연산 차이를 보였고 가중치 역변환은
정확했다. 실제 학습 대상 MLP는 CPU/CUDA 모두 오차0이었다. linear 단위 검사는1e-6 절대
오차를 허용하며, 실제 MLP 학습기는 모든 train/monitor 입력의 변환 오차0을 계속 요구한다.

1. `distance16`: residual에만 거리 입력을 16배 한다. 해당 첫 층 가중치를 1/16로
   변환하여 시작 정책 함수는 그대로 유지한다. 기존 동결 정책은 기존 distance/16을 받는다.
   BC는 기존 latent 정답을 사용한다. checkpoint에 scale을 명시하고 저장·복원한다.
   비기본 scale의 checkpoint는 v2로 구분하여 예전 코드가 잘못 해석하지 않고 거부하게 한다.
2. `delivered`: 거리 scale은 기존1이다. 실제 Minecraft 명령이 같은 latent 표현들의
   확률 합을 BC 정답 확률로 사용한다. 카메라 off일 때 불필요한 카메라 정답 압력을 줄인다.
   게임 sampling과 PPO/원본 행동 logp는 변경하지 않는다.

두 모델 모두 시작은 v3 `584e7cf507a9ce4376f542f46269660fc40fc9f900e3878f425bc9f727066fb1`이다.
현재 canonical/scale1 결과는 참조이며, 추가 학습된 후보에서 시작하지 않는다.
입력 변환만으로 actor가 학습됐다고 세지 않는다. 변환 후 optimizer 전 fingerprint를 기준으로
실제 retained update와 actor 변경, 동결 원본/value 보존, logit 변환 오차와 reload 오차를 검증한다.

두 variant는 GPU에서 순차 실행한다. 학습·별도 monitor의 canonical 및 delivered NLL,
거리별 실제 명령 확률, 안정 도착을 각각 기록한다. 두 후보 중 monitor delivered NLL이
낮고 진단상 가까운 목표 정지 확률이 개선된 후보를 먼저 개발 게임에서 검사한다.
사전에 적합성을 확인한4개 학습 상태를 고정하며, 먼 목표 전진 확률이 참조보다0.05 이상
떨어진 후보는 제외한다. 이 작은 반사실 검사를 실제 이동 성과로 세지 않는다.
어느 쪽도 개선되지 않으면 게임 성공을 가정하지 않고 학습 실패를 진단한다.
모니터는 선택에 쓰인 개발 자료이며 최종 평가가 아니다.

게임 비교는 동일 월드·목표·초기 화면/기억·sampling seed17479, client pose,
12틱 안정 도착을 유지하고 같은 코드/JAR에서 새 기준 실행과 짝짓는다.
기준은 canonical/scale1의 현재 좌표 학습 후보다. 각 게임 제어시간 최대180초,
최소10/12 안정 도착·월드별 악화 없음·총 도착 개선 또는 동률에서 행동 감소가 필요하다.
STOP 후 행동0·키 해제·소유 PID 정리 및 확률 재생 감사도 필요하다.
통과 전 기본 모델은 교체하지 않는다. 예약 최종 시드와 인간 영상 학습은 사용하지 않는다.

이 단계는 목표 조건부 공통 이동·접근·감속의 실제 가중치 학습이다. 자연 지형 위험 회피,
시각만으로 목표 발견, 제작 및 돌 도끼로 원목64개 수집까지 검증됐다는 뜻은 아니다.

## 실행 중 추가 진단: 가까운 정면 목표의 자료 부족

`results/common-navigation-conditioning-preparation-20261017/label-coverage.json`에서
1,384개 학습 정답의 거리 입력과 실제 현재 좌표 거리가 정확히 일치했다.
정지 반경 안 정답451개 중 목표가 정면12도 이내인 것은54개,5도 이내는16개뿐이었다.
특히5도 이내에서 이미 거의 정지한 자료는4개이고 나머지12개는 이동 중이었다.
목표가 정면12도 이내이면서 정지 반경 밖인 이동 정답은221개였다.
전체 정지 표본 수만으로 정면 접근·정지 조건의 coverage가 충분하다고 볼 수 없다.
이는 데이터 편향의 근거이며 단독 원인이나 실제 개선의 증명은 아니다.

두 고정 비교의 결과를 먼저 보존한다. 이후에도 같은 반응이 남으면 실제 train 영상 상태에
서로 다른 합법적인 상대 목표를 짝지어 교사에게 질의하는 방법을 검토한다. 알려진 평지
범위 안에서만 가능하며, 가상의 목표/정답 sidecar를 원본 행동·logp와 분리해야 한다.
그러한 자료는 실제로 수행한 궤적이나 PPO 표본, 실제 목표 달성으로 계산할 수 없다.
