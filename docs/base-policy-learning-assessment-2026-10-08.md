# 기본 행동 학습의 제약과 추가 학습 경로

후속 실행: [마지막 기억층 BC·실제 진단4회](temporal-bc-validation-2026-10-08.md)를 완료했다.
아래 내용은 그 구현 전 조사다. 현재는 기억층 학습/추론 연결이 구현됐으나 긴 벽 우회는 미해결이다.

2026-10-08 사용자 질문에 대한 코드·공식 자료 조사. 원인 확정이나 개선 완료 보고가 아니다.
이번에는 새 학습/게임/대용량 다운로드/Colab 연결을 실행하지 않았다.

## 추가 학습 가능 여부

VPT는 모방학습과 RL로 추가 학습할 수 있고, 공식 저장소에는 RL 미세조정 가중치가 공개돼 있다.
[공식 VPT](https://github.com/openai/Video-Pre-Training#models-with-environment-interactions).
STEVE-1도 학습 가능한 VPT 기반 정책이며 공식 학습 코드는 목표 조건을 준 연속 시연 BC다.
RL 업데이트를 붙이는 것은 가능하지만 원 논문의 BC 학습을 곧바로 PPO 구현으로 취급하지 않는다.
[공식 STEVE-1](https://github.com/Shalev-Lifshitz/STEVE-1).
MineStudio는 PPO와 시퀀스 기반 온라인 학습 구성 요소를 제공한다. 현재 환경의 STEVE-1/RM/STOP
계약과 호환되는지 확인해야 하며 설치만으로 이동 능력이 생기는 것은 아니다.
[MineStudio trainer](https://craftjarvis.github.io/MineStudio/online/trainer.html).

## 현재 코드에서 확인한 제약

| 확인한 사실 | 근거 | 해석 경계 |
|---|---|---|
| 로컬 PPO는 actor/value만 갱신 | scripts/train_rl_heads.py의 optimizer parameter 목록 | 사전학습 전체의 RL 적응을 시험한 것이 아님 |
| 최근 BC는 lastlayer/final_ln+actor만 갱신 | scripts/train_bc_heads.py, 캐시 tail_input | 실제 파인튜닝이지만 CNN/recurrent 학습은 아님 |
| 특징 추출은 no_grad, CNN/recurrent 동결 | src/minecraftrl/rl_policy.py | 기존 시간 문맥은 사용하지만 기억 표현을 새로 학습하지 못함 |
| RM6은 net 출력 뒤 붙음 | RLPolicy.features, extend_context_head | RM 단계가 시각/기억 특징 생성에 직접 들어가지 않음 |
| 범주 행동 head는 선형층 | external/steve1/steve1/VPT/lib/action_head.py | 고정 특징+RM 입력은 주로 행동 logit 조절; RM 조건의 새로운 시각·기억 표현 학습과 구분 |
| BC KL<=.03을 게임 비교 gate로 사용 | src/minecraftrl/bc_core.py | 모델 고유 한계가 아니라 프로젝트 실험 기준 |
| 실제 자연 원목 획득, 긴 벽은 정체 | diverse-correction-validation-2026-10-08.md | 기본 조작 전부 미학습이라는 결론은 근거 부족 |

공식 STEVE-1 `train/3_train.sh`는 trunc_t=64인 연속 학습 설정을 제공한다.
이 값을 그대로 실행하자는 뜻은 아니며, 현재 분리된 특징에 대한 head/tail 업데이트와
시간에 걸쳐 오차를 전파하는 학습의 차이를 보여준다.

최근 강한 BC 후보는 개발 손실이 줄었으나 KL gate에서 제외됐다. 평가한 후보는 lr5e-7이었다.
따라서 ‘추가 학습해도 안 된다’고 결론 낼 수 없다. 변화 제한이 기존 벽 공격 행동까지
보존했을 가능성, 조건부 기억의 제한, 교사/학생 방문 상태 차이, 합성 장애물과 사전학습 분포 차이,
기존 로컬 미세조정의 편향을 분리해야 한다. 어느 하나도 현재 단독 원인으로 입증되지 않았다.

## 영상으로 학습하는 방법

VPT는 약70,000시간의 온라인 Minecraft 영상에 IDM으로 행동 의사 라벨을 붙여 학습했다.
IDM은 화면 전후에서 눌렀을 키·마우스 이동을 추정한다. 이를 학습하는 데는 먼저 실제 행동이
기록된 영상이 필요했다. [VPT 방법](https://openai.com/index/vpt/).

행동 없는 영상 → 정제/프레임·카메라 조건 확인 → IDM 행동 추정 → 목표 조건 구성
→ 연속 시퀀스 BC → 실제 환경 RL/평가.

유튜브 영상을 보는 것만으로 정확한 키/마우스 제어 라벨이 생기지는 않는다. 편집·배속·시점·GUI
차이는 라벨 품질에 영향을 줄 수 있다. 영상 표현 학습과 실행 가능한 행동 정책 학습도 구분한다.
우선순위는 공식 공개 ‘영상+실제 행동’ 자료와 목표에 맞는 복구 시연이다. 이미 확보한 소량의
외부 샘플을 대규모 사람 행동 학습으로 부풀리지 않는다. STEVE-1 조건에는 검증된 구간 목표나
공식 hindsight MineCLIP 변환을 사용하며 모든 영상에 collect wood를 붙이지 않는다.

## 근본 원인을 분리할 다음 순서

1. **사전학습 기준선과 실행 경로 대조:** 원본 STEVE-1과 로컬 부모를 동일한 작은 이동·회전·나무
   접근·장애물 복구 묶음에서 비교한다. 동일 가중치의 공식/로컬 추론 전처리, 행동 매핑,
   recurrent reset/commit, guidance를 확인한다. 평가용 자료는 학습에 넣지 않는다.
2. **학습을 실제 허용하는 범위 정리:** BC의 KL 수치를 PPO와 같은 절대 gate로 둘 필요가 있는지
   별도 조건으로 검증한다. 기존 수집 보존은 실제 행동 회귀 평가로 확인하고, 강한 후보의 효과는
   실행 전 새 조건을 고정한 뒤 평가한다. 기존 미실행 결과는 그대로 보존한다.
3. **연속적인 기본 행동·복구 시연 학습:** 걷기/시점/점프/대상 접근/막힌 곳에서 벗어나기를 여러
   지형에서 학습하되, 각각 독립 모델을 처음부터 만들지 않는다. 후반 temporal 층의 부분 해제나
   어댑터를 비교하고, RM이 필요한 경우 조건이 기억/표현에도 작용하는 설계를 검토한다.
   이는 새로운 구현이며 효과·메모리 적합성은 아직 미검증이다.
4. **학생 방문 상태의 교정과 RL:** 실패 상태에서 전문가가 실제로 제공한 교정 행동을 추가한다.
   실패 행동을 그대로 정답으로 재학습하지 않는다. BC 후 실제 서버 사건/RM 보상으로 PPO 등을
   적용하고, 기존 기본 행동 유지와 새로운 복구를 함께 평가한다.
   [DAgger의 상태 분포 문제](https://proceedings.mlr.press/v15/ross11a.html).

RM 목표 보존·우선순위 변경 합의는 유지한다. 상위 목표 관리와 하위 기본 행동 학습을 혼동하지 않는다.

## 자원

현재 GTX1060 3GB에서 부분 BC는 실제 실행했다. 약2.5억 파라미터 전체를 FP32 Adam으로
학습하면 가중치/gradient/두 optimizer 상태의 산술 하한만 약3.72GiB이고 activation은 별도다.
이는 전층 OOM 실험 결과가 아니며 offload/부분 학습 가능성을 배제하지 않는다.
시간 문맥을 학습하는 메모리 probe와 외부 GPU용 재현 묶음이 필요하다. 실제 Colab 연결과
유료 자원 사용은 별도 범위이며 이번에는 실행하지 않았다.
