# 판자 회수 즉시 정지·보존 검증

이전 판자 실험과 같은 원목 1개 저장 세대, 같은 문구·가중치·guidance 및 고정 시드
5개를 사용한다. 변경 조건은 회수 증거(원목 감소 1, 판자 증가 4, 제작 통계 증가 4)가
관측된 직후 정책을 정지하는 옵션뿐이다. 원본 저장소는 보존하고 독립 복사본을 쓴다.
제어 상한 180초, 추가 API 0회, 일반 대화/RM에는 아직 제작 목표를 추가하지 않는다.

판자 4개 회수 관측 직후 target_reached를 기록하며 다음 추론·정책 dispatch는 없어야 한다.
그 뒤 중립 입력 해제·필요 시 GUI 닫기·저장한다. 정리 후 관측뿐 아니라 저장 NBT의
실제 플레이어 인벤토리에도 판자 4개가 남아야 보존 성공으로 판정한다.
회수에 도달하지 못한 시행은 별도 미달성으로 기록한다. 정리가 대신 회수한 것은
정책 성공으로 계산하지 않는다. 기존 무정지 결과와 비교하되 게임의 비결정성 때문에
성공률 차이 전체를 정지 옵션의 인과 효과로 단정하지 않는다.
