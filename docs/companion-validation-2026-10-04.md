# 통합 실행 진입점 검증

`scripts/Start-MinecraftRL.ps1`로 Windows 대화 콘솔과 WSL STEVE-1 세션을 함께
시작하는 흐름을 추가했다. [사용법](companion-use.md). 기존 SessionDialogue,
사용자별 기억·페르소나, 파일 명령함, 월드 저장, 정책 실행기를 재사용한다.
기본 API 호출은 0회다. 이번 검증의 입력은 제한된 한국어 명령이며 원격 LLM 평가는 아니다.

## 실제 발견한 문제와 수정

1. 실행기 기록 폴더를 먼저 만들면 기존 CLI의 신규 출력 폴더 조건과 충돌했다.
   게임 기록을 별도 `run/`에 쓰도록 분리했다. 최초 실패는 게임 시작 전이며
   `results/companion-smoke-20261004T050016Z/`와 해당 실행 로그에 보존했다.
2. WSL 자식이 콘솔의 표준 입력을 공유해 입력이 콘솔에 도달하지 않는 현상이 있었다.
   WSL 경로 조회와 정책 실행 자식에 DEVNULL을 지정했다. 수정 전 시험은 준비 상태에서
   STOP으로 저장·종료했으며 `results/companion-smoke-20261004T050048Z/`에 보존했다.
   수정 후 같은 PowerShell 진입점의 파이프 입력이 실제 정책 명령으로 전달됐다.
3. 복원한 완료/취소 과업에 새 수집을 요청하면 대화기가 불필요한 expected_revision을
   붙여 새 요청을 막았다. 활성 과업에만 revision을 붙이고 worker의 기존 상태 검사를
   유지했다. 완료 과업에서 새 수집이 되는 실제 세션도 확인했다.
4. 자연 완료 직후 STOP을 다시 설정하면 supervisor가 성공 상태를 cancelled로
   재분류하는 경합이 있었다. 자연 종료 기록·프로세스 종료를 기다린 뒤 STOP을 설정한다.
   사용자 종료는 기존대로 STOP을 먼저 보낸다. 두 순서에 대한 회귀 검사를 추가했다.

## 실제 사용 흐름

시험 전용 슬롯 `companion-smoke-20261004T050428Z`만 사용했다. 기본 companion 슬롯과
앞선 연구용 실패 월드는 변경하지 않았다. 세션 제어 상한은 각각 180초다.

| 단계 | 실제 동작 | 관측 결과 |
|---|---|---|
| A | 새 월드에서 원목 64 요청→행동 1회→일시정지→/status→/exit | paused 과업 저장, 정상 정리 |
| B | 같은 월드·원목 목표 복원→흙 1개로 수정→재개 | 인벤토리 흙 1개, 142 steps, 과업 완료 |
| C | 완료된 과업 복원→새 흙 1개 요청 | baseline 1→총 2개, 152 steps, task_completed |

A/B는 `results/companion-smoke-20261004T050428Z/acceptance.json` 및 각 phase 로그,
C는 `results/companion-completion-acceptance.json`, `results/companion-completion-live.log`에 있다.
B의 raw session status는 수정 전 경합으로 cancelled였지만 task status=completed와
실제 획득 증거가 있다. 원래 기록을 수정하지 않았다. C에서는 종료 상태 수정 후
task_completed와 정상 정리를 확인했다. 따라서 A/B의 passed는 당시 검사한
제어·획득·정리 조건이며, 종료 상태 표시 오류까지 없었다는 뜻이 아니다.

모든 A/B/C에서 입력 해제, 월드 저장, 소유 자식 종료를 확인했다. A의 pause 수락 후
행동 0회, B의 명시적 resume 전 행동 0회, 각 STOP acknowledgment 후 행동 0회다.
시험 사용자 기억 revision은 5이며 세션을 넘긴 요청·중단·수정·재개 기록이 저장됐다.

- 최종 Windows 108개 중 104개 통과, Linux 전용 4개 제외(1.703초).

- PowerShell 구문 검사 통과. 초기 새 테스트 실패와 후속 통과 로그 보존.

- 종료 시 프로젝트 관련 WSL Python/Java 잔존 0개, STOP 유지, 실행기 잠금 해제.
- 추가 API 0회, 기존 누적 37회 유지. 시스템 환경·GitHub·Colab 변경 없음.
