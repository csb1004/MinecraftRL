# 통로 진입 경험 확보 — 사전 조건

직전 짧은 벽2세계×2회 실패는 보존하고 반복하지 않는다. 이번 단위는 하위 정책의 실제
통로 통과→재접근→원목 획득 경험 확보다. LLM 실시간 재계획은 별도 설계 항목이며
이번 실제 정책 수집에는 넣지 않는다.

훈련104743/104759의 원본 자연 월드에서 새 ZIP2개를 만든다. 벽 x7,z1..3은 유지하고
시작점만 상대좌표(5.5,201,5.5)로 이동한다. 두 번째 배치는 전체 z축 반사이며 연속 좌표는
16-z, 블록 좌표는15-z다. 시작 yaw는 나무 중심을 향하고 pitch-13이다.
이는 오프라인 훈련 배치 변경이며 게임 중 scripted 이동이나 정책 성공으로 세지 않는다.

세계 seed와 정책 sampling seed를 분리해701/702를 사용한다. 옵션 미지정 시 기존 seed
동작을 유지한다. 부모 v2 checkpoint·embedding·v4 보상·200tick 정체 판정·전체 물리 행동
공간·backbone 고정 조건은 그대로다. 각1회 최대180초, 실제 통과(center x≥8.3)와 서버
인벤토리 원목 증가를 각각 기록한다. 정체 전 통과는 정체 복구 성공으로 계산하지 않는다.

중립 cleanup의 실제 서버 응답에서 held_key_count0과 server_available1을 기록·검사한다.
누락/비영 값은 기술 실패이며 유효 학습 궤적으로 처리하지 않는다. STOP 뒤 정책 행동 금지,
입력 해제와 소유 PID 종료를 감사한다. 기존 사망 경로는 terminal 환경을 다시 step하지 않는다.

두 궤적 모두 감사 통과하고 한 개 이상 실제 통과 및 획득하면 같은 behavior의 두 훈련 자료로
fresh PPO2epoch를 실행한다(lr1e-5, gamma.99, lambda.95, batch16, KL.01, clip.2).
최종 reference KL≤.03 및 확률 재현/reload 검사를 통과한 경우만 후보로 보존한다.
초과하면 같은 데이터에서 fresh1epoch를 단1회 시도한다. 후보가 없으면 후속 평가를 실행하지 않는다.
이전 실패·평가 궤적을 이번 학습에 혼합하지 않는다. 수집2회 모두 실패하면 무한 반복하지 않는다.

후보가 있으면 이미 준비된 별도2000003/2000029의 긴 벽 ZIP에서 부모/후보 각1회,
첫 세계 부모→후보·둘째 후보→부모로 실행한다. v4 동일 조건, 초기 서버/메모리/픽셀 비교,
실제 통과·획득·시간·추론·VRAM·중단을 기록한다. 평가를 보고 재학습하지 않는다.
기본 정책 자동 승격, 최종5시드 사용, 유료 API/Colab 연결은 없다.
