# 공통 이동 정책의 손실 충돌 진단

공동학습+BCE 후보의 실제 train 검증과 자료 봉인을 마친 뒤, 같은 후보에서 학습 항별
기울기를 측정한다. 원인은 아직 확정하지 않는다. 목적은 다음 설정 변경을 결과에 근거해
선택하는 것이며, 새 학습·게임·정답 추가·기본 정책 승격은 이 진단에 포함하지 않는다.

대상은 0c987523 후보와 출발 223ae08d이다. 기존 41,387정답, BC 가중치, 첫 회차의
546개 기본/대조 표본 순서를 해시로 재현한다. 이 중 처음부터 끝까지 균등한 64배치를
측정한다. 개발·최종 정답은 기울기에 사용하지 않는다. 기존 공간 입력 재매개변수화8과
학습변수1,471,828개를 그대로 사용한다. 업데이트 수는 0이다.

분리하는 항은 평지 BC, 단차 BC, 사람 시연 BC, 전체 KL(.01), 평지 추가 KL(1),
목표 쌍 BCE(.2)다. 실제 학습의 중요도 보정과 손실 비중을 적용한다. 각 항의 평균
기울기 크기, 서로의 내적/각도와 기존 근거리 train 진단의 정지 확률에 대한 국소 방향을
기록한다. 후자는 추가 학습 정답으로 사용하지 않는다.

평지 추가 KL이 나머지 항과 반대 방향인지, 그 항을 .25 또는 0으로 줄인 가상 기울기에서
국소 정지 오차의 방향이 어떻게 달라지는지 계산한다. 이 비교는 실제 Adam 업데이트가
아니며 새 가중치를 만들지 않는다. 관측된 충돌이 없으면 KL을 원인으로 단정하지 않는다.
충돌이 있더라도 실제 성능 개선은 별도 고정 예산 대조와 기존 검증 기준으로 확인해야 한다.

코드: `results/common-gradient-balance-20261023/audit_loss_gradients.py`.
출력: 같은 폴더의 `loss-gradient-audit.json`. 학습·게임과 GPU를 동시에 사용하지 않는다.
