# 상대 경유점 이동 학습·개발 검사

사용자 `응 실행해줘`로 직전 제안의 경유점 이동 학습·검증을 실행한다. 원문 연구 명세와
root RM/보상/원본 체크포인트는 유지한다. 새 유료 API와 최종 평가 시드는 사용하지 않는다.
주 실행 흐름에서 순차 작업한다.

목표는 지도에 선택된 위치까지 신경망 행동으로 이동하는 선행 능력이다. 이번 고정 개발 검사는
이미 검증된 fixture 경로를 상위 목표로 공급한다. 자동 통행 지점 인식/자연 월드 경로 계획이나
F3 이동 중 판독의 성공으로 해석하지 않는다. 위치·시선 입력과 성공 판정은 privileged server다.

## 데이터·학습 계약

- 자료: 감사된 `onset-coverage-features-20261009/features.pt`의13세션. train11/개발2,
  train seed104743·104759, 개발104761. 개발 자료는 optimizer/checkpoint 선택에서 제외한다.
- 원본 handoff의 경유점 순서와 실제 teacher 행을 결합한다. 좌표를 정규화하고 mirror 변환을
  적용한다. 원래 도착 반경0.22에서 목표를 넘기며, 거리0.35 이하의 도착/중립 행과 harvest는
  이동 BC 정답에서 제외한다. 학생 prefix는 기억 문맥이며 정답으로 쓰지 않는다.
- 부모는 SHA473142f…의 coverage checkpoint. 기존 frozen prefix 캐시에서 부모의 마지막 기억층과
  표현층을 전 에피소드 순서로 재계산한다. 과거 다른 가중치의 완성 특징을 그대로 학습하지 않는다.
- 목표 입력6개: 상대 방위 sin/cos, 수평거리/16, 수직거리/4, pitch/90, 활성 상수1.
  기존2054 특징 뒤에 추가하며 기본 글꼴/F3와 무관한 수치 조건임을 명시한다.
- 이동 actor는 부모 actor 복사본+0 초기화 목표 열이다. 기존 actor/value/시각·기억 가중치는 보존한다.
  이동 actor만 BC. 목표 열을 별도 선형 파라미터로 두어 lr1e-3, 기존 특징 열 lr5e-5,
  batch32,12epoch, seed9921,
  parent KL계수0.01, gradient norm1. 개발 평가로 epoch/체크포인트를 선택하지 않는다.
- 평가: NLL/버튼·카메라 정답률, 목표 반전 개입의 행동 분포 변화, 저장/reload와 실제 runtime 일치.
  오프라인 수치가 좋아도 실제 도달 성공으로 세지 않는다.

## 실제 개발 조건

개발 far/corner 원본 월드 각1회, sampling seed9922/9923, 총 제어180초 이하.
parent 원목 정책의 실제 정체 뒤 fixture 경유점을 공급한다. 이동 행동은 학습 actor에서만 샘플한다.
이동 예산 최대400행동/60초. 실제 수평거리0.35 이하·높이차1.5 이하에서 경유점을 완료하고,
경로 완료 후 기존 원목 actor/RM으로 복귀한다. 예산 소진/GUI/정체 실패는 기록하고 중지한다.
성공은 서버 위치/인벤토리, 중단 이후 새 정책 행동0·키 해제·소유 PID 정리로 판정한다.
미실행/기술 오류는 정책 실패와 구분한다. 부모 비교가 없으면 인과 개선을 주장하지 않는다.

실제 입장 조건은 출처/분할·finite·reload·정책 입력 일치 통과다. 예측 성능의 임의 임계값으로
미실행을 성공/실패로 바꾸지 않는다. 실패 시 원본을 보존하고 원인에 근거한 수정만 별도 조건으로 실행한다.
