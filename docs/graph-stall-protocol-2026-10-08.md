# 그래프 반복·무진전 감지 검사

사용자 승인: 반복 행동/무진전 감지에 그래프 사이클을 검토하고, 기존 로그에서 정상 채굴·우회와
정체를 구분하는 감지기부터 구현한다. 이 단위는 **관찰 전용 replay**다. 새 게임·정책 학습·LLM
호출·RM 변경·실행 중단 개입은 하지 않는다. 정책의 실제 우회 개선은 별도 후속 검증이다.

## 구현 계약

- 노드는 1블록 위치 셀, 45도 시선 구간, 실제 센서의 내부 단계, 대상 좌표다. 간선은 실제 시간
  순서의 전이다. 정적 그래프의 사이클 존재만으로 경보하지 않는다. 순차 경로의 재방문에서
  닫힌 경로를 추출하고 같은 방향의 사이클 반복과 실제 무진전을 함께 기록한다.
- 자기 루프, 여러 노드 순환, 사이클 없이 무진전인 경우를 구분한다. 작은 움직임/단계 왕복만으로
  타이머를 재설정하지 않는다. 임계값보다 작은 위치 변화를 각각 진행으로 누적하지 않는다.
- 진전은 새 탐색 위치/방향, 처음 발견한 대상, 동일 대상 거리 최고 기록의 0.5블록 이상 개선,
  실제 채굴 진행 최고 기록, 블록 소실 사건, 목표 인벤토리 최고 기록이다. 방향 신규성은 search에만
  사용한다. 이동 셀 신규성은 탐색/접근에서만 사용하며 유한한 시간 예산과 별개다.
- 정상 우회를 막지 않도록 신규 위치로의 이동은 직선거리 증가와 함께 발생해도 허용한다.
  단순 target/stage 변경은 진전이 아니다. 새 대상/블록 사건은 해당 ID당 한 번만 인정한다.
- 관찰창의 초기 가설: search 400, approach 200, mine 400, collect 200 server ticks.
  stage 변경만으로 시간을 연장하지 않도록 최근 무진전 구간에 적용된 가장 긴 관찰창을 사용한다.
  별도로 과업 증거 없는 800tick을 재검토 후보로 기록한다. 이 값들은 검증된 최적값이 아니다.
- 실제 채굴 damage 센서는 현재 저장 로그에 없다. wood_server_mining=1을 damage 진전으로
  둔갑시키지 않고 mine 유예만 적용한다. 서버 위치/인벤토리를 사용하는 privileged 조건이다.
- stale tick/관측 누락은 정체 대신 관측 오류로 분리하고 기존 시간 이력을 끊는다. 종료 뒤에는
  새 판단을 받지 않는다. 감지기는 행동을 전송하거나 목표/RM/보상을 변경하지 않는다.
- 경보는 무진전 episode당 한 번, 유효 진전으로 해제한다. 재계획 성공·관측 부족·정체를 구분해
  출력하고 근거 tick, 반복 경로, 행동 비중, 마지막 진전 이유를 보존한다.

## 확인할 단위

1. 단위 검사: 제자리 공격, 정상 연속 채굴, 느린 접근, 멀어지는 우회, 상태/대상 왕복, 반복 경로,
   단발 왕복, 좌표 경계 떨림, 관측 누락/시간 역행, 목표 완료/외부 STOP, 보상 악용 없는 기록.
2. 기존 train 교사6회와 막힌 출발2회는 개발용 진단으로 분리한다. 기존 development의 원본/로컬
   긴벽2회·자연2회·교사 우회2회를 별도 요약한다. 이미 본 개발 자료이므로 새로운 blind test가 아니다.
3. 고정 시드 최종 평가5개는 읽거나 사용하지 않는다. 원본 events/summary/초기 상태 해시를 고정하고
   결과는 새 results 경로에 저장한다. 완료된 게임 배치를 다시 실행하지 않는다.
4. 긴벽의 이동0 구간에서 감지 지연을 계산한다. 성공 궤적의 경보는 전부 출력하여 오탐 후보로
   검토한다. 성공했다는 이유만으로 중간 정체가 없었다고 단정하지 않는다. 실제 반복 왕복 사례가
   부족하면 합성 검사 결과와 구분하여 실로그 검증 미완료로 남긴다.

그래프 정의 참고: [NetworkX directed simple cycles](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.cycles.simple_cycles.html).
일반 그래프의 모든 사이클을 열거하는 의존성을 추가하지 않고 실제 경로에서 관측된 사이클만 추출한다.
